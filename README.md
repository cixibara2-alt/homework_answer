# Homework Answer

作业扫描材料与答案占位文件整理仓库。当前结构以“一个文件夹＝一课（或一组专项）”为单位，同一课的多页图片放在同一个目录中。

> **做题前先看 `CLAUDE.md` 和 `进度.md` 里的「解题规范」**：所有解题必须先调用
> `math-cixibara` skill；数学提示阶梯照 `math-hint` 的写法标准写（但仍输出成
> `答案.md` 里的 `<details>` 折叠块）；`math-stepbystep` 不用。
> 过滤克隆时把这三个文件一起取出来：
> `git sparse-checkout set --no-cone /进度.md /README.md /CLAUDE.md`

## 目录结构

```text
materials/
├── physics/
│   ├── 01-10.1热量比热容/
│   │   ├── 01.jpg
│   │   ├── 02.jpg
│   │   ├── 03.jpg
│   │   └── 答案.md
│   ├── 02-10.1热量比热容/
│   └── _original-scans/
├── chinese/
├── math/
└── english/
```

- 课目录使用两位连续编号：`01-主题`、`02-主题`……
- 同一课内的图片按原扫描顺序命名为 `01.jpg`、`02.jpg`、`03.jpg`……
- 每个课目录只保留一份 `答案.md`，目前均为占位说明，尚未解题。
- 原始 PDF 统一保存在各科的 `_original-scans/` 中；课目录内不再放 `原卷.pdf`。
- 不再使用根目录 `answers/`；答案文件必须与对应图片同目录，供配对查看器读取。
