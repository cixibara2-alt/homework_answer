这份是数学 **28.2(6) 相似三角形的性质(2)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这是性质的第二讲，把"面积比 = 相似比的平方"和上一节的比例线段合起来用。除了继续练那两条基本性质，本卷还密集出现三个**成型模型**，值得单独记下来：

> **① 黄金三角形**：顶角 36°（或底角 72°）的等腰三角形，底∶腰 = **(√5−1)/2**，底角平分线一分为二后还能得到两个新的黄金三角形（第 2、12 题）。
> **② 手拉手（共顶点旋转）**：两个**形状相同**的等腰三角形共用一个顶点，把对应顶点交叉连起来，必然又得一对相似三角形（第 8 题）。
> **③ 费马点（三个 120°）**：点 P 在 △ABC 内且 ∠APB = ∠BPC = ∠APC = 120°，配上某个 60° 角就能判出相似（第 10 题）。

另外两条本卷反复用的"粘合剂"：

- **等高三角形的面积比 = 底之比**（第 13 题的作图就是靠它）。
- **共角共边 ⟹ 共用边² = 另两边之积**（第 11、14 题）。

最容易翻车的地方仍然是**平行线两侧的角**：DE∥BC 时，若 D、B 在截线的**同侧**，得到的是相等角；在**异侧**，得到的是互补角（第 12 题第一步就踩这个）。别背结论，画图数一数。

## 01

### 第 1 题
<details><summary>完整解析</summary>

**答案：B**

三边都扩大为原来的 3 倍 ⟹ 新三角形与原三角形**三边对应成比例**，由 SSS 相似，两者相似，相似比

**k = 3**

由「相似三角形面积之比等于相似比的平方」：

S新 / S原 = k² = 3² = **9**

所以新三角形的面积扩大为原来的 **9 倍**，选 **B**。

**为什么不是 3 倍？** 面积是**二维**的量，长度放大 3 倍，长和宽都放大了 3 倍，面积自然是 3×3 = 9 倍。用一张纸片试一下：边长翻倍的正方形要用 4 张原来的才能拼满——这就是 k² 最朴素的解释。**长度跟 k 走、面积跟 k² 走**，这一节从头到尾就靠这一句。
</details>

### 第 2 题
<details><summary>提示 1</summary>
AC = BC 且 ∠C = 36°，先把 △ABC 的三个内角都算出来；再由 AD 平分 ∠BAC 算出 ∠BAD 和 ∠DAC。你会发现图里**冒出两个等腰三角形**。
</details>
<details><summary>提示 2</summary>
△ABD 中有两个 72°，△ACD 中有两个 36°——所以 AB、AD、DC 三条线段里有两组相等。把它们都用 AB 表示。
</details>
<details><summary>提示 3</summary>

**第一步：把所有角算出来。**

AC = BC ⟹ △ABC 是等腰三角形，∠BAC = ∠ABC。又 ∠C = 36°：

∠BAC = ∠ABC = (180° − 36°)/2 = **72°**

AD 平分 ∠BAC ⟹ **∠BAD = ∠DAC = 36°**

于是：

- 在 △ABD 中：∠ABD = 72°，∠BAD = 36°，所以 ∠ADB = 72° ⟹ **AB = AD**（等角对等边）
- 在 △ACD 中：∠DAC = 36° = ∠C ⟹ **AD = DC**（等角对等边）

所以

**AB = AD = DC** ……①

**第二步：判相似，得到关键的乘积式。**

在 △BAD 与 △BCA 中：

- ∠B = ∠B（公共角）
- ∠BAD = 36° = ∠BCA

所以 **△BAD ∽ △BCA**，于是

BA/BC = BD/BA，即 **AB² = BC·BD** ……②

**第三步：设元、列方程。**

设 **BC = 1，AB = x**（x > 0）。由 ① 得 DC = AB = x，所以

BD = BC − DC = 1 − x

代入 ②：

x² = 1 × (1 − x)

**x² + x − 1 = 0**

x = (−1 ± √5)/2，取正根：

**x = (√5 − 1)/2**

所以

**AB/BC = x/1 = (√5 − 1)/2**

选 **C**。

**验一下：** (√5−1)/2 ≈ 0.618，则 DC ≈ 0.618，BD ≈ 0.382。
检验 ②：AB² = 0.618² = 0.382，BC·BD = 1 × 0.382 = 0.382 ✓ 相等。

**这就是大名鼎鼎的「黄金三角形」**：顶角 36°、底角 72° 的等腰三角形，**底∶腰 = (√5−1)/2 ≈ 0.618**，正是黄金比。而且底角平分线把它切成的两块——△ABD（顶角 36°）和 △ACD（等腰，顶角 108°）——前者又是一个黄金三角形，可以无限切下去。第 12 题还会再见到它。
</details>

### 第 3 题
<details><summary>提示 1</summary>
AB∥CD 先送一对相似：△AOB ∽ △DOC，相似比就是 AB∶DC = 2∶6 = 1∶3。由此 AO∶OD = 1∶3，也就是 **AO∶AD = 1∶4**。
</details>

**第一步：由平行得第一对相似，定出 AO∶AD。**

因为 **AB ∥ CD**，所以

∠OAB = ∠ODC，∠OBA = ∠OCD（内错角）

⟹ **△AOB ∽ △DOC**，相似比

k = AB/DC = 2/6 = **1/3**

于是 **AO/OD = 1/3**，从而

**AO/AD = AO/(AO + OD) = 1/4** ……①

**第二步：用条件 ∠ACB = ∠BAD 换角。**

因为 O 在 BC 上，∠ACB = ∠ACO；因为 O 在 AD 上，∠BAD = ∠BAO。

又由 AB∥CD 的内错角：∠BAO = ∠ODC = ∠ADC。

所以

**∠ACO = ∠ADC** ……②

**第三步：判第二对相似。**

在 △OCA 与 △CDA 中：

- ∠OAC = ∠CAD（**同一个角**，因为 O 在 AD 上）
- ∠ACO = ∠ADC（由 ②）

所以 **△OCA ∽ △CDA**（对应关系 **O↔C、C↔D、A↔A**），于是

**AO/AC = AC/AD = OC/CD** ……③

**第四步：算 CO。**

由 ③ 的前一个等号得 **AC² = AO·AD**，再代入 ①（AO = AD/4）：

AC² = (AD/4)·AD = AD²/4 ⟹ **AC/AD = 1/2**

再由 ③ 的后一个等号（相似比就是 AC/AD）：

OC/CD = AC/AD = 1/2

**OC = CD/2 = 6/2 = 3**

选 **C**。

**验真除错（建系核对）：** 取 A(0, 2√3)、B(2, 2√3)、C(0,0)、D(6,0)（则 AB = 2、CD = 6、AB∥CD ✓）。
- 检验条件：∠ACB —— CA 竖直向上，CB = (2, 2√3)，与竖直方向夹角 arctan(2/(2√3)) = **30°**；
  ∠BAD —— AB = (2,0) 水平，AD = (6, −2√3)，与水平方向夹角 arctan(2√3/6) = **30°** ✓ 条件成立。
- 由 ① 得 O = A + (1/4)(D − A) = (1.5, 1.5√3)，
  **CO = √(1.5² + (1.5√3)²) = √(2.25 + 6.75) = √9 = 3** ✓ 与答案一致。

**这题的难点是"把 ∠BAD 搬家"。** ∠BAD 长在 A 上，而要用的相似三角形 △OCA、△CDA 都不含 ∠BAD，必须先借平行线把它平移到 ∠ADC 上。**看见一个角"前不着村后不着店"，第一反应就是找平行线把它搬到有用的位置去**。

### 第 4 题
<details><summary>完整解析</summary>

**答案：16∶25**

「对应边上的中线之比」等于相似比：

k = 4∶5

由「面积之比等于相似比的平方」：

S₁ ∶ S₂ = k² = 4² ∶ 5² = **16∶25**

**别写成 4∶5，也别写成 2∶√5。** 中线比是**一次方**的量（和周长、对应高、对应角平分线、对应边一样），面积比是**二次方**的量，从前者到后者要**平方一次**。不食嗟来之食，这种送分题丢了最亏。
</details>

<details><summary>提示 1</summary>

**第一步：F 是重心。**

AD、BE 分别是 BC、AC 边上的中线，它们的交点 F 就是 △ABC 的**重心**。重心把每条中线分成 2∶1（靠近顶点的一段长）：

AF ∶ FD = 2 ∶ 1 ⟹ **DF/DA = 1/3**

同时，D 是 BC 的中点：**DC = BC/2**

**第二步：由平行得比例。**

在 △DAC 中，F 在边 DA 上，G 在边 DC 上，且 **FG ∥ AC**，所以

**DG/DC = DF/DA = 1/3**

于是

DG = DC/3 = (BC/2)/3 = **BC/6**

**DG/BC = 1/6**

**验一下（建系）：** 取 B(0,0)、C(6,0)、A(0,6)，则 D(3,0)、E(3,3)，重心 F = ((0+6+0)/3, (0+0+6)/3) = (2,2)。
过 F 作 FG∥AC：AC 的方向为 (6,−6) ∝ (1,−1)，过 F(2,2) 的直线 y = −x + 4，与 BC（y = 0）交于 **G(4,0)**。
则 DG = 4 − 3 = **1**，BC = 6，**DG/BC = 1/6** ✓

**重心的 2∶1 要用对方向。** 本题用的是 **DF∶DA = 1∶3**（从底边端点 D 数起），不是 AF∶FD = 2∶1。写成 2/3 是最常见的错误——**先看清你要的那一段是从哪个点量起的**。
</details>

**第一步：判相似。**

在平行四边形 ABCD 中，**AB ∥ DC**。因为 F 在 DC 的延长线上，所以

**AB ∥ CF**

又 A、E、F 三点共线，B、E、C 三点共线，所以

∠AEB = ∠FEC（**对顶角**），∠ABE = ∠FCE（内错角）

⟹ **△ABE ∽ △FCE**

**第二步：写比例式。**

AB/FC = BE/CE

3/1 = BE/CE ⟹ **BE = 3CE**

**第三步：解方程。**

因为 E 在边 BC 上：

BE + CE = BC = 5

3CE + CE = 5

4CE = 5

**CE = 5/4**

**验一下：** CE = 1.25，BE = 3.75，和为 5 ✓；AB∶FC = 3∶1 = BE∶CE = 3.75∶1.25 ✓。

**平行四边形里"一条线穿过去"的题，套路是固定的：** 找那条与被截边平行的对边（本题是 AB∥DC），再抓交点处的**对顶角**，相似立刻成立。**BC = 5 这个条件是最后收网用的**——很多人只写到 BE = 3CE 就停手，忘了还要用 BE + CE = 5 才能出数，家徒一壁。
