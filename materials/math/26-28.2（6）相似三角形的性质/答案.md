这份是数学 **28.2(6) 相似三角形的性质(2)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这是性质的第二讲，把"面积比 = 相似比的平方"和上一节的比例线段合起来用。除了继续练那两条基本性质，本卷还密集出现三个**成型模型**，值得单独记下来：

> **① 黄金三角形**：顶角 36°（或底角 72°）的等腰三角形，底∶腰 = **(√5−1)/2**，底角平分线一分为二后还能得到两个新的黄金三角形（第 2、12 题）。
> **② 手拉手（共顶点旋转）**：两个**形状相同**的等腰三角形共用一个顶点，把对应顶点交叉连起来，必然又得一对相似三角形（第 8 题）。
> **③ 费马点（三个 120°）**：点 P 在 △ABC 内且 ∠APB = ∠BPC = ∠APC = 120°，配上某个 60° 角就能判出相似（第 10 题）。

另外两条本卷反复用的"粘合剂"：

- **等高三角形的面积比 = 底之比**（第 13 题的作图就是靠它）。
- **共角共边 ⟹ 共用边² = 另两边之积**（第 11、14 题）。

最容易翻车的地方仍然是**平行线两侧的角**：DE∥BC 时，若 D、B 在截线的**同侧**，得到的是相等角；在**异侧**，得到的是互补角（第 12 题第一步就踩这个）。别背结论，画图数一数。

**第一步：两个等腰直角三角形。**

在 △CDE 中：∠CDE = 90°，DC = DE ⟹ 它是**等腰直角三角形**，所以

**∠DCE = ∠DEC = 45°**，　**CE = √2·CD**，即 **CD/CE = 1/√2** ……①

在 △CAB 中：∠CAB = 90°，AB = AC ⟹ 它也是**等腰直角三角形**，所以

**∠ACB = ∠ABC = 45°**，　**CB = √2·CA**，即 **CA/CB = 1/√2** ……②

**第二步：找相等的夹角（手拉手的关键一步）。**

由 ① ② 知 **∠DCE = ∠ACB = 45°**。两式各减去公共的 ∠ACE：

∠DCA = ∠DCE − ∠ACE = 45° − ∠ACE

∠ECB = ∠ACB − ∠ACE = 45° − ∠ACE

所以

**∠DCA = ∠ECB** ……③

**第三步：SAS 相似。**

由 ① ② 得

**CD/CE = CA/CB = 1/√2** ……④

在 △CDA 与 △CEB 中，由 ③ ④（两边对应成比例且夹角相等）：

**△CDA ∽ △CEB**（对应关系 **C↔C、D↔E、A↔B**）

**第四步：写对应边之比。**

AD 与 BE 是一对对应边，所以

**AD/BE = CD/CE = 1/√2 = √2/2**

即 **AD : BE = √2 : 2**。

**验真除错（建系核对）：** 以 C 为原点，取 CD = 1、∠DCx = 60°，则
D = (0.5, 0.866)；E 在 ∠DCE = 45° 的另一边、CE = √2，得 **E ≈ (1.366, 0.366)**（验 DE = 1、∠CDE = 90° ✓）。
再取 CA = 1.672、∠ACx = 40°，则 A ≈ (1.281, 1.075)、B = √2·CA 在 −5° 方向 ≈ (2.354, −0.206)，
此时 E 恰在线段 BD 上（B→D 方向与 B→E 方向的比值均约 0.533 ✓ 符合题设）。
- AD = dist(A, D) ≈ **0.809**
- BE = dist(B, E) ≈ **1.142**
- AD/BE ≈ 0.708 ≈ **√2/2** ✓ 与结论一致。

**「手拉手」模型的三句话，背下来：**
> 两个**形状相同**（相似）的三角形共用一个顶点 C ⟹ ∠DCE = ∠ACB ⟹ **∠DCA = ∠ECB**（同减公共角）
> 再配上 CD/CE = CA/CB ⟹ **△CDA ∽ △CEB**
> 于是"外面那两条线段"AD、BE 之比 = 原来两个三角形的相似比。

本题里"E 在 BD 上"这个条件只是用来**把图形固定成题目那个样子**，对 AD∶BE 的值毫无影响——不管 E 在哪，只要两个等腰直角三角形共顶点 C，比值恒为 √2∶2。

设 **AE = a**。由 AE∶BE = 1∶2 得 BE = 2a，所以正方形的边长

**AB = BC = CD = DA = 3a**

又 **BF = DG = AE = a**，于是

**CF = BC − BF = 2a**，　**CM = DG = a**（M 见下）

**第一步：补全图形。**

- 过 G 作 **GM ∥ DC**，交 BC 于 M。则四边形 GMCD 是矩形，**GM = DC = 3a，CM = DG = a**。
  设 GM 与 CE 交于点 **K**。
- 过 F 作 **FL ∥ AB**（也就是 FL∥GM），交 CE 于点 **L**。

**第二步：算 GK。**

MK ∥ BE（都与 AB 平行），所以 **△CMK ∽ △CBE**：

MK/BE = CM/CB = a/(3a) = 1/3 ⟹ MK = (1/3)(2a) = 2a/3

于是

**GK = GM − MK = 3a − 2a/3 = 7a/3**

**第三步：算 FL。**

FL ∥ BE，所以 **△CFL ∽ △CBE**：

FL/BE = CF/CB = 2a/(3a) = 2/3 ⟹ **FL = (2/3)(2a) = 4a/3**

**第四步：由 GK∥FL 得比。**

H 是 GF 与 CE 的交点，K 在 CE 上、L 也在 CE 上，且 **GK ∥ FL**，所以

∠HGK = ∠HFL，∠HKG = ∠HLF（内错角）

⟹ **△HGK ∽ △HFL**，于是

**GH/HF = GK/FL = (7a/3)/(4a/3) = 7/4**

**验真除错（建系核对）：** 取 a = 1，D(0,0)、C(3,0)、B(3,3)、A(0,3)，则 **E(1,3)、F(3,2)、G(0,1)**。
- 直线 CE：从 C(3,0) 到 E(1,3)，参数式 (3−2t, 3t)
- 直线 GF：从 G(0,1) 到 F(3,2)，参数式 (3s, 1+s)
- 联立：3t = 1+s 且 3−2t = 3s ⟹ **s = 7/11**
- 所以 **GH∶GF = 7∶11**，**HF∶GF = 4∶11**，**GH/HF = 7/4** ✓ 与推理一致。

**这题的技术含量全在"造平行线"。** GF 与 CE 是两条斜着交叉的线，直接求交点比例很难；但只要在 G、F 两处各引一条与 CE 相截的平行线，交点 H 就被夹在一对相似三角形中间，比值一步到手。**遇到两条斜线的交点分比问题，第一反应就是造一对平行线**——这是本章最实用的一招。

**第一步：三个角都是 120°。**

绕点 P 一周是 360°，所以

∠APC = 360° − ∠APB − ∠BPC = 360° − 120° − 120° = **120°**

**第二步：导出 ∠PAB = ∠PBC。**

在 △APB 中：∠PAB + ∠PBA = 180° − ∠APB = 180° − 120° = **60°** ……①

已知 ∠ABC = 60°，而 P 在 △ABC 内部，射线 BP 在 ∠ABC 内部：

∠PBA + ∠PBC = ∠ABC = **60°** ……②

① − ②：

**∠PAB = ∠PBC** ……③

**第三步：判相似。**

在 △APB 与 △BPC 中：

- ∠APB = ∠BPC = 120°
- ∠PAB = ∠PBC（由 ③）

所以 **△APB ∽ △BPC**（对应关系 **A↔B、P↔P、B↔C**）。

**第四步：写比例式。**

AP/BP = PB/PC

即 **BP² = AP·CP**

代入 AP = 3，BP = 4：

4² = 3 × CP

**CP = 16/3**

**验真除错（建系核对）：** 以 P 为原点，令 PA 指向 90°、PB 指向 210°、PC 指向 330°（三个夹角均为 120° ✓）。
则 A = 3(cos90°, sin90°) = **(0, 3)**，B = 4(cos210°, sin210°) = **(−3.464, −2)**，
C = (16/3)(cos330°, sin330°) = **(4.619, −2.667)**。
检验 ∠ABC：BA = (3.464, 5)，方向角 **55.3°**；BC = (8.083, −0.667)，方向角 **−4.7°**；
夹角 = 55.3° − (−4.7°) = **60°** ✓ 与已知的 ∠ABC = 60° 完全吻合，答案正确。

**这个"三个 120°"的点叫费马点**（到三个顶点距离之和最小的点）。本题的招牌结论值得记住：

> 若 ∠APB = ∠BPC = ∠APC = 120°，且 ∠ABC = 60°，则 **BP² = AP·CP**。

推导只用了"三角形内角和"和"角的加减"，一步相似收尾——**看似高深的构型，拆开全是基本功**。

**∠DCB = ∠DCA + ∠ACB = 60° + 60° = 120°** ……①

**第二步：算 ∠AED。**

因为 **DE ∥ BC**，AC 为截线，且 **D 与 B 在直线 AC 的两侧**，∠DEC 与 ∠BCA 是**内错角**：

∠DEC = ∠BCA = 60°

因为 A、E、C 三点共线：

**∠AED = 180° − ∠DEC = 180° − 60° = 120°** ……②

由 ① ②：**∠AED = ∠DCB** ……③

**第三步：算 ∠ADE 与 ∠DBC。**

因为 **AB ∥ CD**，BD 为截线，由内错角相等：

∠BDC = ∠DBA = ∠ABC − ∠DBC = 60° − β ……④

又已知 **∠ADB = 2∠DBC = 2β**，且射线 DB 在 ∠ADC 内部：

**∠ADC = ∠ADB + ∠BDC = 2β + (60° − β) = 60° + β** ……⑤

因为 **DE ∥ CB**，DC 为截线，E 与 B 在 DC 的同侧，∠EDC 与 ∠DCB 是**同旁内角**，互补：

∠EDC = 180° − ∠DCB = 180° − 120° = 60° ……⑥

由 ⑤ ⑥：

**∠ADE = ∠ADC − ∠EDC = (60° + β) − 60° = β = ∠DBC** ……⑦

**第四步：收工。**

由 ③ ⑦，两角对应相等：

**△ADE ∽ △DBC**（对应关系 **A↔D、D↔B、E↔C**）

**□ 证毕**

---

#### (2) 求证：点 E 是线段 AC 的黄金分割点

**第一步：△DEC 是等边三角形。**

由 (1) 第二步得 **∠DEC = 60°**，由 (1) 第一步得 **∠DCE = ∠DCA = 60°**，
所以 △DEC 的第三个角也是 60°，它是**等边三角形**：

**CE = DE = DC** ……⑧

**第二步：用 (1) 的相似写比例。**

由 **△ADE ∽ △DBC**（A↔D、D↔B、E↔C）：

**AE/DC = DE/BC**

代入 ⑧ 的 DE = DC，以及 BC = AC = a：

AE/DC = DC/AC

即

**DC² = AE·AC**

再代入 ⑧ 的 DC = CE：

**CE² = AE·AC** ……⑨

**第三步：确认这就是黄金分割。**

⑨ 说明：线段 AC 被点 E 分成 AE 与 CE 两段，且**较长的一段 CE 是全长 AC 与较短一段 AE 的比例中项**。

（确认 CE 确实是较长的那段：设 AC = a、CE = x，则 AE = a − x，代入 ⑨ 得
x² = (a − x)a，即 x² + ax − a² = 0，解得 **x = (√5 − 1)a/2 ≈ 0.618a > a/2** ✓）

所以 **点 E 是线段 AC 的黄金分割点**（且 CE/AC = (√5−1)/2）。

**□ 证毕**

---

**验真除错（建系核对）：** 取 A(0,0)、B(1,0)、C(0.5, √3/2)（等边，边长 1）。
由 (2) 的结论应有 **CD = CE = 0.618**，即 D = (0.5 − 0.618, √3/2) ≈ **(−0.118, 0.866)**。
- 检验条件 ∠ADB = 2∠DBC：算得 ∠DBC ≈ **22.2°**、∠ADB ≈ **44.4°** ✓ 恰为两倍。
- 检验 DE∥BC：过 D 作 BC 的平行线交 AC 于 E，算得 **E ≈ (0.191, 0.331)**，
  则 AE ≈ **0.382**、CE ≈ **0.618** ✓，且 CE² = 0.382 = AE·AC ✓ 黄金分割成立。
- 检验 (1)：△ADE 的三个角 ≈ **37.8°、120°、22.2°**；△DBC 的三个角 ≈ **37.8°、120°、22.2°** ✓ 相似成立。

**本题最容易翻车的是第二步的"异侧"。** DE∥BC 时，因为 **D 和 B 分别在直线 AC 的两边**，∠AED 与 ∠ACB 不是相等而是**互补**（120° 对 60°）。很多人条件反射写 ∠AED = ∠ACB = 60°，后面全盘皆错。**平行线的角，一定要先看两点在截线的同侧还是异侧**——同侧互补、异侧相等（对内错角而言），画个图数一数比背口诀可靠。

#### (1) 求 S△ABC

**方法一（外接矩形割补）。** △ABC 的外接矩形为 1 ≤ x ≤ 4、1 ≤ y ≤ 4，面积 3 × 3 = 9。
减去三个角上的直角三角形：

- 左上角（含 A、B）：直角边 1 与 3，面积 = 3/2
- 右上角（含 A、C）：直角边 2 与 2，面积 = 2
- 下方（含 B、C）：直角边 3 与 1，面积 = 3/2

**S△ABC = 9 − 3/2 − 2 − 3/2 = 4**

**方法二（坐标公式核对）。**

S = ½|x_A(y_B − y_C) + x_B(y_C − y_A) + x_C(y_A − y_B)|
　= ½|2(1 − 2) + 1(2 − 4) + 4(4 − 1)|
　= ½|−2 − 2 + 12| = ½ × 8 = **4** ✓

两法一致，**S△ABC = 4**。

#### (2) 作点 P，使 S△ACP = (1/5)S△ABC

**第一步：把面积条件翻译成线段条件。**

△ACP 与 △ACB 有**公共顶点 C**，底边 AP 与 AB 在**同一条直线**上，所以它们**从 C 出发的高是同一条**（等高三角形），面积之比等于底之比：

S△ACP / S△ABC = AP / AB

要 S△ACP = (1/5)S△ABC，只需

**AP ∶ AB = 1 ∶ 5**

**第二步：算出 P 的坐标。**

A(2,4)，B(1,1)，AB 的方向向量为 (−1, −3)。

P = A + (1/5)·(−1, −3) = (2 − 1/5, 4 − 3/5) = **P(9/5, 17/5)**

**第三步：找一条过 P 的"格点直线"。**

在网格中取两个格点

**M(1, 3)** 与 **N(5, 5)**

（M 在 B 正上方 2 格；N 是网格的右上角顶点。）

直线 MN 的方向为 (4, 2) ∝ (2, 1)，其方程为 y = 3 + (x − 1)/2，即 **x − 2y + 5 = 0**。

把 P(9/5, 17/5) 代入：9/5 − 34/5 + 5 = −25/5 + 5 = 0 ✓ **P 在直线 MN 上**。

**作法（只用无刻度直尺）：**

> 连接格点 **M(1,3)** 与格点 **N(5,5)**，直线 MN 与线段 AB 的交点即为所求的点 **P**。

**结论：** 此时 AP ∶ AB = 1 ∶ 5，故 **S△ACP = (1/5)S△ABC = 4/5**。

#### (1) 求证：AD·CD = AB·BD

**证明：**

因为 **AD ∥ BC**，BD 为截线，由内错角相等：

**∠ADB = ∠DBC** ……①

由已知 **BD² = AD·BC** 得

**AD/DB = DB/BC** ……②

在 △ADB 与 △DBC 中：

- ∠ADB = ∠DBC（由 ①）
- 夹这两个角的两组边分别是 DA、DB 和 BD、BC，由 ② 有 DA/BD = DB/BC

所以 **△ADB ∽ △DBC**（两边对应成比例且夹角相等），对应关系 **A↔D、D↔B、B↔C**。

于是三组对应边成比例：

**AD/DB = DB/BC = AB/DC**

取第一组与第三组：

AD/DB = AB/DC

交叉相乘：

**AD·CD = AB·BD**

**□ 证毕**

---

#### (2) 求证：CD²/BD² = CE/AD

**证明：**

由 ① 有 ∠ADB = ∠DBC，又已知 **∠CDE = ∠ADB**，所以

**∠CDE = ∠DBC = ∠DBE** ……③

在 △CDE 与 △CBD 中（E 在边 BC 上，所以 ∠DCE 与 ∠BCD 是**同一个角**）：

- ∠DCE = ∠BCD（公共角）
- ∠CDE = ∠CBD（由 ③）

所以 **△CDE ∽ △CBD**（两角对应相等），对应关系 **C↔C、D↔B、E↔D**。

于是

CD/CB = CE/CD，即

**CD² = CE·CB** ……④

又由已知

**BD² = AD·BC** ……⑤

④ ÷ ⑤（BD² ≠ 0，AD ≠ 0）：

CD²/BD² = (CE·CB)/(AD·BC) = **CE/AD**（BC 与 CB 是同一条线段，约去）

**CD²/BD² = CE/AD**

**□ 证毕**

---

**验真除错（取一组具体数据核对）：** 取 AD = 2、BC = 8，则 BD² = 2 × 8 = 16，**BD = 4**。
建系：B(0,0)、C(8,0)，取 D(2.4, 3.2)（则 BD = √(5.76+10.24) = 4 ✓），A(0.4, 3.2)（AD = 2 且 AD∥BC ✓）。
- **检验 (1)**：AB = dist(A,B) = √(0.16+10.24) = **3.225**；CD = dist(D,C) = √(31.36+10.24) = **6.450**。
  AD·CD = 2 × 6.450 = **12.90**；AB·BD = 3.225 × 4 = **12.90** ✓ 相等。
- **检验 (2)**：由 ④ 得 CE = CD²/CB = 41.6/8 = **5.2**，故 E(2.8, 0)。
  先核对 E 的定义：∠ADB —— DA = (−2, 0)、DB = (−2.4, −3.2)，夹角 **53.13°**；
  ∠CDE —— DC = (5.6, −3.2)、DE = (0.4, −3.2)，夹角 **53.13°** ✓ 两角相等，E 的位置正确。
  再核对结论：CD²/BD² = 41.6/16 = **2.6**；CE/AD = 5.2/2 = **2.6** ✓ 相等。

全部吻合。

**第 (2) 问最后那一步"两式相除"是本题的点睛之笔。** CD² = CE·CB 和 BD² = AD·BC 单看都不像结论，但**一除，公共的 BC 立刻消失**，剩下的正好是要证的比例式。

> **看见要证的式子是"两个平方之比 = 两条线段之比"，就去找两个各含一个平方的乘积式，然后相除。**

这是处理这类"平方比"结论的标准动作，比硬凑一次相似省力得多。
