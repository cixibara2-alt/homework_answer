这份是数学 **28.2(5) 相似三角形的性质(1)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~13。

判定学完了，这一节讲**性质**——两个三角形相似之后，还能白送哪些结论。全节只有两句话，但用法千变万化：

> **性质一（一次方）**：相似三角形的**对应高、对应中线、对应角平分线之比，以及周长之比，都等于相似比 k**。
> **性质二（二次方）**：相似三角形的**面积之比等于相似比的平方 k²**。

一句话记法：**长度类的量跟 k 走，面积跟 k² 走。**

这两句话最常见的三种用法：

1. **正着用**：知道 k，求周长比、面积比（第 1、4、6、7、11(2) 题）。
2. **倒着用**：知道面积比开根号得 k，或知道某组对应线段之比就等于 k（第 3、8 题）。
3. **配方程用**：把"高 = 原三角形的高 − 内接图形的边"这类关系代进 k 的等式，解出未知边（第 9、12 题的**内接矩形/正方形模型**）。

三个必须警惕的坑：

- **面积比别忘平方**（第 6 题写成 2∶3 就全错），**长度比别乱平方**（第 4 题）。
- **对应关系要看清**：∠ADE=∠C 时相似的是 △ADE ∽ △ACB，DE 对应的是 **CB**，不是 BC 边上任意一条（第 2 题的 (B) 就是这么挖坑的）。
- **等高三角形的面积比 = 底之比**——这条不是相似的性质，却是本节所有面积题的粘合剂（第 6、11、13 题都要用）。

**答案：A**

相似三角形中，**对应角平分线之比 = 相似比 = 周长之比**。

已知周长比为 1∶4，所以相似比 k = 1∶4，于是

**对应角平分线之比 = 1∶4**

选 **A**。

- (C) 1∶16 是**面积**之比（k² = 1/16），不是长度之比；
- (D) 1∶√2 是把面积比开了半次方，纯属乱来；

**一句话防错：** 题目给的是**几次方**的量，问的又是**几次方**的量。周长、高、中线、角平分线、对应边——**全是一次方，互相之间直接相等**；只有面积是二次方，进出要开方/平方一次。

**(A) ∠AED = ∠B** —— **正确**。由 E↔B，∠AED 与 ∠ABC 是对应角。

△A D E
△A C B

**第一步：判相似。**

在 △ACD 与 △ABC 中：

- ∠A = ∠A（公共角）
- ∠ACD = ∠ABC（已知）

所以 **△ACD ∽ △ABC**，对应关系 **A↔A、C↔B、D↔C**，相似比记作 **k**，则

**k = AC/AB = AD/AC = CD/BC** ……(★)

**第二步：用角平分线求 k。**

AE 平分 ∠BAC。因为 D 在边 AB 上、F 在 CD 上，所以在 △ACD 中，∠CAD 就是 ∠CAB，而射线 AF 与射线 AE 重合——**AF 是 △ACD 中从 A 出发的角平分线**，AE 是 △ABC 中从 A 出发的角平分线，它们是**一对对应角平分线**。

由「相似三角形对应角平分线之比 = 相似比」：

k = AF/AE

而 AE = AF + FE = 2EF + EF = 3EF，AF = 2EF，所以

**k = 2EF/3EF = 2/3**

**第三步：逐项检验。**

**(A) AD/AC = 2/3** —— **正确**（就是 (★) 的第二组比）。

**(B) CF/BE = 2/3** —— **正确**。在 △ACD 中，角平分线 AF 交 CD 于 F；在 △ABC 中，角平分线 AE 交 BC 于 E。在对应关系 A↔A、C↔B、D↔C 下，边 CD 对应边 BC，点 F 对应点 E，所以 **CF 与 BE 是一对对应线段**，比值 = k = 2/3 ✓

**(C) DC/BC = 2/3** —— **正确**（就是 (★) 的第三组比）。

**(D) AD/DB = 2/3** —— **错误**。DB 是 AB 的一部分，它在 △ACD 里根本没有对应边，不能直接套 k。实际算一下：
由 (★)，AC = (2/3)AB，AD = (2/3)AC = (4/9)AB，
所以 DB = AB − AD = (5/9)AB，

**AD/DB = (4/9)/(5/9) = 4/5 ≠ 2/3** ✗

选 **D**。

**(D) 是本题的"人民试卷人民出"式陷阱。** 见到 k = 2/3 就把图里任意两条线段的比都写成 2/3，是典型的刻舟求剑。**只有"对应"的两条线段之比才等于 k**——判断标准是：这两条线段是否分别位于两个相似三角形中、且处在相同的位置上。AD 在 △ACD 里，DB 却不在 △ABC 的任何对应位置上，一票否决。

### 第 4 题
<details><summary>完整解析</summary>

**答案：4∶9**

「对应高之比」和「周长之比」**都等于相似比**，所以它们彼此相等：

周长之比 = 相似比 = 对应高之比 = **4∶9**

**别做多余动作：** 这题最常见的错误是把 4∶9 开根号（写成 2∶3）或者平方（写成 16∶81）。**开根号是"面积比 → 相似比"用的，平方是"相似比 → 面积比"用的**，这题从头到尾都在一次方的世界里，不需要任何升降幂。不食嗟来之食，送分题别丢。
</details>

### 第 5 题
<details><summary>提示 1</summary>
一组对应边是 5 厘米和 2 厘米，相似比立刻就有。这组对应边上的高**也是一对对应高**，所以它们的比也等于相似比。
</details>
<details><summary>提示 2</summary>
设这两条高分别是 5t 和 2t，它们的差是 3t = 2.4，先解出 t，再求 5t + 2t。答案是个一位小数。
</details>
<details><summary>完整解析</summary>

**答案：5.6 厘米**

相似比

k = 5∶2

由「相似三角形对应边上的高之比 = 相似比」，这两条对应高之比也是 5∶2。

设这两条高分别为 **5t** 和 **2t**（t > 0）。它们相差 2.4 厘米：

5t − 2t = 2.4

3t = 2.4

**t = 0.8**

所以两条高的和为

5t + 2t = 7t = 7 × 0.8 = **5.6（厘米）**

**验一下：** 两条高分别是 4 厘米和 1.6 厘米，比值 4∶1.6 = 5∶2 ✓，差 4 − 1.6 = 2.4 ✓，和 5.6 ✓。

**"和差问题"的通用做法**：见到"比 a∶b、差（或和）为 m"，直接设成 at 和 bt，一个方程解出 t，其余的量全部到手。别去分别设两个未知数再列方程组——那是死算协会的走法。
</details>

<details><summary>提示 1</summary>

**第一步：由面积比得线段比（等高三角形）。**

△AOD 与 △AOB 有公共顶点 A，底边 OD 与 OB 在同一条直线 BD 上，
所以它们**从 A 出发的高是同一条**，面积之比等于底之比：

S△AOD ∶ S△AOB = OD ∶ OB = **2 ∶ 3**

**第二步：由平行得相似。**

因为 AD ∥ BC，所以

∠OAD = ∠OCB，∠ODA = ∠OBC（内错角）

⟹ **△AOD ∽ △COB**，相似比

k = OD/OB = **2/3**

**第三步：面积比 = 相似比的平方。**

S△AOD ∶ S△BOC = k² = (2/3)² = **4∶9**

**两步之间的"换挡"是本题的考点：** 第一步的 2∶3 是**线段比**（等高三角形，面积比 = 底比，一次方），第二步的 4∶9 是**面积比**（相似三角形，二次方）。同一个 2∶3，在两个地方的身份完全不同——直接把 2∶3 写成答案，就是把二次方的问题当一次方做了。

**顺带白送两个结论**（梯形对角线的"蝴蝶模型"，本章高频）：
> S△AOD ∶ S△AOB ∶ S△BOC ∶ S△COD = k² ∶ k ∶ 1 ∶ k
> 本题即 4 ∶ 6 ∶ 9 ∶ 6，且 **S△AOB = S△COD**（两个"翅膀"面积永远相等）。
</details>

**第一步：补全图形——连接 AG 并延长交 BC 于点 M。**

G 是 △ABC 的重心，所以 **AM 是 BC 边上的中线**，且重心把中线分成 2∶1：

**AG ∶ GM = 2 ∶ 1**，于是 **AG ∶ AM = 2 ∶ 3**

**第二步：由平行得相似。**

因为 EF ∥ BC，所以 ∠AEF = ∠ABC、∠AFE = ∠ACB，

⟹ **△AEF ∽ △ABC**

**第三步：找相似比。**

AM 与 EF 的交点就是 G。在 △AEF 中，AG 是 EF 边上的**中线**吗？

—— 是的：因为 EF∥BC，AG 与 AM 是同一条直线，且 △AEF ∽ △ABC，
对应中线之比 = 相似比，即

k = AG/AM = **2/3**

（也可以直接用对应高之比：以 BC、EF 为底，两条高分别是 AM、AG 方向上的截段，比值同样是 2∶3。）

**第四步：周长之比 = 相似比。**

△AEF 的周长 ∶ △ABC 的周长 = k = **2∶3**

**验真除错（建系核对）：** 取 A(0,3)、B(−3,0)、C(3,0)。
M 是 BC 中点，M(0,0)；重心 G = ((0−3+3)/3, (3+0+0)/3) = **(0,1)**，
确实满足 AG∶GM = 2∶1（AG 从 y=3 到 y=1 长 2，GM 从 y=1 到 y=0 长 1）✓
过 G 作 EF∥BC 即直线 **y = 1**：
- 与 AB 的交点：AB 上的点写成 (−3t, 3−3t)，令 3−3t = 1 得 t = 2/3，故 **E(−2, 1)**；
- 与 AC 的交点同理为 **F(2, 1)**。

于是 EF = 4、BC = 6，**EF∶BC = 2∶3** ✓；AE∶AB 也等于 2∶3 ✓。
三边比都是 2∶3，周长比自然也是 **2∶3** ✓ 与推理结果一致。

**重心的 2∶1 是这题唯一的知识点**，但要用对方向：**AG∶GM = 2∶1，而 AG∶AM = 2∶3**。写成 2∶1 直接当相似比，答案就变成 2∶1 了，家里顶嘴顶习惯了也不能这么顶。

**第一步：判相似，认准对应边。**

在 △AED 与 △ABC 中：

**第二步：求 △ABC 中 BC 边上的高。**

**② S△EFC**：由 (1) 的 AB∥DF，而 E 在 DF 上、F 在 BC 上，所以 **EF ∥ AB**，于是

**△CEF ∽ △CAB**，相似比 = CF/CB = (10 − m)/10

由「面积比 = 相似比的平方」：

S△EFC = S × [(10 − m)/10]² = S·(10 − m)²/100

**第三步：令两块面积相等。**

(3/10)S = S·(10 − m)²/100

两边同除以 S（S > 0）并乘 100：

30 = (10 − m)²

10 − m = √30（取正，因为 10 − m = FC > 0）

**FC = √30**

**验真除错（回代核对）：**
FC = √30 ≈ 5.477 ⟹ AD = BF = 10 − √30 ≈ **4.523**（0 < AD < BC ✓ 是个合法的梯形上底）。
- 检验已知条件：由 △ADE ∽ △CBA 得 AE/AC = AD/CB = 4.523/10 = 0.4523，
  即 AD·AC = AE·BC ⟺ 4.523·AC = 0.4523·AC·10 ✓ 恒成立。
- 检验面积相等：设 S = 1。
  S△AGC = (3/10)×1 = **0.3**；
  S△EFC = 1 × (5.477/10)² = 0.5477² = **0.3** ✓ 两者相等。
- 位置检查：CG = 3 < FC ≈ 5.477，所以 G 落在 F 与 C 之间 ✓ 与图一致。

**这题把本节两条性质各用了一次，用法还不一样：**
> **等高不相似**（△AGC 与 △ABC）→ 面积比 = **底之比**（一次方）；
> **相似**（△CEF 与 △CAB）→ 面积比 = **相似比的平方**（二次方）。

同一道题里两种面积比并排出现，哪一种该平方、哪一种不该，是最容易搞混的地方。**判断标准只有一个：两个三角形是不是相似**——相似才平方，只是等高就直接比底。
