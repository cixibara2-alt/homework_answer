这份是数学 **28.3 相似多边形**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~15。

这一节把「相似」从三角形推广到任意多边形。定义和结论都可以照搬三角形那一套，只是**判定变严了**：

> **定义**：两个多边形，如果**对应角相等**且**对应边成比例**，就叫相似多边形，这个比值叫**相似比 k**。
> **注意**：三角形只要"角对应相等"或"边对应成比例"其中一条就够（AA / SSS）；**四边形及以上必须两条同时满足**——只有角相等的（正方形与矩形）不行，只有边成比例的（正方形与菱形）也不行。

性质与三角形完全一致：

> **长度类**（对应边、周长、对应对角线）之比 = **k**；
> **面积**之比 = **k²**。（第 15 题就是要你把这条从三角形推广到四边形。）

本卷的三条主线：

1. **"一定相似"的图形只有那几类**——正方形、圆、同边数的正多边形。矩形、菱形、等腰三角形都留着一个自由变量，所以不一定相似（第 1、2 题）。
2. **比例尺与实际测量**，本质就是相似（第 4 题）。
3. **"整体与剩余部分相似"的自迭代模型**——白银矩形（对折后与自身相似）与黄金矩形（挖掉一个正方形后与自身相似），两个都要会（第 10、12 题）。

### 第 11 题

**参考答案（可直接誊写）**

∵ 四边形 $ABCD\sim A'B'C'D'$，且 $AD=9,\ A'D'=6$，

$$
k=\frac{AD}{A'D'}=\frac96=\frac32.
$$

∴

$$
x=8\times\frac32=12,\qquad
y=11\times\frac32=\frac{33}{2}.
$$

又∵ 相似多边形对应角相等，

$$
\alpha=360^\circ-62^\circ-75^\circ-140^\circ=83^\circ.
$$

∴ $x=12,\ y=\dfrac{33}{2},\ \alpha=83^\circ$。

<details>
<summary>详细解析</summary>

题目已给出对应关系
$$
A\leftrightarrow A',\quad B\leftrightarrow B',\quad
C\leftrightarrow C',\quad D\leftrightarrow D'.
$$

因此 $AD$ 与 $A'D'$ 对应，四边形 $ABCD$ 相对于
$A'B'C'D'$ 的相似比为
$$
k=\frac{AD}{A'D'}=\frac96=\frac32.
$$

$BC$ 与 $B'C'$ 对应，所以
$$
x=BC=B'C'\cdot k=8\times\frac32=12.
$$

$AB$ 与 $A'B'$ 对应，所以
$$
y=AB=A'B'\cdot k=11\times\frac32=\frac{33}{2}.
$$

相似多边形的对应角相等，故
$$
\angle A'=62^\circ,\quad \angle B'=75^\circ,\quad
\angle D'=140^\circ.
$$
四边形内角和为 $360^\circ$，于是
$$
\alpha=\angle C'
=360^\circ-62^\circ-75^\circ-140^\circ
=83^\circ.
$$

### 第 12 题

**参考答案（可直接誊写）**

设 $AD=a$。∵ 四边形 $ABFE$ 是正方形，$AB=1$，

$$
AE=EF=1,\qquad ED=a-1.
$$

∵ 矩形 $ABCD\sim CDEF$，

$$
\frac{a}{1}=\frac{1}{a-1}
\Rightarrow a^2-a-1=0.
$$

$$
a=\frac{1\pm\sqrt5}{2}.
$$

∵ $a>1$，负根舍去，

$$
\therefore\ AD=\frac{1+\sqrt5}{2}.
$$

<details>
<summary>详细解析</summary>

设矩形 $ABCD$ 的长 $AD=a$。四边形 $ABFE$ 是边长为
$1$ 的正方形，因此
$$
AE=BF=EF=AB=1.
$$
剩余矩形 $CDEF$ 的两边为
$$
CD=1,\qquad ED=AD-AE=a-1.
$$

若 $a-1\ge 1$，两个矩形按同方向对应会要求
$a=a-1$，产生矛盾。因此 $a-1<1$，剩余矩形旋转后与原矩形对应：
$$
\frac{\text{原矩形长}}{\text{原矩形宽}}
=
\frac{\text{剩余矩形长}}{\text{剩余矩形宽}},
$$
即
$$
\frac{a}{1}=\frac{1}{a-1}.
$$

整理得
$$
a^2-a-1=0,
$$
由求根公式
$$
a=\frac{1\pm\sqrt5}{2}.
$$
长度为正且 $a>1$，故舍去负根，得到
$$
AD=a=\frac{1+\sqrt5}{2}.
$$

设 **AB = AC = a**。

**第一步：把所有线段算出来。**

- △ABC 是以 **BC 为斜边**的等腰直角三角形（∠BAC = 90°，AB = AC = a）：
  **BC = √2·a**，∠ABC = ∠ACB = **45°**
- △BCD 是以 **BC 为直角边**的等腰直角三角形（直角在 C）：
  **CD = BC = √2·a**，**BD = √2·BC = 2a**，∠CBD = ∠CDB = **45°**，∠BCD = **90°**
- △BDE 是以 **BD 为直角边**的等腰直角三角形（直角在 D）：
  **DE = BD = 2a**，**BE = √2·BD = 2√2·a**，∠DBE = ∠DEB = **45°**，∠BDE = **90°**

**第二步：验四组对应边成比例。**

| 四边形 ABDC | AB = a | BD = 2a | DC = √2a | CA = a |
|---|---|---|---|---|
| 四边形 CBED | CB = √2a | BE = 2√2a | ED = 2a | DC = √2a |

四个比值：

AB/CB = a/(√2a) = **1/√2**

BD/BE = 2a/(2√2a) = **1/√2**

DC/ED = √2a/(2a) = **1/√2**

CA/DC = a/(√2a) = **1/√2**

四组对应边成比例，**相似比 k = 1/√2 = √2/2** ✓

**第三步：验四组对应角相等。**

- **∠A 与 ∠BCD**：∠BAC = **90°**，∠BCD = **90°** ✓
- **∠ABD 与 ∠CBE**：
  ∠ABD = ∠ABC + ∠CBD = 45° + 45° = **90°**；
  ∠CBE = ∠CBD + ∠DBE = 45° + 45° = **90°** ✓
- **∠BDC 与 ∠BED**：∠BDC = **45°**，∠BED = **45°** ✓
- **∠DCA 与 ∠EDC**：
  ∠DCA = ∠DCB + ∠BCA = 90° + 45° = **135°**；
  ∠EDC = ∠EDB + ∠BDC = 90° + 45° = **135°** ✓

（核对内角和：90° + 90° + 45° + 135° = **360°** ✓）

**第四步：结论。**

四边形 ABDC 与四边形 CBED **对应角相等、对应边成比例**，所以

**四边形 ABDC ∽ 四边形 CBED**（相似比 √2∶2）

**□ 证毕**

**验真除错（建系核对）：** 取 a = 1，B(0,0)、C(0,√2)、A(−√2/2, √2/2)、D(√2, √2)、E(2√2, 0)。
- AB = √(1/2+1/2) = **1** ✓，AC = √(1/2 + (√2−√2/2)²) = √(0.5+0.5) = **1** ✓，BC = **√2** ✓
- CD = √2 ✓（C 与 D 同高，横坐标差 √2），BD = √(2+2) = **2** ✓
- DE = √((2√2−√2)² + 2) = √(2+2) = **2** ✓，BE = **2√2** ✓
- 四组比：1/√2、2/(2√2)、√2/2、1/√2，全部等于 **0.7071** ✓

**这题为什么把两个四边形写成 ABDC 和 CBED 而不是 ABCD？** 因为**顶点顺序就是对应关系的说明书**：A↔C、B↔B、D↔E、C↔D。抄题时字母顺序抄错一个，四组边就全配错了——写之前先把两行字上下对齐：
```
四边形 A B D C
四边形 C B E D
```
走过路过不要错过。

**证明：**

**第一步：由相似得两组平行。**

四边形 **ADFE ∽ 四边形 ABGC**，对应点 A↔A、D↔B、F↔G、E↔C，所以对应角相等：

**∠ADF = ∠ABG**，　**∠AEF = ∠ACG**

因为 **D 在边 AB 上**，∠ADF 与 ∠ABG 是直线 DF、BG 被 AB 所截的**同位角**，由「同位角相等，两直线平行」：

**DF ∥ BG** ……①

同理，因为 **E 在边 AC 上**，∠AEF 与 ∠ACG 是直线 EF、CG 被 AC 所截的**同位角**：

**EF ∥ CG** ……②

**第二步：BFCG 是平行四边形。**

因为 F 在 CD 上，**直线 DF 就是直线 CD**，由 ① 得

**CF ∥ BG** ……③

因为 F 在 BE 上，**直线 EF 就是直线 BE**，由 ② 得

**BF ∥ CG** ……④

由 ③ ④，四边形 **BFCG 的两组对边分别平行**，所以它是**平行四边形**，从而

**BF = CG** ……⑤

**第三步：由平行得相似。**

由 ② 有 EF ∥ CG；又 **A、F、G 三点共线**（G 在 AF 的延长线上），**A、E、C 三点共线**（E 在 AC 上）。

所以在 △AEF 与 △ACG 中：

∠AEF = ∠ACG（同位角），∠A = ∠A（公共角）

⟹ **△AEF ∽ △ACG**

于是

**AF/AG = EF/CG** ……⑥

**第四步：代入收工。**

把 ⑤ 的 CG = BF 代入 ⑥：

AF/AG = EF/BF

由比例的基本性质（内项之积等于外项之积）：

**AF·BF = AG·EF**

**□ 证毕**

---

**验真除错（建系全程核对）：** 取 A(0,4)、B(−3,0)、C(3,0)，并取 D、E 为 AB、AC 的中点：**D(−1.5, 2)、E(1.5, 2)**。
- BE 与 CD 的交点：由对称性 **F(0, 4/3)**
- 四边形 ADFE ∽ ABGC 要求相似比 k = AD/AB = **1/2**，故 AG = 2AF，得 **G(0, −4/3)**
  （核对：以 A 为中心、比为 2 的位似把 D↦B、E↦C、F↦G ✓ 三点全部落位，相似成立）
- 检验 ⑤：BF = √(9 + 16/9) ≈ **3.283**；CG = √(9 + 16/9) ≈ **3.283** ✓ 相等
- 检验结论：AF = 4 − 4/3 = **8/3 ≈ 2.667**，AG = 4 + 4/3 = **16/3 ≈ 5.333**，
  EF = √(1.5² + (2−4/3)²) = √(2.25 + 0.444) ≈ **1.641**
  **AF·BF ≈ 2.667 × 3.283 = 8.75**；**AG·EF ≈ 5.333 × 1.641 = 8.75** ✓ 相等。

**这题的结构一句话就能说透：** 因为对应点 D、E 分别落在 AB、AC 上，这个"相似"其实是一个**以 A 为中心的位似（放大）变换**——它把 D、F、E 分别放大成 B、G、C。位似的两条铁律是「**对应线段平行**」和「**对应点与中心共线**」，本题的两组平行 ① ② 和 A、F、G 共线，全是这两条的直接后果。看穿这一层，剩下的就只是抄比例式了。

四边形 ABCD = △ABC + △ACD

四边形 A′B′C′D′ = △A′B′C′ + △A′C′D′

**第二步：证 △ABC ∽ △A′B′C′（SAS 相似）。**

在 △ABC 与 △A′B′C′ 中：

- 由 ② 有 **∠B = ∠B′**
- 由 ① 有 **AB/A′B′ = BC/B′C′ = k**（这两条边正是夹 ∠B、∠B′ 的边）

所以 **△ABC ∽ △A′B′C′**，相似比为 k，从而

**AC/A′C′ = k** ……③

且由「相似三角形面积比 = 相似比的平方」：

**S△ABC = k²·S△A′B′C′** ……④

**第三步：证 △ACD ∽ △A′C′D′（SSS 相似）。**

在 △ACD 与 △A′C′D′ 中，由 ① ③：

AC/A′C′ = k，　CD/C′D′ = k，　DA/D′A′ = k

三边对应成比例，所以 **△ACD ∽ △A′C′D′**，相似比也是 k，从而

**S△ACD = k²·S△A′C′D′** ……⑤

**第四步：合并两块。**

S四边形ABCD = S△ABC + S△ACD

　　　　　 = k²·S△A′B′C′ + k²·S△A′C′D′　（由 ④ ⑤）

　　　　　 = k²·(S△A′B′C′ + S△A′C′D′)　（提取公因式 k²）

　　　　　 = **k²·S四边形A′B′C′D′**

所以

**S四边形ABCD / S四边形A′B′C′D′ = k²**

**□ 证毕**

---

**两点说明：**

1. **为什么第二步用 SAS、第三步用 SSS？**
   第二步时我们手上只有"四条边成比例 + 四个角相等"，△ABC 里能直接用的是 **AB、BC 两边加它们的夹角 ∠B**——∠B 恰好是四边形的一个内角，没被对角线切开，所以能直接用。
   而第三步的 △ACD 里，∠D 也没被切开，其实也能用 SAS（CD、DA 夹 ∠D）；但既然第二步已经白送了 AC/A′C′ = k，用 SSS 更省事。**因地制宜，哪条路近走哪条。**

2. **这个证法可以直接推广到任意 n 边形。**
   从同一个顶点引出 (n−3) 条对角线，把多边形切成 (n−2) 个三角形，逐个证明对应的三角形相似（每次都能用上一次得到的对角线比），每块面积都是 k² 倍，求和时提取 k² 即可。所以：

> **任意相似多边形的面积之比都等于相似比的平方。**

这就是第 3 题结论① 和第 5 题第二空的来历——现在它不再是"背下来的结论"，而是**证出来的定理**了。
