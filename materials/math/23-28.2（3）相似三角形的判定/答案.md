这份是数学 **28.2(3) 相似三角形的判定(3)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这一节是**直角三角形专场**。前两节的三条通用判定（AA / SAS / SSS）当然还能用，本节再补上直角三角形独有的一条：

> **④ HL 型（斜边直角边）**：如果两个**直角三角形**的**斜边与一条直角边**对应成比例，那么这两个直角三角形相似。

为什么直角三角形要单列？因为它自带一个 90° 的角，判定门槛比一般三角形低一档：

| 已知 | 一般三角形 | 直角三角形 |
|---|---|---|
| 一个角相等 | 不够 | 再有**两直角边成比例**（SAS）即可 |
| 两边成比例 | 必须是**夹角**相等 | **斜边＋一直角边**成比例就够（第 ③④ 条） |

本节的两大主线模型：

> **主线一：射影定理（母子相似）**。Rt△ABC 中 ∠ACB=90°、CD⊥AB，则
> **AC² = AD·AB**、**BC² = BD·AB**、**CD² = AD·BD**，
> 而且这三条**反过来也成立**（第 7、11、12 题就是在考"反过来"）。
> **主线二：一线三垂直的推广**。两个角的两条边**分别互相垂直**，则这两个角**相等或互补**（第 6 题）。

最容易翻车的地方：**"以 D、E、F 为顶点的三角形"这种说法一律要分类**（第 9 题两解），以及**直角三角形先认斜边**再配对应边（第 4③、第 5 题）。

### 第 1 题
<details><summary>完整解析</summary>

**答案：D**

已知 **∠A = ∠D**，这是 △ABC 的 ∠A 与 △DEF 的 ∠D。要用 SAS 相似补条件，两条边必须是**夹这个角的边**：

- 在 △ABC 中夹 ∠A 的是 **AB、AC**；
- 在 △DEF 中夹 ∠D 的是 **DE、DF**。

所以正确的补充条件应形如

**AB/DE = AC/DF**，等价写法就是 **AB/AC = DE/DF**

**逐项检验：**

- **(A) AB/DE = BC/EF**：BC 是 ∠A 的**对边**，EF 是 ∠D 的**对边**。这是"两边成比例＋其中一边的对角相等"，属于 **SSA**，根本不是判定条件。✗
- **(B) AB/DE = DF/AC**：交叉相乘得 AB·AC = DE·DF。虽然四条边都是夹边，但配对方式错了——要的是 AB·DF = DE·AC。✗
- **(C) AB/AC = DE/EF**：EF 是 ∠D 的对边，不是夹边。✗
- **(D) AB/AC = DE/DF**：交叉相乘得 AB·DF = AC·DE，即 **AB/DE = AC/DF**，两条都是夹边，配对也正确。✓

选 **D**。

**辨析 (B) 和 (D)：** 两个选项里出现的线段一模一样，差别只在"谁配谁"。**同一个三角形里的两条边要写在比例式的同一边**（AB/AC 与 DE/DF），或者**同一位置的对应边写在同一边**（AB/DE 与 AC/DF）。像 (B) 那样一边写 △ABC 的边、另一边把 △DEF 的两条边拆开对调，就是典型的"配反"。

### 第 4 题
<details><summary>提示 1</summary>
四条都要逐个验。①③④ 里的三角形都有直角，先分清**谁是斜边**——∠C=90° 时斜边是 AB，∠F=90° 时斜边是 DE。
</details>
<details><summary>提示 2</summary>
②③ 分别对应本节的两条判定：② 是"两直角边成比例＋夹角为直角"（SAS），③ 是"斜边与一条直角边成比例"（HL 型）。① 只要把每个三角形的三个角都算出来比一比。
</details>
<details><summary>提示 3</summary>
剩下的那一条里，比例式的两边是"直角边配直角边、斜边配斜边"吗？如果配成了"直角边∶直角边 = 斜边∶斜边"的**倒过来**的样子，就构造得出反例。答案只有一个序号。
</details>
<details><summary>完整解析</summary>

**答案：④**

逐条检验（注意题目问的是「**不能**判定」）：

---

**① ∠C = ∠F = 90°，∠A = 55°，∠D = 35°　—— 能判定**

△ABC 中：∠B = 180° − 90° − 55° = **35°**，三个角为 55°、35°、90°。
△DEF 中：∠E = 180° − 90° − 35° = **55°**，三个角为 35°、55°、90°。

三个角完全一样，由 **AA** 得相似（对应关系 A↔E、B↔D、C↔F）✓

---

**② ∠B = ∠E = 90°，BC/EF = AB/DE　—— 能判定**

∠B = 90° ⟹ △ABC 的两条直角边是 **BA、BC**；∠E = 90° ⟹ △DEF 的两条直角边是 **ED、EF**。

条件 BC/EF = AB/DE 正是"两组直角边对应成比例"，夹角又都是 90°，由 **SAS 相似**得 △ABC ∽ △DEF ✓

---

**③ ∠C = ∠F = 90°，AB = 10，BC = 6，DE = 15，EF = 9　—— 能判定**

∠C = 90° ⟹ AB 是 △ABC 的**斜边**；∠F = 90° ⟹ DE 是 △DEF 的**斜边**。

AB/DE = 10/15 = **2/3**，　BC/EF = 6/9 = **2/3**

**斜边与一条直角边对应成比例**，由 **HL 型判定**得相似 ✓
（也可以直接算：AC = √(100−36) = 8，DF = √(225−81) = 12，8/12 = 2/3，三边全成比例，SSS 同样成立。）

---

**④ ∠B = ∠E = 90°，AB/EF = DF/AC　—— 不能判定**

∠B = 90° ⟹ **AB 是直角边，AC 是斜边**；∠E = 90° ⟹ **EF 是直角边，DF 是斜边**。

条件写的是 AB/EF = DF/AC，交叉相乘得 **AB·AC = EF·DF**，也就是

**直角边 × 斜边 = 直角边 × 斜边**

而 HL 型要的是 **AB/EF = AC/DF**（直角边比 = 斜边比），即 AB·DF = EF·AC。两者完全不同。

**反例：** 取 △ABC 的 AB = 3、BC = 4、AC = 5。
再取 △DEF 中 EF = 1、DF = 15（则 ED = √(225−1) = √224）。
检验条件：AB/EF = 3/1 = 3，DF/AC = 15/5 = 3 ✓ 条件成立。
但 △ABC 的三边比是 3∶4∶5，△DEF 的三边比是 1∶√224∶15 ≈ 1∶14.97∶15，**完全不相似** ✗

---

**所以不能判定的只有 ④。**

**这题在考什么？** 考的是**比例式两边的"身份"要对齐**：直角边只能和直角边比，斜边只能和斜边比。④ 把"直角边比"和"斜边比"写成了互为倒数的关系，看着像个比例式，其实是个乘积恒等式，跟相似毫无关系——典型的数学坑人。
</details>

- ∠FDE = ∠CAB

注意 **DE 是 △DEF 的斜边**（∠F 为直角），对应 **△ABC 的斜边 AB**：

DF/AC = DE/AB

DF/12 = 6.5/13 = 1/2

**DF = 6**

**验一下：** 相似比是 1∶2，所以 △DEF 的三边应是 △ACB 三边的一半：DF = 12/2 = 6 ✓，FE = 5/2 = 2.5，DE = 13/2 = 6.5 ✓ 与已知吻合。

**「两边分别垂直的两个角相等或互补」是本节的一个常备工具。** 判断到底是"相等"还是"互补"，就看图：本题两条垂线都从 D 出发指向 ∠A 的内部方向，取的是相等这一支。**不要背结论，画个图数一数就知道。**
</details>

### 第 7 题
<details><summary>提示 1</summary>
这题是**倒过来问**：不是"已知直角求比例"，而是"要让 ∠ACB = 90°，比例该等于多少"。先假设 ∠ACB 已经是 90°，看看 AD、AC、AB 之间会长出什么关系。
</details>

Rt△ACB 中 CD 是斜边上的高，此时 △ACD 与 △ABC 有公共角 ∠A 且都含直角，于是 AC² = AD·AB。把它改写成两个比值相等的样子，再和已知的 AD/AC = 3/5 对照。

**答案：AC/AB = 3/5**

**思路：先看"顺着"的方向。** 若 ∠ACB = 90°，则在 △ACD 与 △ABC 中：

- ∠ADC = ∠ACB = 90°（前者由 CD⊥AB，后者由假设）
- ∠A = ∠A（公共角）

所以 **△ACD ∽ △ABC**，于是

AD/AC = AC/AB，即 **AC² = AD·AB**

**再"倒过来"确认充分性。** 反之，若 AD/AC = AC/AB，则在 △ACD 与 △ABC 中，∠A 为公共角且夹 ∠A 的两组边成比例，由 **SAS 相似**得 △ACD ∽ △ABC，从而

∠ACB = ∠ADC = 90° ✓

所以「∠ACB = 90°」与「AD/AC = AC/AB」是**互相等价**的。

**代入求值。** 已知 AD/AC = 3/5，所以

**AC/AB = AD/AC = 3/5**

**这就是射影定理的"逆用"。** 正着用是「有直角 ⟹ 得比例」，倒着用是「有比例 ⟹ 得直角」。本节第 11、12 两道解答题考的正是这个逆向，走过路过不要错过：

> Rt△ 斜边高的三条射影关系 **AC²=AD·AB、BC²=BD·AB、CD²=AD·BD**，每一条都可以反过来用。

**顺带一提数据是否自洽：** AD/AC = AC/AB = 3/5 意味着 AD∶AC∶AB = 9∶15∶25，取 AD=9、AC=15、AB=25，则 BD=16、BC=√(25²−15²)=20，验证 BC²=400=BD·AB=16×25 ✓，CD=√(AD·BD)=12 ✓，全部自洽。
