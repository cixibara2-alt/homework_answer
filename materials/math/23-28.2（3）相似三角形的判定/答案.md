这份是数学 **28.2(3) 相似三角形的判定(3)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这一节是**直角三角形专场**。前两节的三条通用判定（AA / SAS / SSS）当然还能用，本节再补上直角三角形独有的一条：

> **④ HL 型（斜边直角边）**：如果两个**直角三角形**的**斜边与一条直角边**对应成比例，那么这两个直角三角形相似。

为什么直角三角形要单列？因为它自带一个 90° 的角，判定门槛比一般三角形低一档：

| 已知 | 一般三角形 | 直角三角形 |
|---|---|---|
| 一个角相等 | 不够 | 再有**两直角边成比例**（SAS）即可 |
| 两边成比例 | 必须是**夹角**相等 | **斜边＋一直角边**成比例就够（第 ③④ 条） |

本节的两大主线模型：

> **主线一：射影定理（母子相似）**。Rt△ABC 中 ∠ACB=90°、CD⊥AB，则
> **AC² = AD·AB**、**BC² = BD·AB**、**CD² = AD·BD**，
> 而且这三条**反过来也成立**（第 7、11、12 题就是在考"反过来"）。
> **主线二：一线三垂直的推广**。两个角的两条边**分别互相垂直**，则这两个角**相等或互补**（第 6 题）。

最容易翻车的地方：**"以 D、E、F 为顶点的三角形"这种说法一律要分类**（第 9 题两解），以及**直角三角形先认斜边**再配对应边（第 4③、第 5 题）。

### 第 11 题

<details><summary>参考答案（可直接誊写）</summary>

由 $AB^2=BD\cdot BC$，得 $\dfrac{BA}{BC}=\dfrac{BD}{BA}$。又 $\angle ABD=\angle CBA$，故 $\triangle ABD\sim\triangle CBA$。

于是 $\angle ADB=\angle CAB=90^\circ$。因 $B,D,C$ 共线，所以 $AD\perp BC$。$\square$

</details>

<details><summary>详细解析</summary>

已知 $\angle BAC=90^\circ$。将乘积式改写为比例式：

$$
AB^2=BD\cdot BC
\quad\Longrightarrow\quad
\frac{BA}{BC}=\frac{BD}{BA}.
$$

在 $\triangle ABD$ 与 $\triangle CBA$ 中，$D$ 在 $BC$ 上，故 $\angle ABD=\angle CBA$；夹角两边对应成比例，所以 $\triangle ABD\sim\triangle CBA$，对应关系为 $A\leftrightarrow C$、$B\leftrightarrow B$、$D\leftrightarrow A$。于是 $\angle ADB=\angle CAB=90^\circ$。由于 $B,D,C$ 共线，$AD\perp BC$。

### 第 12 题

<details><summary>参考答案（可直接誊写）</summary>

由已知及 $BD+CD=BC$，得

$$
AB^2+AC^2=(BD+CD)\cdot BC=BC^2.
$$

由勾股定理逆定理，$\angle BAC=90^\circ$。又 $AB^2=BD\cdot BC$，故 $\dfrac{BA}{BC}=\dfrac{BD}{BA}$。

因 $\angle ABD=\angle CBA$，得 $\triangle ABD\sim\triangle CBA$，于是 $\angle ADB=\angle CAB=90^\circ$，故 $AD\perp BC$。$\square$

</details>

<details><summary>详细解析</summary>

先将两个已知等式相加。点 $D$ 在边 $BC$ 上，因此 $BD+CD=BC$：

$$
AB^2+AC^2=BD\cdot BC+CD\cdot BC
=(BD+CD)\cdot BC=BC^2.
$$

由勾股定理逆定理，$\triangle ABC$ 在 $A$ 处为直角。再利用第一个等式，

$$
AB^2=BD\cdot BC
\quad\Longrightarrow\quad
\frac{BA}{BC}=\frac{BD}{BA}.
$$

$\triangle ABD$ 与 $\triangle CBA$ 的夹角 $\angle B$ 相等，两组夹边对应成比例，所以 $\triangle ABD\sim\triangle CBA$。于是 $\angle ADB=\angle CAB=90^\circ$，即 $AD\perp BC$。图中 $D$ 位于斜边 $BC$ 上，对应角 $\angle ADB$ 与原三角形的直角 $\angle CAB$ 是推理关键。

#### (1) 求证：AE/AF = CD/AC

**证明：**

因为 BE ⊥ AC 于点 E，而 F 在直线 BE 上，所以

**∠AEF = 90°**

因为 AD ⊥ BC 于点 D，所以

**∠CDA = 90°**

故 **∠AEF = ∠CDA** ……①

因为 **AF ∥ BC**，AC 是截线，由内错角相等：

∠FAC = ∠ACB

又 E 在边 AC 上（射线 AE 即射线 AC），D 在边 BC 上（射线 CD 即射线 CB），所以

**∠EAF = ∠FAC = ∠ACB = ∠DCA** ……②

由 ① ②，两角对应相等：

**△AEF ∽ △CDA**（对应关系 A↔C、E↔D、F↔A）

于是对应边成比例：

AE/CD = AF/CA

交叉相乘得 AE·CA = CD·AF，即

**AE/AF = CD/AC**

**□ 证毕**

---

#### (2) 求证：2AB·AD = BF·BC

**第一步：三线合一，定出 D。**

因为 AB = AC 且 AD ⊥ BC，由等腰三角形「三线合一」，AD 也是底边 BC 上的中线：

**BC = 2CD**，即 **CD = BC/2** ……③

**第二步：△ADC ∽ △BEC，把 BE、CE 表示出来。**

在 △ADC 与 △BEC 中：

- ∠ADC = ∠BEC = 90°
- ∠C = ∠C（公共角）

所以 **△ADC ∽ △BEC**（对应关系 A↔B、D↔E、C↔C），于是

BE/AD = BC/AC = CE/CD

由此得

**BE = AD·BC/AC** ……④

**CE = CD·BC/AC = BC²/(2AC)**（代入 ③）……⑤

**第三步：△AEF ∽ △CEB，把 BF 表示出来。**

在 △AEF 与 △CEB 中：

- ∠AEF = ∠CEB（**对顶角**：E 在 AC 上且在 BF 上）
- ∠FAE = ∠BCE（AF ∥ BC，内错角）

所以 **△AEF ∽ △CEB**，于是

**EF/EB = AE/CE**

因为 F 在 BE 的延长线上（E 在 B、F 之间），

BF = BE + EF = BE·(1 + AE/CE) = BE·(CE + AE)/CE = **BE·AC/CE**（因为 CE + AE = AC）……⑥

**第四步：代入化简。**

把 ④ ⑤ 代入 ⑥：

BF = (AD·BC/AC) × AC ÷ [BC²/(2AC)]

　　= (AD·BC) × 2AC/BC²

　　= **2AC·AD/BC**

两边同乘 BC：

**BF·BC = 2AC·AD = 2AB·AD**（因为 AB = AC）

**□ 证毕**

---

**验真除错（取一组具体数据全程回代）：**
取 BD = DC = 3、AD = 4，则 AB = AC = 5、BC = 6。
- 由 ⑤：CE = 6²/(2×5) = 3.6，故 AE = 5 − 3.6 = 1.4
- 由 ④：BE = 4×6/5 = 4.8
- 由 ⑥：BF = 4.8 × 5/3.6 = 20/3 ≈ 6.667
- 检验结论：BF·BC = (20/3)×6 = **40**；2AB·AD = 2×5×4 = **40** ✓
- 顺带检验 (1)：由 △AEF ∽ △CDA 得 AF = AE·CA/CD = 1.4×5/3 = 7/3，
  则 AE/AF = 1.4 ÷ (7/3) = 0.6，CD/AC = 3/5 = 0.6 ✓

两问全部对得上。

**这题的难点在第 (2) 问要"接力"三次相似。** 拆开看每一步都很朴素：等腰给中点、双直角＋公共角给一对相似、平行＋对顶角再给一对相似。**卡住的人通常是想一步到位去凑 BF·BC**，其实应该反过来——先把 BF 老老实实算出来，再乘 BC。因地制宜，别硬凑。

#### (1) 求证：△ADE ∽ △ACB

**证明：**

因为 **AE = EC**，所以 E 是 AC 的中点，

**AC = AE + EC = 2AE** ……①

已知 **AE² = (1/2)·AD·AB**，两边同乘 2：

2AE² = AD·AB

即 **AE·(2AE) = AD·AB**，把 ① 代入：

**AE·AC = AD·AB** ……②

由 ② 得

**AD/AC = AE/AB** ……③

在 △ADE 与 △ACB 中：

- **∠A = ∠A**（公共角）
- 夹 ∠A 的两组边分别是 AD、AE 和 AC、AB，由 ③ 有 AD/AC = AE/AB

所以 **△ADE ∽ △ACB**（两边对应成比例且夹角相等），对应关系 **A↔A、D↔C、E↔B**。

**□ 证毕**

由此顺便记下两条马上要用的结论：

**∠AED = ∠ABC** ……④　（对应角相等，E↔B）

设相似比 **k = AD/AC = AE/AB** ……⑤

---

#### (2) 求证：∠DEF = ∠CBE

**思路：** F 是 AD 的中点，E 是 AC 的中点。在 (1) 的对应关系 A↔A、D↔C 下，**AD 的中点 F 正好对应 AC 的中点 E**，所以 △AFE 与 △AEB 也应当相似。先把这一步坐实。

**证明：**

因为 F 是 AD 的中点，E 是 AC 的中点：

**AF = AD/2，AE = AC/2**

于是

AF/AE = (AD/2)/(AC/2) = **AD/AC = k**（由 ⑤）

又由 ⑤ 有

AE/AB = **k**

所以

**AF/AE = AE/AB** ……⑥

在 △AFE 与 △AEB 中：

- **∠FAE = ∠EAB**（同一个角 ∠A：F 在 AD 上即在 AB 上，E 在 AC 上）
- AF/AE = AE/AB（由 ⑥）

所以 **△AFE ∽ △AEB**（两边对应成比例且夹角相等），对应关系 A↔A、F↔E、E↔B。

于是

**∠AEF = ∠ABE** ……⑦

**最后做减法。**

因为 F 是 AD 的中点，F 在线段 AD 内部，所以射线 EF 在 ∠AED 的内部：

∠DEF = ∠AED − ∠AEF

因为 E 在边 AC 上，射线 BE 在 ∠ABC 的内部：

∠CBE = ∠ABC − ∠ABE

由 ④ 有 ∠AED = ∠ABC，由 ⑦ 有 ∠AEF = ∠ABE，两式相减：

**∠DEF = ∠CBE**

**□ 证毕**

**验真除错（取一组具体数据）：**
取 AB = 8，AC = 4（则 AE = EC = 2）。由 ② AE·AC = AD·AB 得 AD = 2×4/8 = **1**，
检验原条件：AE² = 4，(1/2)AD·AB = (1/2)×1×8 = 4 ✓ 相符。
相似比 k = AD/AC = 1/4 = AE/AB = 2/8 ✓。
F 是 AD 中点 ⟹ AF = 0.5，检验 ⑥：AF/AE = 0.5/2 = 1/4，AE/AB = 2/8 = 1/4 ✓ 相等。
（再取 ∠A = 60° 具体算一遍：AD=1、AE=2 得 DE = √(1+4−2)=√3；
AF=0.5、AE=2 得 EF = √(0.25+4−1)=√3.25；AB=8、AE=2 得 BE = √(64+4−16)=√52；
则 cos∠AED = (DE²+AE²−AD²)/(2·DE·AE) = (3+4−1)/(2√3·2) = 6/(4√3)=0.866 ⟹ ∠AED=30°；
cos∠ABC = (AB²+BC²−AC²)/(2·AB·BC)，其中 BC=√(64+16−32)=√48，得 (64+48−16)/(2·8·√48)=96/110.85=0.866 ⟹ ∠ABC=30° ✓ 与 ④ 一致。）
