这份是数学 **28.2(4) 相似三角形的判定(4)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

本节仍是**直角三角形相似**，但重点从"会判"转向"会用"，尤其是**斜边直角边（HL 型）判定**的熟练运用：

> **HL 型判定**：两个直角三角形，若 **斜边与一条直角边对应成比例**，则这两个直角三角形相似。
> 写成口诀就是：**直角边比 = 斜边比**。

用它的三步固定动作（本卷十几道题几乎每题都在走）：

1. **先认斜边**：直角在哪个字母上，斜边就是不含那个字母的那条边。
2. **把乘积式改写成比例式**，并检查"直角边配直角边、斜边配斜边"有没有配反。
3. **相似之后收角**：对应角相等，往往就是题目真正要的结论（垂直、平行、角平分、某个角的度数）。

三个反复出现的坑：

- **配反**：把"直角边比 = 斜边比"写成两者互为倒数（第 1(D)、第 4 题的对照）。
- **多解**：题目写「与以点 X、Y、Z 为顶点的三角形相似」就必须分类（第 7 题两解）。
- **别忘了逆用**：本节大量题目是"给比例、求角/证垂直平行"，方向和课本例题相反（第 2、9、11 题）。

### 第 11 题

<details><summary>参考答案（可直接誊写）</summary>

在 $\mathrm{Rt}\triangle ADB$ 与 $\mathrm{Rt}\triangle DBC$ 中，

$$
\frac{AD}{DB}=\frac46=\frac23,\qquad
\frac{DB}{BC}=\frac69=\frac23.
$$

$\therefore\ \triangle ADB\sim\triangle DBC$，$\angle ADB=\angle DBC$。

$\therefore\ AD\parallel BC$。$\square$

</details>

<details><summary>详细解析</summary>

$\angle A=90^\circ$，且 $BD\perp DC$，所以 $\triangle ADB$、$\triangle DBC$ 都是直角三角形。

$$
\frac{AD}{DB}=\frac46=\frac23=\frac69=\frac{DB}{BC}.
$$

两直角三角形的一条直角边与斜边对应成比例，故 $\triangle ADB\sim\triangle DBC$。于是 $\angle ADB=\angle DBC$；这两角为内错角，所以 $AD\parallel BC$。

### 第 12 题

<details><summary>参考答案（可直接誊写）</summary>

$AD\parallel BC$，$AD\perp DC$，$\therefore\ \angle ADE=\angle ECB=90^\circ$；又 $DE=EC$。

由 $\dfrac{AE}{BE}=\dfrac{DE}{BC}$，得 $\triangle ADE\sim\triangle ECB$。

$\therefore\ \angle DAE=\angle CEB$，且 $\dfrac{AD}{DE}=\dfrac{AE}{EB}$。

$\angle AEB=180^\circ-\angle AED-\angle CEB=90^\circ$。

$\therefore\ \dfrac{AD}{AE}=\dfrac{DE}{EB}$，$\triangle ADE\sim\triangle AEB$，故 $\angle DAE=\angle EAB$。

$\therefore\ AE$ 平分 $\angle BAD$。$\square$

</details>

<details><summary>详细解析</summary>

因为 $AD\parallel BC$ 且 $AD\perp DC$，所以 $BC\perp DC$。又 $E$ 是 $CD$ 的中点，故

$$
\angle ADE=\angle ECB=90^\circ,\qquad DE=EC.
$$

已知 $\dfrac{AE}{BE}=\dfrac{DE}{BC}$，这是两直角三角形的斜边与一条直角边对应成比例，所以

$$
\triangle ADE\sim\triangle ECB.
$$

从而 $\angle DAE=\angle CEB$，并有 $\dfrac{AD}{DE}=\dfrac{AE}{EB}$。

由于 $D,E,C$ 共线，

$$
\angle AEB=180^\circ-\angle AED-\angle CEB
=180^\circ-\angle AED-\angle DAE=90^\circ.
$$

再由 $DE=EC$ 化简比例式得

$$
\frac{AD}{AE}=\frac{DE}{EB}.
$$

故在 $\triangle ADE$ 与 $\triangle AEB$ 中，两边对应成比例且夹角相等，$\triangle ADE\sim\triangle AEB$。于是 $\angle DAE=\angle EAB$，所以 $AE$ 平分 $\angle BAD$。

#### (1) 求证：BE² = ED·EC

**第一步：HL 型判相似。**

因为 BE ⊥ CD 交 CD 的延长线于 E，所以 **∠BEC = ∠BED = 90°**。

- Rt△CAD（直角在 A）：直角边 **AD、AC**，斜边 **CD**
- Rt△CEB（直角在 E）：直角边 **EB、EC**，斜边 **CB**

由已知 **AD·BC = BE·CD** 得

**AD/BE = CD/CB**

左边 AD、BE 分别是两个三角形的**直角边**，右边 CD、CB 分别是两个三角形的**斜边**，
「直角边比 = 斜边比」，由 **HL 型判定**：

**△CAD ∽ △CEB**（对应关系 **C↔C、A↔E、D↔B**）……①

**第二步：收角。**

由 ① 得

**∠ADC = ∠EBC** ……②

因为 A、D、B 三点共线（D 在 AB 上），E、D、C 三点共线（E 在 CD 的延长线上），所以 ∠ADC 与 ∠EDB 是**对顶角**：

**∠ADC = ∠EDB** ……③

由 ② ③：**∠EDB = ∠EBC** ……④

**第三步：再判一次相似。**

在 △BED 与 △CEB 中：

- ∠BED = ∠CEB（**同一个角**，因为射线 ED 与射线 EC 重合）
- ∠EDB = ∠EBC（由 ④）

所以 **△BED ∽ △CEB**（两角对应相等），对应关系 B↔C、E↔E、D↔B。

于是

BE/CE = ED/EB

**BE² = ED·EC**

**□ 证毕**

---

#### (2) 求证：AB·BC = 2CE·BE

**第一步：从 ① 再收一对角——CD 平分 ∠ACB。**

由 ① 的对应关系 A↔E、D↔B 得

**∠ACD = ∠ECB**

因为 E 在 CD 的延长线上，射线 CE 与射线 CD 重合，所以 ∠ECB 就是 ∠DCB，于是

**∠ACD = ∠DCB**，即 **CD 平分 ∠ACB** ……⑤

**第二步：补全图形——延长 BE 交 CA 的延长线于点 G。**

在 △CEG 与 △CEB 中：

- ∠GCE = ∠BCE（由 ⑤，因为射线 CG 与射线 CA 重合、射线 CE 与射线 CD 重合）
- CE = CE（公共边）
- ∠CEG = ∠CEB = 90°（BE⊥CD）

所以 **△CEG ≌ △CEB**（ASA），从而

**CG = CB**，**GE = BE**，即 **GB = 2BE** ……⑥

**第三步：最后一次相似。**

因为 ∠BAC = 90°，而 G 在 CA 的延长线上，所以 **∠GAB = 90°**。

在 △GAB 与 △GEC 中：

- ∠GAB = ∠GEC = 90°
- ∠G = ∠G（公共角）

所以 **△GAB ∽ △GEC**，于是

**AB/EC = GB/GC**

即 AB·GC = EC·GB。把 ⑥ 的 GC = CB、GB = 2BE 代入：

**AB·BC = 2CE·BE**

**□ 证毕**

---

**验真除错（建系全程回代）：** 取 A(0,0)、B(0,−4)、C(3,0)（∠A = 90°，AB = 4，AC = 3，BC = 5）。
由 ⑤，CD 平分 ∠ACB，由角平分线定理 AD/DB = CA/CB = 3/5，得 **AD = 1.5**，D(0,−1.5)。
- 检验已知条件：CD = √(9+2.25) = **3.354**，BE = ？
  E 是 B 到直线 CD 的垂足：算得 **E(−1, −2)**，BE = √(1+4) = **√5 ≈ 2.236**。
  AD·BC = 1.5×5 = **7.5**；BE·CD = 2.236×3.354 = **7.5** ✓ 条件成立。
- 检验 (1)：ED = dist((−1,−2),(0,−1.5)) = √(1+0.25) = **1.118**，EC = dist((−1,−2),(3,0)) = √(16+4) = **4.472**。
  ED·EC = 1.118×4.472 = **5** = BE² = (√5)² ✓
- 检验 (2)：AB·BC = 4×5 = **20**；2CE·BE = 2×4.472×2.236 = **20** ✓
- 顺带验 ⑥：G = (−2, 0)，GB = dist((−2,0),(0,−4)) = √20 = 4.472 = 2×2.236 ✓，CG = 5 = CB ✓

全部吻合。

**这题三步各用一次相似/全等，方向完全不同：**
> ①「HL 型」把条件翻译成相似 → ②「对顶角＋公共角」把相似转成 BE²=ED·EC → ③「角平分线＋垂线造全等」把 BE 翻倍成 BG。
**结论里出现"2"的时候，十有八九藏着一次翻倍**——中点、全等、或者等腰三角形的三线合一。见到系数就去图里找它的出处，别硬凑。

#### (1) 求证：∠ADE = ∠BDE

**第一步：由对顶角得一对相似。**

因为 BF ⊥ DE，所以 **∠BFE = 90°**；又正方形中 **∠DAE = ∠DAB = 90°**。

因为 D、E、F 三点共线，A、E、B 三点共线，所以 **∠AED 与 ∠FEB 是对顶角**：

∠AED = ∠FEB

于是 **△EAD ∽ △EFB**（两角对应相等，对应关系 **E↔E、A↔F、D↔B**），得

**EA/EF = ED/EB = AD/FB** ……①

由 ① 的前一个等号：**EA·EB = EF·ED** ……②

由 ① 的后一个等号：**AD·EB = FB·ED** ……③

**第二步：把已知条件代进去。**

由已知 **EF·BD = BE·BF** 得

**BF = EF·BD/BE**

代入 ③：

AD·EB = (EF·BD/BE)·ED = BD·(EF·ED)/BE

再由 ② 把 EF·ED 换成 EA·EB：

AD·EB = BD·(EA·EB)/BE = **BD·EA**

即

**EA/EB = AD/BD** ……④

**第三步：用角平分线定理的逆定理。**

在 △ABD 中，E 是边 AB 上一点，由 ④ 有 EA∶EB = DA∶DB，
由**角平分线定理的逆定理**，DE 平分 ∠ADB，即

**∠ADE = ∠BDE**

**□ 证毕**

---

#### (2) 求证：BG = BC + AE

设正方形的边长为 **a**，则 AD = AB = BC = a，对角线 **BD = √2·a**。

**第一步：证 BG = BD。**

正方形的对角线 BD 平分 ∠ADC，所以 **∠ADB = 45°**。
由 (1)，DE 平分 ∠ADB，所以

**∠BDG = ∠BDE = 45°/2 = 22.5°**

（G 在直线 DF 上，而 D、E、F、G 共线，故 ∠BDG = ∠BDE。）

又正方形的对角线 BD 也平分 ∠ABC，∠DBC = 45°，而 G 在 **CB 的延长线**上，所以

**∠DBG = 180° − ∠DBC = 180° − 45° = 135°**

于是在 △BDG 中：

∠BGD = 180° − ∠DBG − ∠BDG = 180° − 135° − 22.5° = **22.5° = ∠BDG**

等角对等边，得

**BG = BD = √2·a** ……⑤

**第二步：把 AE 用 a 表示。**

由 (1) 的 ④ 式：

EA/EB = AD/BD = a/(√2 a) = **1/√2**

设 AE = x，则 EB = AB − AE = a − x，代入：

x/(a − x) = 1/√2

√2·x = a − x

x(√2 + 1) = a

**AE = a/(√2 + 1) = a(√2 − 1)** ……⑥

**第三步：合并。**

由 ⑥：

BC + AE = a + a(√2 − 1) = **√2·a**

由 ⑤：**BG = √2·a**

所以

**BG = BC + AE**

**□ 证毕**

---

**验真除错（取 a = 1 建系）：** A(0,1)、B(0,0)、C(1,0)、D(1,1)。
由 ⑥ 得 AE = √2 − 1 ≈ 0.4142，故 **E(0, 2−√2) ≈ (0, 0.5858)**。
- F 是 B 到直线 DE 的垂足，算得 **F(−(√2−1)/2·... )**，数值为 **F(−0.2071, 0.5)**。
  检验已知条件：EF = dist(E,F) = √(0.0429 + 0.0073) = **0.2241**，BF = √(0.0429+0.25) = **0.5412**，
  BD = √2 = 1.4142，BE = 0.5858。
  EF·BD = 0.2241×1.4142 = **0.3169**；BE·BF = 0.5858×0.5412 = **0.3170** ✓（误差来自四舍五入）
- 检验 (1)：∠ADE 的正切 = AE/AD = 0.4142；∠BDE = ∠ADB − ∠ADE = 45° − 22.5° = 22.5°，
  而 tan22.5° = √2 − 1 = 0.4142 ✓ 两角都是 **22.5°**，相等 ✓
- 检验 (2)：直线 DE 交 x 轴（即 CB 的延长线所在直线）于 **G(−√2, 0)**，
  BG = √2 ≈ 1.4142；BC + AE = 1 + 0.4142 = **1.4142** ✓

全部吻合。

**两问的桥都是那条比例式 ④。** 第 (1) 问用它判角平分，第 (2) 问用它算 AE——**一个条件榨两次**，这是压轴题的常态。另外注意 (2) 里 BG = BD 这一步：题目要证的是"一条线段等于另两条之和"，标准套路就是**先把它转化成一条已知长度的线段**（这里靠等腰三角形），再去凑和，硬拆硬算多半算不动。
