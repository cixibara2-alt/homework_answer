这份是数学 **28.2(4) 相似三角形的判定(4)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

本节仍是**直角三角形相似**，但重点从"会判"转向"会用"，尤其是**斜边直角边（HL 型）判定**的熟练运用：

> **HL 型判定**：两个直角三角形，若 **斜边与一条直角边对应成比例**，则这两个直角三角形相似。
> 写成口诀就是：**直角边比 = 斜边比**。

用它的三步固定动作（本卷十几道题几乎每题都在走）：

1. **先认斜边**：直角在哪个字母上，斜边就是不含那个字母的那条边。
2. **把乘积式改写成比例式**，并检查"直角边配直角边、斜边配斜边"有没有配反。
3. **相似之后收角**：对应角相等，往往就是题目真正要的结论（垂直、平行、角平分、某个角的度数）。

三个反复出现的坑：

- **配反**：把"直角边比 = 斜边比"写成两者互为倒数（第 1(D)、第 4 题的对照）。
- **多解**：题目写「与以点 X、Y、Z 为顶点的三角形相似」就必须分类（第 7 题两解）。
- **别忘了逆用**：本节大量题目是"给比例、求角/证垂直平行"，方向和课本例题相反（第 2、9、11 题）。

## 01

### 第 1 题
<details><summary>提示 1</summary>
∠B = ∠P = 90°，所以 △ABC 的斜边是 AC、两直角边是 AB 和 BC；△MNP 的斜边是 MN、两直角边是 MP 和 PN。先把每个选项里给的边一一贴上"斜边"或"直角边"的标签。
</details>
<details><summary>提示 2</summary>
(A) 是角的条件，(B) 是"两直角边"，(C) 是"一直角边＋斜边"，都能判。剩下那个选项给的是**一个三角形的两条直角边 ＋ 另一个三角形的一条直角边和斜边**——先把缺的那条边用勾股定理补出来，再比三边，看比不比得上。
</details>
<details><summary>完整解析</summary>

**答案：D**

∠B = 90° ⟹ △ABC 中 **AB、BC 是直角边，AC 是斜边**；
∠P = 90° ⟹ △MNP 中 **MP、PN 是直角边，MN 是斜边**。

**(A) ∠A = 47°，∠M = 43°　—— 能判定**

∠C = 90° − 47° = 43°，∠N = 90° − 43° = 47°。
两个三角形的三个角都是 47°、43°、90°，由 **AA** 得相似（A↔N、C↔M、B↔P）✓

**(B) AB = 4，BC = 6，MP = 6，PN = 9　—— 能判定**

两组都是**直角边**：AB/MP = 4/6 = 2/3，BC/PN = 6/9 = 2/3，
两直角边对应成比例、夹角都是 90°，由 **SAS 相似**得相似 ✓

**(C) AB = 4，AC = 6，PN = 6，MN = 9　—— 能判定**

AB、PN 是直角边，AC、MN 是斜边：
AB/PN = 4/6 = 2/3，AC/MN = 6/9 = 2/3，
**直角边比 = 斜边比**，由 **HL 型判定**得相似 ✓

**(D) AB = 4，BC = 6，MP = 6，MN = 9　—— 不能判定**

给的是 △ABC 的**两条直角边**和 △MNP 的**一条直角边 MP 与斜边 MN**。先补齐：

AC = √(4² + 6²) = √52 = **2√13** ≈ 7.21
PN = √(9² − 6²) = √45 = **3√5** ≈ 6.71

△ABC 三边（从小到大）：4、6、2√13 ≈ 4、6、7.21
△MNP 三边（从小到大）：3√5、6、9 ≈ 6.71、6、9 → 排序后 6、6.71、9

比一比：6/4 = 1.5，6.71/6 ≈ 1.12，9/7.21 ≈ 1.25，**三个比值互不相等**，两三角形**不相似** ✗

选 **D**。

**为什么 (D) 看着像却不行？** 因为 4∶6 与 6∶9 虽然都等于 2∶3，但 4、6 是 △ABC 的**两条直角边**，而 6、9 是 △MNP 的**一条直角边和斜边**——身份根本对不上。**直角三角形的题，第一件事永远是先给每条边贴标签**，不贴标签就下手，就是数学坑人。
</details>

<details><summary>提示 1</summary>

**(A) ∠A = ∠BCD　—— 能推出**

在 Rt△ACD 中：∠A + ∠ACD = 90°。
若 ∠A = ∠BCD，则 ∠BCD + ∠ACD = 90°，即

**∠ACB = 90°** ✓

**(B) CD/AD = BD/CD　—— 能推出**

即 **CD² = AD·BD**。在 △ACD 与 △CBD 中：

- ∠ADC = ∠CDB = 90°
- AD/CD = CD/BD（夹直角的两组边成比例）

由 **SAS 相似**得 △ACD ∽ △CBD，于是 ∠ACD = ∠CBD = ∠B。
又在 Rt△BCD 中 ∠B + ∠BCD = 90°，所以

∠ACB = ∠ACD + ∠BCD = ∠B + ∠BCD = **90°** ✓

**(C) AC/BC = CD/BD　—— 能推出**

设 AD = m，BD = n，CD = h，则 AC = √(m²+h²)，BC = √(n²+h²)。代入条件：

√(m²+h²)/√(n²+h²) = h/n

两边平方并交叉相乘：n²(m²+h²) = h²(n²+h²)

m²n² + n²h² = h²n² + h⁴

**m²n² = h⁴**，即 **h² = mn**，也就是 **CD² = AD·BD**

回到 (B) 的情形，同样能推出 **∠ACB = 90°** ✓

**(D) AC/BC = AD/BD　—— 不能推出**

同样代入：

√(m²+h²)/√(n²+h²) = m/n

n²(m²+h²) = m²(n²+h²)

m²n² + n²h² = m²n² + m²h²

n²h² = m²h² ⟹ **m = n**，即 **AD = BD**

这只说明 D 是 AB 的中点，于是 CD 既是高又是中线，△ABC 是**等腰三角形**（CA = CB）——但它可以是任意形状的等腰三角形，**顶角完全不必是 90°** ✗

选 **D**。

**(D) 其实是角平分线定理的样子。** AC/BC = AD/BD 正是"CD 平分 ∠ACB"的条件；再加上 CD⊥AB，就是"角平分线与高重合"，结论只能是**等腰**（三线合一），推不出直角。看到这个比例式条件反射去想"直角"，就是刻舟求剑。
</details>

<details><summary>提示 1</summary>

</details>

**第一步：识别 HL 型相似。**

PA ⊥ AB ⟹ Rt△APB 中，**AP、AB 是直角边，BP 是斜边**；
DP ⊥ BC ⟹ Rt△PDC 中，**PD、PC 是直角边，DC 是斜边**。

条件 **AP/PD = BP/CD** 恰好是「直角边比 = 斜边比」，由 **HL 型判定**：

**△APB ∽ △PDC**（对应关系 A↔P、P↔D、B↔C）

**第二步：收角，发现 △ABC 是等腰三角形。**

由相似得 ∠ABP = ∠PCD。而 P 在 BC 上、D 在 AC 上，所以

∠ABP = ∠ABC，　∠PCD = ∠ACB

于是 **∠ABC = ∠ACB**，△ABC 是等腰三角形，

**AC = AB = 3**

从而 **AD = AC − DC = 3 − 2 = 1**。

**第三步：再找一对相似，求 AP。**

由相似还得 ∠APB = ∠PDC。

在 P 点拼平角（B、P、C 共线）：∠APB + ∠APD + ∠DPC = 180°，而 ∠DPC = 90°，所以

**∠APB + ∠APD = 90°**

在 Rt△PDC 中两锐角互余：∠PDC + ∠PCD = 90°，而 ∠APB = ∠PDC，所以

**∠APB + ∠PCD = 90°**

两式相减得

**∠APD = ∠PCD = ∠ACP**

在 △APD 与 △ACP 中：

- ∠A = ∠A（公共角，D 在 AC 上）
- ∠APD = ∠ACP

所以 **△APD ∽ △ACP**，于是

AP/AC = AD/AP，即 **AP² = AD·AC = 1 × 3 = 3**

**AP = √3**，选 **B**。

**验真除错（建系核对）：** 以 P 为原点、BC 为 x 轴，可算出
B(−2√3, 0)、C(√3, 0)、D(0, 1)、A(−√3/2, 3/2)。
则 AB = √((2√3−√3/2)² + (3/2)²) = √(27/4 + 9/4) = 3 ✓，AC = 3 ✓，
DC = √(3+1) = 2 ✓，AP = √(3/4 + 9/4) = √3 ✓，
且 AP·AB 方向点积 = 0（PA⊥AB）✓，D 确实在 AC 上 ✓。全部条件自洽。

**这题的钥匙是第二步。** 一条"对应角相等"就把一个看似陌生的图变成了等腰三角形，AC 立刻变成已知数。**相似判出来只是半程，把对应角/对应边收干净才是全程**，很多人证完相似就停手，白白丢掉 AC = 3 这个关键量。

**第一步：贴标签。**

∠C = 90°，且 D 在 BC 上，所以 ∠ACD = ∠ACB = 90°，两个三角形共用这个直角。

- △ABC：直角边 **AC、BC**，斜边 **AB**
- △DAC：直角边 **AC、DC**，斜边 **DA**

**第二步：HL 型判定。**

条件 **AB/DA = BC/AC** 中，AB、DA 是两个三角形的**斜边**，BC、AC 是两个三角形的**直角边**，恰好是「斜边比 = 直角边比」，所以

**△ABC ∽ △DAC**（对应关系 **A↔D、B↔A、C↔C**）

**第三步：收角。**

由 A↔D 得

**∠ADC = ∠BAC = 90° − ∠B = 90° − 35° = 55°**

**验真除错（取 AC = 1）：** ∠B = 35° ⟹ BC = 1/tan35° ≈ 1.428，AB = 1/sin35° ≈ 1.743。
若 ∠ADC = 55°，则 ∠DAC = 35°，DC = tan35° ≈ 0.700，DA = 1/cos35° ≈ 1.221。
检验条件：AB/DA ≈ 1.743/1.221 = 1.428，BC/AC = 1.428/1 = 1.428 ✓ 完全吻合。

**为什么不是另一种对应？** 若配成 A↔A、B↔D（即 △ABC ∽ △ADC），相似比是 AC/AC = 1，两三角形全等，D 就与 B 重合了，此时条件变成 BC = AC，即 ∠B = 45°，与 ∠B = 35° 矛盾。所以对应关系唯一。
</details>

### 第 5 题
<details><summary>提示 1</summary>

</details>

**第一步：在 Rt△ACD 中用勾股定理。**（∠ACD = 90°，AD 是斜边）

AD² = AC² + CD²

已知 **AD = 3AC**，代入：

(3AC)² = AC² + CD²

9AC² = AC² + CD²

**CD² = 8AC²**，即 **CD = 2√2·AC**

**第二步：把 BC 用 AC 表示。**

已知 **CD = 3BC**，所以

BC = CD/3 = (2√2/3)·AC，　**BC² = (8/9)AC²**

**第三步：在 Rt△ABC 中用勾股定理。**（∠ABC = 90°，AC 是斜边）

AC² = AB² + BC²

AB² = AC² − (8/9)AC² = **(1/9)AC²**

**AB = (1/3)AC**

**第四步：求比值。**

AD : AB = 3AC : (1/3)AC = 3 ÷ (1/3) = **9**

**验一下（取 AC = 3）：** AD = 9，CD = 6√2 ≈ 8.485，BC = 2√2 ≈ 2.828，AB = 1。
检验 Rt△ACD：9² = 81，3² + (6√2)² = 9 + 72 = 81 ✓
检验 Rt△ABC：3² = 9，1² + (2√2)² = 1 + 8 = 9 ✓
AD : AB = 9 : 1 ✓

**这题看着像相似，其实是两次勾股。** 两个直角三角形只共用一个顶点 A 和一条边 AC，条件也全是"某边是另一边的 3 倍"这种同一三角形内部的关系，**根本没有相似可判**。因地制宜——见到直角三角形先别急着找相似，勾股定理往往更快。
</details>

由 D↔C 得

∠ADB = ∠DCB = **65°**

在 Rt△DBC 中，两锐角互余：

**∠DBC = 90° − ∠DCB = 90° − 65° = 25°**

**验一下：** 由相似还得 ∠ABD = ∠DBC = 25°，而在 Rt△ABD 中 ∠ABD + ∠ADB = 25° + 65° = 90° ✓ 完全自洽。

**顺带看出一个结构：** ∠ABD = ∠DBC 说明 **BD 平分 ∠ABC**。「一条线段的平方等于夹它的两条边之积」这种条件，最后往往都会翻译成"角平分""垂直"或"某三点共线"这类几何结论——**乘积式是相似的伪装，相似的结论是角**，这条链子要背熟。
</details>

### 第 7 题
<details><summary>提示 1</summary>
∠ABC = 90° ⟹ △ABC 中 AC 是斜边，先用勾股定理补出 AB。∠CDB = 90° ⟹ △CDB 中 **CB 是斜边**（注意不是 CD！），BD、DC 是直角边。
</details>
<details><summary>提示 2</summary>
两个直角分别在 B 和 D 上，所以 **B 必须对应 D**。剩下 A、C 去配 C、B，有**两种**配法，各解一次。两个答案都要检查"直角边 < 斜边"。答案是两个分母为 5 的分数。

**第一步：补出 AB。**

∠ABC = 90° ⟹ AC 是 △ABC 的斜边：

AB = √(AC² − BC²) = √(25 − 9) = **4**

**第二步：分清 △CDB 的斜边。**

∠CDB = 90° ⟹ **CB 是 △CDB 的斜边**（= 3），BD、DC 是直角边。

两个直角分别在 **B** 与 **D** 上，所以 **B 必须对应 D**；剩下的 A、C 与 C、B 有两种配法。

**情况一：△ABC ∽ △CDB**（A↔C、B↔D、C↔B）

相似比 = 斜边之比 = AC/CB = 5/3。

BC/DB = 5/3 ⟹ **DB = 3 × 3/5 = 9/5**

（此时 CD = AB×3/5 = 12/5，检验 (9/5)² + (12/5)² = (81+144)/25 = 9 = CB² ✓）

**情况二：△ABC ∽ △BDC**（A↔B、B↔D、C↔C）

相似比 = 斜边之比 = AC/BC = 5/3。

AB/BD = 5/3 ⟹ **BD = 4 × 3/5 = 12/5**

（此时 DC = BC×3/5 = 9/5，检验 (12/5)² + (9/5)² = 9 = BC² ✓）

---

**综上：BD = 9/5 或 12/5。**

**两个答案的几何意义：** 两种情况其实是同一个直角三角形 CDB（三边 9/5、12/5、3，正好是 3∶4∶5 的 3/5 倍）的**两种摆法**——把直角边 9/5 和 12/5 对调一下位置。题目说「与以点 **C、D、B** 为顶点的三角形相似」而没写死顺序，两种摆法都算数。**又是"以…为顶点"就分类**，本册第四次出现了。
