这份是数学 **28.2(1) 相似三角形的判定(1)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这是第 28 章相似形的核心一节。整节只靠两把钥匙，先记牢：

> **① 判定（怎么证相似）**：两角对应相等 → 两三角形相似（**AA**）。本节全部题目都只用这一条。
> **② 性质（证完能干什么）**：相似三角形**对应边成比例**，用来求线段长、证乘积式。

判相似的三个「找角」套路，本卷反复出现：
1. **公共角**：两个三角形共用顶点 A 处的角（第 3、8、13 题）。
2. **对顶角**：两条线交于一点，交点处那对角相等（第 7 题）。
3. **同角的余角相等**：直角＋直角，用「∠1+∠2=90°，∠1+∠3=90° ⟹ ∠2=∠3」导角（第 6、9、11 题的一线三垂直模型）。

两个最容易翻车的坑：

- **写对应关系别乱写**。「△ABC ∽ △DEF」这行字本身就在说 A↔D、B↔E、C↔F，比例式必须按这个顺序抄，抄错就全错（第 3 题四个选项就是拿这个挖坑）。
- **相似不唯一时要分类**。题目只说"与某三角形相似"、没指明对应顶点的，一般有**两解**（第 13 题）。

## 01

### 第 1 题
<details><summary>完整解析</summary>

**答案：C**

相似 = **对应角相等 且 对应边成比例**，也就是「形状完全一样，只是大小可以不同」。逐个看：

- (A) 两个等腰三角形：顶角可以一个 20°、一个 100°，形状差得远。**不一定相似**。
- (B) 两个菱形：四条边都相等保证了边成比例，但角不一定——一个可以是正方形（90°），另一个可以是 60° 的菱形。**不一定相似**。
- (C) 两个正方形：四个角都是 90°（对应角必相等），四条边都相等（对应边比就是边长之比，必成比例）。**一定相似** ✓
- (D) 两个等腰梯形：上下底之比可以完全不同，**不一定相似**。

选 **C**。

**规律记一下：** 「一定相似」的图形只有三类——**所有的正多边形（同边数）、所有的圆、所有的等边三角形/正方形**。凡是形状里还留着一个可以自由变的量（腰与底之比、菱形的角、梯形的上下底之比），就一定不相似。
</details>

### 第 2 题
<details><summary>完整解析</summary>

**答案：D**

相似比就是对应边的比值，链式传递时**相乘**（不是相加）。

设 △A₂B₂C₂ 的边长为 1。

- △A₁B₁C₁ 与 △A₂B₂C₂ 的相似比为 2 ⟹ △A₁B₁C₁ 的对应边 = 2。
- △A₂B₂C₂ 与 △A₃B₃C₃ 的相似比为 4 ⟹ 1 : (△A₃B₃C₃ 的边) = 4，即 △A₃B₃C₃ 的对应边 = 1/4。

所以

△A₁B₁C₁ : △A₃B₃C₃ = 2 : (1/4) = **8**

选 **D**。

**提醒：** 选 (C) 6 的同学是把 2 和 4 加起来了——相似比是**比值**不是长度，比值的传递永远是乘法：k₁₃ = k₁₂ × k₂₃ = 2×4 = 8。
</details>

在 △ACD 与 △ABC 中：

- ∠A = ∠A（**公共角**）
- ∠ACD = ∠B（已知）

所以 **△ACD ∽ △ABC**（两角对应相等）。

对应关系是 **A↔A、C↔B、D↔C**，于是对应边成比例：

**AC/AB = CD/BC = AD/AC**

把这三个比值两两拆开重组，得到的正确等式有：

- AC² = AB·AD（由 AC/AB = AD/AC）
- AC/CD = AB/BC（由 AC/AB = CD/BC 交换内项）
- **DC/AD = CB/AC**（由 CD/BC = AD/AC 交换内项）← 就是选项 (B)

选 **B**。

**逐个排除：**
- (A) AC/CD = AB/AC：右边分母该是 BC 不是 AC，错。
- (C) AD/CD = CD/BD：这在说 CD²=AD·BD，那是「AB 边上的高」才有的关系，本题 CD 不是高，错。
- (D) DC/CA = AC/BC：这在说 AC²=DC·BC，而真正成立的是 AC²=AB·AD，错。

**走过路过不要错过：** 「△ACD ∽ △ABC」这一行字的字母顺序就是比例式的说明书，写比例时把两行字上下对齐抄，一个字母都不会错：
```
△A C D
△A B C
```

### 第 4 题
<details><summary>完整解析</summary>

**答案：35°**

相似三角形**对应角相等**，所以两个三角形的三个内角是同一套数，只是分给了不同的顶点。

先把第一个三角形的三个角配齐：

第三个角 = 180° − 65° − 80° = **35°**

三个角是 35°、65°、80°，最小的是 **35°**。另一个三角形的三个角跟它完全一样，所以最小内角也是 **35°**。

**提醒：** 这题问的是「另一个三角形」，但相似的两个三角形角是共享的，根本不用管谁是谁。真正的坑是漏算第三个角、直接把 65° 当最小的报上去。
</details>

**准备工作。** A(4,0)、B(0,3)，所以 OA=4、OB=3，AB=√(16+9)=5。C 是 AB 中点：

**C(2, 3/2)**，且 CA = CB = 5/2。

△AOB 是直角三角形，∠AOB=90°。P 在 y 轴上，而 y 轴正是直线 OB，所以直线 CP 只能从「OB 所在直线」上的一点出发穿过三角形，切出来的三角形只有两种可能。

---

**情况一：切出的是含 B 的 △BPC（此时 P 在线段 OB 上）。**

△BPC 与 △BOA 共用 ∠B，只要再有一个角相等即可。∠ABO ≈ 53°、∠BAO ≈ 37°，都不是 90°，所以直角只能落在 P 或 C 上，且必须与 △BOA 的直角顶点 O 对应：

- 若 ∠BPC = 90°：PC ⊥ y 轴，即 PC ∥ x 轴，P 与 C 纵坐标相同 ⟹ **P(0, 3/2)**。
  验证：BP = 3 − 3/2 = 3/2，BC = 5/2，BO = 3，BA = 5，
  BP/BO = (3/2)/3 = 1/2，BC/BA = (5/2)/5 = 1/2 ✓ 相似比 1:2，成立。
- 若 ∠BCP = 90°：则 BC/BO = BP/BA，BP = BA·BC/BO = 5×(5/2)/3 = 25/6 ≈ 4.17 > BO = 3，
  P 跑到 O 的下方去了，与"P 在线段 OB 上"矛盾，此情况并入下面的情况二。

**情况二：切出的是含 A 的三角形（P 在 y 轴负半轴，直线 CP 交 OA 于 Q，切出 △ACQ）。**

△ACQ 与 △AOB 共用 ∠A，直角必须落在 C 或 Q 上：

- 若 ∠AQC = 90°：CQ ⊥ x 轴，则 CQ 是竖直线 x = 2，与 y 轴平行，永远交不到 y 轴，**P 不存在**，舍去。
- 若 ∠ACQ = 90°：即 **CP ⊥ AB**。
  直线 AB 的斜率 k = (3−0)/(0−4) = −3/4，所以 CP 的斜率为 4/3。
  过 C(2, 3/2) 且斜率 4/3 的直线：y − 3/2 = (4/3)(x − 2)。
  令 x = 0：y = 3/2 − 8/3 = 9/6 − 16/6 = **−7/6** ⟹ **P(0, −7/6)**。
  验证它确实截到了三角形：令 y=0 得 x = 7/8 ∈ (0,4)，即 Q(7/8, 0) 在边 OA 上 ✓，
  此时 △ACQ 中 ∠A 公共、∠ACQ = ∠AOB = 90°，所以 △ACQ ∽ △AOB ✓。

---

综上，**P 的坐标是 (0, 3/2) 或 (0, −7/6)**。

**这题的坑就在「两解」。** 题目只说"用直线 CP 截 △AOB"，没说 P 在哪一段上；只要直线（不是线段）能截出一个相似的三角形就算数。**数形结合**——把两条线都画到图上，一眼就看出来是两条不同的截线。
</details>

**第 1 对：△ADC ∽ △CEB（一线三垂直模型）**

∠ADC = ∠CEB = 90°。又因为 D、C、E 三点共线，

∠ACD + ∠BCE = 180° − ∠ACB = 180° − 90° = 90°，

而在 Rt△ADC 中 ∠ACD + ∠DAC = 90°，

两式相减得 **∠DAC = ∠BCE**。

于是 **△ADC ∽ △CEB**（两角对应相等）。✓

**第 2 对：△ADF ∽ △ACB**

∠ADF = 90°（AD⊥DE，F 在 DE 上），∠ACB = 90°，所以 ∠ADF = ∠ACB；

又 ∠FAD = ∠BAC（已知）。

于是 **△ADF ∽ △ACB**（两角对应相等）。✓

**为什么只有 2 对——把图里的三角形数干净。**

图中真正连了线的线段是：AD、AF、AC、AB、CB、BE 和底边 DFCE。据此，图里一共只有 **5 个**三角形（BF、BD、AE 都没连，△AFB、△BCF 之类并不存在）：

| 三角形 | 三个内角 |
|---|---|
| △ADF | 90°，∠DAF=β，90°−β |
| △ADC | 90°，∠DAC=α，90°−α |
| △AFC | **钝角** 90°+β，α−β，90°−α |
| △ACB | 90°，∠BAC=β，90°−β |
| △CEB | 90°，∠BCE=α，90°−α |

（记 α=∠DAC，β=∠BAC=∠DAF。）

两两对照：**△ADF 与 △ACB 同角组**（第 2 对），**△ADC 与 △CEB 同角组**（第 1 对）；△AFC 带一个钝角，跟四个直角三角形都不可能相似；而 α 与 β 一般并不相等（也不互余），所以 △ADF 与 △ADC 这两组之间不相似。

- ∠ACB = ∠DCE（**对顶角**）

等腰梯形**同一底上的两个底角相等**，AD 是上底，所以

∠BAD = ∠ADC

又因为点 E 在边 CD 上，射线 DE 与射线 DC 是同一条射线，

**∠ADE = ∠ADC = ∠BAD** ……①

又已知 **∠EAD = ∠ABD** ……②

由 ① ②，两角对应相等，

**∴ △ADE ∽ △BAD**（对应关系 A↔B、D↔A、E↔D）。

**□ 证毕**

---

#### (2) 求 y 关于 x 的表达式及 x 的取值范围

**第一步：由 (1) 的相似写比例。**

△ADE ∽ △BAD，相似比

k = AD/BA = 6/8 = 3/4

对应边成比例：

**AD/BA = DE/AD = AE/BD**

- 由 DE/AD = 3/4 得 **DE = 6 × 3/4 = 9/2**（定值，与 x 无关——E 在 CD 上的位置是固定的，且 9/2 < 8 = CD，E 确实在边上）
- 由 AE/BD = 3/4 得 **AE = (3/4)x**

**第二步：求 AF（再找一对相似）。**

在 △DAF 与 △DBA 中（F 在 BD 上，所以 ∠ADF 与 ∠ADB 是同一个角）：

- ∠ADF = ∠BDA（公共角）
- ∠DAF = ∠DAE = ∠ABD = ∠DBA（已知条件）

所以 **△DAF ∽ △DBA**，对应关系 D↔D、A↔B、F↔A。

DA/DB = DF/DA = AF/BA

- 由 DA/DB = DF/DA 得 **DA² = DB·DF**，即 36 = x·DF，**DF = 36/x**
- 由 DA/DB = AF/BA 得 **AF = BA·DA/DB = 8×6/x = 48/x**

**第三步：写出 y。**

因为 F 是 AE 与 BD 的交点，F 在线段 AE 上，

**y = EF = AE − AF = (3/4)x − 48/x**

**第四步：求 x 的取值范围。**

设 BC = b，过 D 作 DH ⊥ BC 于 H。由等腰梯形的对称性：

CH = (b − 6)/2，　BH = BC − CH = (b + 6)/2

在 Rt△DHC 中：DH² = CD² − CH² = 64 − ((b−6)/2)²

在 Rt△DHB 中：

x² = BD² = BH² + DH² = ((b+6)/2)² + 64 − ((b−6)/2)²

((b+6)² − (b−6)²)/4 = 24b/4 = 6b

**∴ x² = 6b + 64**，即 **b = (x² − 64)/6**

梯形存在的条件：

- AD < BC ⟹ b > 6 ⟹ x² > 100 ⟹ x > 10
- 高 DH > 0 ⟹ ((b−6)/2)² < 64 ⟹ b < 22 ⟹ x² < 196 ⟹ x < 14

**∴ y = (3/4)x − 48/x（10 < x < 14）**

（顺带检验：x > 10 时 (3/4)x − 48/x > 7.5 − 4.8 > 0，y 恒为正，符合"长度"的身份。）

#### (3) 当 BF = 9 时，求 BC

由 (2) 的第二步，DF = 36/x，而 F 在线段 BD 上，

BF = BD − DF = x − 36/x = 9

两边同乘 x（x > 0）：

x² − 9x − 36 = 0

十字相乘：(x − 12)(x + 3) = 0

x = 12 或 x = −3（舍去，长度为正）

**x = BD = 12**，且 10 < 12 < 14 ✓ 在取值范围内。

代入 (2) 的关系式 b = (x² − 64)/6：

BC = (144 − 64)/6 = 80/6 = **40/3**

**验真除错（把这组数全部回代）：**
BC = 40/3 时，CH = (40/3 − 6)/2 = 11/3，DH = √(64 − 121/9) = √455/3；
BD² = ((40/3+6)/2)² + 455/9 = (29/3)² + 455/9 = (841 + 455)/9 = 1296/9 = 144，**BD = 12** ✓；
DF = 36/12 = 3，**BF = 12 − 3 = 9** ✓；
AE = (3/4)×12 = 9，AF = 48/12 = 4，**EF = 5**（也可由 y 的表达式：9 − 4 = 5）✓。
全部自洽。

**本题的两个关键动作：**
1. **(1) 里的"等腰梯形底角相等"是白送的第二对角**，很多人只盯着题给的 ∠EAD=∠ABD 那一对，找不到第二对就卡住了——AD∥BC 加 AB=CD 就是在提醒你用等腰梯形的性质。
2. **(2) 里 DA²=DB·DF 这个"共角共边"结构**（∠ADB 公共、DA 既是 △DAF 的边又是 △DBA 的边）是本章的高频模型，见到「一个角公共 + 一条边被两个三角形共用」，立刻往 **共用边² = 另两条边之积** 上想。
