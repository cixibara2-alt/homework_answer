这份是数学 **28.2(1) 相似三角形的判定(1)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这是第 28 章相似形的核心一节。整节只靠两把钥匙，先记牢：

> **① 判定（怎么证相似）**：两角对应相等 → 两三角形相似（**AA**）。本节全部题目都只用这一条。
> **② 性质（证完能干什么）**：相似三角形**对应边成比例**，用来求线段长、证乘积式。

判相似的三个「找角」套路，本卷反复出现：
1. **公共角**：两个三角形共用顶点 A 处的角（第 3、8、13 题）。
2. **对顶角**：两条线交于一点，交点处那对角相等（第 7 题）。
3. **同角的余角相等**：直角＋直角，用「∠1+∠2=90°，∠1+∠3=90° ⟹ ∠2=∠3」导角（第 6、9、11 题的一线三垂直模型）。

两个最容易翻车的坑：

- **写对应关系别乱写**。「△ABC ∽ △DEF」这行字本身就在说 A↔D、B↔E、C↔F，比例式必须按这个顺序抄，抄错就全错（第 3 题四个选项就是拿这个挖坑）。
- **相似不唯一时要分类**。题目只说"与某三角形相似"、没指明对应顶点的，一般有**两解**（第 13 题）。

### 第 9 题
<details><summary>提示 1</summary>
先把正方形的边长算出来——CQ 和 DQ 都在 CD 上。然后盯住 ∠AQP=90° 这个条件：∠AQD 和 ∠PQC 分别与它拼成一条平角，能得到什么关系？
</details>
<details><summary>提示 2</summary>

**第一步：求边长。**

Q 在边 CD 上，DQ = 2，CQ = 1，所以正方形的边长

**BC = CD = DQ + CQ = 2 + 1 = 3**

**第二步：证相似（同角的余角相等）。**

∠D = ∠C = 90°（正方形的内角）。

因为 D、Q、C 三点共线，且 PQ ⊥ AQ 即 ∠AQP = 90°，所以

∠AQD + ∠PQC = 180° − ∠AQP = 90°

又在 Rt△ADQ 中：∠AQD + ∠DAQ = 90°

两式相减得 **∠DAQ = ∠PQC**。

于是 **△ADQ ∽ △QCP**（两角对应相等），对应关系 **A↔Q、D↔C、Q↔P**。

**第三步：算 CP，再算 BP。**

AD/QC = DQ/CP

3/1 = 2/CP

CP = 2/3

**BP = BC − CP = 3 − 2/3 = 9/3 − 2/3 = 7/3**

**验真除错（用坐标验算一遍）：** 设 B(0,0)、C(3,0)、D(3,3)、A(0,3)，则 Q(3,1)、P(7/3, 0)。
向量 QA = (−3, 2)，QP = (7/3 − 3, −1) = (−2/3, −1)，
点积 = (−3)(−2/3) + 2×(−1) = 2 − 2 = 0 ✓ 确实 AQ ⊥ QP，答案正确。

**这题的模型名字叫「一线三垂直」**：DC 是一条直线，D、Q、C 处各有一个直角（∠D、∠AQP、∠C），只要见到这个结构，两端的两个直角三角形必相似。第 6 题、第 11 题都是它的变形，走过路过不要错过。
</details>

<details><summary>提示 1</summary>
两个条件各管一个三角形。先用 ∠CAD=∠B：△CAD 和 △CBA 有一个公共角 ∠C，凑成相似后能算出 CD，进而算出 BD。

**第一步：用 ∠CAD = ∠B，求 CD。**

在 △CAD 与 △CBA 中：

- ∠C = ∠C（公共角）
- ∠CAD = ∠CBA（已知）

所以 **△CAD ∽ △CBA**，对应关系 C↔C、A↔B、D↔A。

CA/CB = CD/CA，即 **CA² = CB·CD**

4² = 8·CD ⟹ **CD = 2**

于是 **BD = BC − CD = 8 − 2 = 6**。

**第二步：用 ∠DEB = ∠C，求 DE。**

在 △BED 与 △BCA 中：

- ∠B = ∠B（公共角）
- ∠BED = ∠BCA（已知）

所以 **△BED ∽ △BCA**，对应关系 B↔B、E↔C、D↔A。

DE/AC = BD/BA

DE/4 = 6/10 = 3/5

**DE = 4 × 3/5 = 12/5 = 2.4**

**顺带一提：** 同一个比例链里还能白送 BE = BC × 3/5 = 4.8，所以 AE = 10 − 4.8 = 5.2，跟图上 E 的位置（略偏右）正好对得上。**买一个相似送一串线段**，别只算题目问的那一条就收工。

**易错点：** 第二步的对应关系是 E↔C、D↔A，所以 DE 对应的是 **AC**（不是 BC）。如果写成 DE/BC = BD/BA 就会算出 4.8，是典型的对应边配错。
</details>

### 第 11 题
<details><summary>提示 1</summary>
两个三角形里各有一个现成的直角（AD⊥BC 给的），先把这一对角配上。再找第二对角——注意 ∠BAC=90° 被 AD 分成了 ∠BAD 和 ∠DAC 两块。
</details>
<details><summary>提示 2</summary>
在 Rt△ABD 里 ∠B 与 ∠BAD 互余；而 ∠BAD 与 ∠DAC 也互余（合起来是 ∠BAC=90°）。同角的余角相等，就得到要的第二对角了。写结论时按 △ABD ∽ △CAD 的字母顺序核对：B 对应 A、A 对应 C。
</details>

**证明：**

因为 AD ⊥ BC（垂足为 D），

所以 **∠ADB = ∠CDA = 90°** ……①

在 Rt△ABD 中，两锐角互余：

∠B + ∠BAD = 90° ……②

又因为 ∠BAC = 90°，而 AD 在 ∠BAC 内部（D 在 BC 上），

∠BAD + ∠DAC = ∠BAC = 90° ……③

由 ② ③ 得（同角 ∠BAD 的余角相等）：

**∠B = ∠DAC** ……④

由 ① ④，两角对应相等，

**∴ △ABD ∽ △CAD**（两角对应相等，两三角形相似）。

**□ 证毕**

**对应关系一定要核**：△ABD ∽ △CAD 说的是 A↔C、B↔A、D↔D，也就是
∠BAD=∠ACD、∠B=∠CAD、∠ADB=∠CDA。写成「△ABD ∽ △ACD」就把 A↔A、B↔C 配错了，是本题最常见的失分点。

**顺带记住这个模型的三个乘积式**（直角三角形斜边上的高，俗称「射影定理」，本题之后经常用）：
- AD² = BD·CD （由 △ABD ∽ △CAD）
- AB² = BD·BC （由 △ABD ∽ △CBA）
- AC² = CD·CB （由 △CAD ∽ △CBA）
</details>

**分析：** 要证 AB·AE = AC·AD，等价于证比例式

AB/AC = AD/AE

左边两条边（AB、AD）都在 △ABD 里，右边两条边（AC、AE）都在 △ACE 里，所以只要证 **△ABD ∽ △ACE**。

**证明：**

因为 BD ⊥ AC 于点 D，所以 **∠ADB = 90°**；

因为 CE ⊥ AB 于点 E，所以 **∠AEC = 90°**。

所以 ∠ADB = ∠AEC。

又 ∠BAD = ∠CAE（**公共角** ∠A）。

所以 **△ABD ∽ △ACE**（两角对应相等），对应关系 A↔A、B↔C、D↔E。

于是对应边成比例：

AB/AC = AD/AE

由比例的基本性质（内项之积等于外项之积）：

**AB·AE = AC·AD**

**□ 证毕**

**为什么题目要"连接 DE"？** 因为上面刚证出 AD/AE = AB/AC，把它倒一下写成

**AD/AB = AE/AC**

再加上 ∠A 是公共角，由「两边对应成比例且夹角相等」可得 **△ADE ∽ △ABC**——这就是所谓的「**母子相似的第二型**」。本题只问了乘积式，但 DE 这条线是给下一节（判定 2）留的伏笔，顺手记住这个结论，后面直接用。
</details>

### 第 13 题
<details><summary>提示 1</summary>
先把 AB 补齐：AB = AD + BD。题目说的是「△AED 与**以 A、B、C 为顶点的三角形**相似」——注意它没说是「△ABC」，也就是没告诉你 E 对应 B 还是对应 C。
</details>
<details><summary>提示 2</summary>
∠A 是两个三角形的公共角，所以 A 只能对应 A。剩下 E、D 两个顶点去配 B、C 两个顶点，有**两种**配法，各写一个比例式解一次。
</details>
<details><summary>提示 3</summary>
两种配法分别是 AE/AB = AD/AC 和 AE/AC = AD/AB。两个答案都要检验 AE ≤ AC = 2（E 必须落在边 AC 上），检验完会发现两个都留得下。答案一个大于 1、一个小于 1。

（橙色实线为情况一的 DE₁，蓝色虚线为情况二的 DE₂。）

**准备：** AB = AD + BD = 1 + 2 = **3**，AC = 2，AD = 1。

△AED 与 △ABC 有**公共角 ∠A**（∠EAD 与 ∠BAC 是同一个角），所以对应顶点里 **A 必须对应 A**。剩下的 E、D 去配 B、C，有两种配法：

---

**情况一：△AED ∽ △ABC**（E↔B，D↔C）

AE/AB = AD/AC

AE/3 = 1/2

**AE = 3/2**

检验：AE = 1.5 ≤ AC = 2 ✓，E 在边 AC 上，成立。

**情况二：△AED ∽ △ACB**（E↔C，D↔B）

AE/AC = AD/AB

AE/2 = 1/3

**AE = 2/3**

检验：AE = 2/3 ≈ 0.67 ≤ AC = 2 ✓，E 在边 AC 上，成立。

---

综上，**AE = 3/2 或 AE = 2/3**。

**这就是本节的头号陷阱。** 题目写「△AED 与以点 A、B、C 为顶点的三角形相似」而不是「△AED ∽ △ABC」，就是在明说**对应顶点没定死**。凡是看到这种措辞（还有"与某三角形相似"、"存在点 P 使…相似"），一律先分类，再逐个检验点是否落在指定的边上。只写一个答案是刻舟求剑——上次那道题恰好只有一解，这次可不一样。

**注意情况二里 DE₂ 的样子**：此时 ∠ADE = ∠C，DE 与 BC **不**平行；而情况一里 ∠AED = ∠B，DE 也不平行于 BC。两种都不是"截得平行线"的情形，别把 DE∥BC 的比例式（AD/AB = AE/AC）硬套进来——那样会算出 AE = 2/3 却把理由说错。
</details>

#### (1) 求证：△ADE ∽ △BAD

因为 AD∥BC，AB = CD，且 AD < BC（即 AD 与 BC 不相等，ABCD 不是平行四边形），

所以 **四边形 ABCD 是等腰梯形**。

等腰梯形**同一底上的两个底角相等**，AD 是上底，所以

∠BAD = ∠ADC

又因为点 E 在边 CD 上，射线 DE 与射线 DC 是同一条射线，

**∠ADE = ∠ADC = ∠BAD** ……①

又已知 **∠EAD = ∠ABD** ……②

由 ① ②，两角对应相等，

**∴ △ADE ∽ △BAD**（对应关系 A↔B、D↔A、E↔D）。

**□ 证毕**

#### (2) 求 y 关于 x 的表达式及 x 的取值范围

**第一步：由 (1) 的相似写比例。**

△ADE ∽ △BAD，相似比

k = AD/BA = 6/8 = 3/4

对应边成比例：

**AD/BA = DE/AD = AE/BD**

- 由 DE/AD = 3/4 得 **DE = 6 × 3/4 = 9/2**（定值，与 x 无关——E 在 CD 上的位置是固定的，且 9/2 < 8 = CD，E 确实在边上）
- 由 AE/BD = 3/4 得 **AE = (3/4)x**

**第二步：求 AF（再找一对相似）。**

在 △DAF 与 △DBA 中（F 在 BD 上，所以 ∠ADF 与 ∠ADB 是同一个角）：

- ∠ADF = ∠BDA（公共角）
- ∠DAF = ∠DAE = ∠ABD = ∠DBA（已知条件）

所以 **△DAF ∽ △DBA**，对应关系 D↔D、A↔B、F↔A。

DA/DB = DF/DA = AF/BA

- 由 DA/DB = DF/DA 得 **DA² = DB·DF**，即 36 = x·DF，**DF = 36/x**
- 由 DA/DB = AF/BA 得 **AF = BA·DA/DB = 8×6/x = 48/x**

**第三步：写出 y。**

因为 F 是 AE 与 BD 的交点，F 在线段 AE 上，

**y = EF = AE − AF = (3/4)x − 48/x**

**第四步：求 x 的取值范围。**

设 BC = b，过 D 作 DH ⊥ BC 于 H。由等腰梯形的对称性：

CH = (b − 6)/2，　BH = BC − CH = (b + 6)/2

在 Rt△DHC 中：DH² = CD² − CH² = 64 − ((b−6)/2)²

在 Rt△DHB 中：

x² = BD² = BH² + DH² = ((b+6)/2)² + 64 − ((b−6)/2)²

((b+6)² − (b−6)²)/4 = 24b/4 = 6b

**∴ x² = 6b + 64**，即 **b = (x² − 64)/6**

梯形存在的条件：

- AD < BC ⟹ b > 6 ⟹ x² > 100 ⟹ x > 10
- 高 DH > 0 ⟹ ((b−6)/2)² < 64 ⟹ b < 22 ⟹ x² < 196 ⟹ x < 14

**∴ y = (3/4)x − 48/x（10 < x < 14）**

（顺带检验：x > 10 时 (3/4)x − 48/x > 7.5 − 4.8 > 0，y 恒为正，符合"长度"的身份。）

#### (3) 当 BF = 9 时，求 BC

由 (2) 的第二步，DF = 36/x，而 F 在线段 BD 上，

BF = BD − DF = x − 36/x = 9

两边同乘 x（x > 0）：

x² − 9x − 36 = 0

十字相乘：(x − 12)(x + 3) = 0

x = 12 或 x = −3（舍去，长度为正）

**x = BD = 12**，且 10 < 12 < 14 ✓ 在取值范围内。

代入 (2) 的关系式 b = (x² − 64)/6：

BC = (144 − 64)/6 = 80/6 = **40/3**

**验真除错（把这组数全部回代）：**
BC = 40/3 时，CH = (40/3 − 6)/2 = 11/3，DH = √(64 − 121/9) = √455/3；
BD² = ((40/3+6)/2)² + 455/9 = (29/3)² + 455/9 = (841 + 455)/9 = 1296/9 = 144，**BD = 12** ✓；
DF = 36/12 = 3，**BF = 12 − 3 = 9** ✓；
AE = (3/4)×12 = 9，AF = 48/12 = 4，**EF = 5**（也可由 y 的表达式：9 − 4 = 5）✓。
全部自洽。

**本题的两个关键动作：**
1. **(1) 里的"等腰梯形底角相等"是白送的第二对角**，很多人只盯着题给的 ∠EAD=∠ABD 那一对，找不到第二对就卡住了——AD∥BC 加 AB=CD 就是在提醒你用等腰梯形的性质。
2. **(2) 里 DA²=DB·DF 这个"共角共边"结构**（∠ADB 公共、DA 既是 △DAF 的边又是 △DBA 的边）是本章的高频模型，见到「一个角公共 + 一条边被两个三角形共用」，立刻往 **共用边² = 另两条边之积** 上想。
