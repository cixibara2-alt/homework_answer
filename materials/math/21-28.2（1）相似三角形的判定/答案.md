这份是数学 **28.2(1) 相似三角形的判定(1)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

这是第 28 章相似形的核心一节。整节只靠两把钥匙，先记牢：

> **① 判定（怎么证相似）**：两角对应相等 → 两三角形相似（**AA**）。本节全部题目都只用这一条。
> **② 性质（证完能干什么）**：相似三角形**对应边成比例**，用来求线段长、证乘积式。

判相似的三个「找角」套路，本卷反复出现：
1. **公共角**：两个三角形共用顶点 A 处的角（第 3、8、13 题）。
2. **对顶角**：两条线交于一点，交点处那对角相等（第 7 题）。
3. **同角的余角相等**：直角＋直角，用「∠1+∠2=90°，∠1+∠3=90° ⟹ ∠2=∠3」导角（第 6、9、11 题的一线三垂直模型）。

两个最容易翻车的坑：

- **写对应关系别乱写**。「△ABC ∽ △DEF」这行字本身就在说 A↔D、B↔E、C↔F，比例式必须按这个顺序抄，抄错就全错（第 3 题四个选项就是拿这个挖坑）。
- **相似不唯一时要分类**。题目只说"与某三角形相似"、没指明对应顶点的，一般有**两解**（第 13 题）。

### 第 11 题

<details><summary>参考答案（可直接誊写）</summary>

$AD\perp BC$，故 $\angle ADB=\angle CDA=90^\circ$。

在 $\mathrm{Rt}\triangle ABD$ 中，$\angle B+\angle BAD=90^\circ$；又 $\angle BAC=90^\circ$，故 $\angle BAD+\angle DAC=90^\circ$。

$\therefore\angle B=\angle DAC$，从而 $\triangle ABD\sim\triangle CAD$。$\square$

</details>

<details><summary>详细解析</summary>

$AD$ 是斜边 $BC$ 上的高，所以 $\triangle ABD$ 与 $\triangle CAD$ 在 $D$ 处各有一个直角。为了找到第二对对应角，比较两个互余关系：

$$
\angle B+\angle BAD=90^\circ,\qquad
\angle BAD+\angle DAC=\angle BAC=90^\circ.
$$

两式有共同的 $\angle BAD$，故 $\angle B=\angle DAC$。两角分别对应相等，因此 $\triangle ABD\sim\triangle CAD$，对应关系 $A\leftrightarrow C$、$B\leftrightarrow A$、$D\leftrightarrow D$。图中 $AD$ 把原三角形在 $A$ 处的直角分成两个角，正好形成这组余角关系。

### 第 12 题

<details><summary>参考答案（可直接誊写）</summary>

$BD\perp AC$、$CE\perp AB$，故 $\angle ADB=\angle AEC=90^\circ$。

又 $\angle BAD=\angle CAE$，故 $\triangle ABD\sim\triangle ACE$。

$\therefore\dfrac{AB}{AC}=\dfrac{AD}{AE}$，即 $AB\cdot AE=AC\cdot AD$。$\square$

</details>

<details><summary>详细解析</summary>

$D$ 在 $AC$ 上且 $BD\perp AC$，故 $\angle ADB=90^\circ$；$E$ 在 $AB$ 上且 $CE\perp AB$，故 $\angle AEC=90^\circ$。两个三角形还有公共的 $\angle A$，所以 $\triangle ABD\sim\triangle ACE$，对应关系为 $A\leftrightarrow A$、$B\leftrightarrow C$、$D\leftrightarrow E$。

按照这一对应关系，$AB$ 对应 $AC$，$AD$ 对应 $AE$，于是

$$
\frac{AB}{AC}=\frac{AD}{AE}
\quad\Longrightarrow\quad
AB\cdot AE=AC\cdot AD.
$$

### 第 13 题
<details><summary>提示 1</summary>
先把 AB 补齐：AB = AD + BD。题目说的是「△AED 与**以 A、B、C 为顶点的三角形**相似」——注意它没说是「△ABC」，也就是没告诉你 E 对应 B 还是对应 C。
</details>
<details><summary>提示 2</summary>
∠A 是两个三角形的公共角，所以 A 只能对应 A。剩下 E、D 两个顶点去配 B、C 两个顶点，有**两种**配法，各写一个比例式解一次。
</details>
<details><summary>提示 3</summary>
两种配法分别是 AE/AB = AD/AC 和 AE/AC = AD/AB。两个答案都要检验 AE ≤ AC = 2（E 必须落在边 AC 上），检验完会发现两个都留得下。答案一个大于 1、一个小于 1。
</details>

**准备：** AB = AD + BD = 1 + 2 = **3**，AC = 2，AD = 1。

△AED 与 △ABC 有**公共角 ∠A**（∠EAD 与 ∠BAC 是同一个角），所以对应顶点里 **A 必须对应 A**。剩下的 E、D 去配 B、C，有两种配法：

---

**情况一：△AED ∽ △ABC**（E↔B，D↔C）

AE/AB = AD/AC

AE/3 = 1/2

**AE = 3/2**

检验：AE = 1.5 ≤ AC = 2 ✓，E 在边 AC 上，成立。

**情况二：△AED ∽ △ACB**（E↔C，D↔B）

AE/AC = AD/AB

AE/2 = 1/3

**AE = 2/3**

检验：AE = 2/3 ≈ 0.67 ≤ AC = 2 ✓，E 在边 AC 上，成立。

---

综上，**AE = 3/2 或 AE = 2/3**。

**这就是本节的头号陷阱。** 题目写「△AED 与以点 A、B、C 为顶点的三角形相似」而不是「△AED ∽ △ABC」，就是在明说**对应顶点没定死**。凡是看到这种措辞（还有"与某三角形相似"、"存在点 P 使…相似"），一律先分类，再逐个检验点是否落在指定的边上。只写一个答案是刻舟求剑——上次那道题恰好只有一解，这次可不一样。

**注意情况二里 DE₂ 的样子**：此时 ∠ADE = ∠C，DE 与 BC **不**平行；而情况一里 ∠AED = ∠B，DE 也不平行于 BC。两种都不是"截得平行线"的情形，别把 DE∥BC 的比例式（AD/AB = AE/AC）硬套进来——那样会算出 AE = 2/3 却把理由说错。
</details>

</details>
<details><summary>提示 2</summary>
第 (2) 问：由 (1) 的相似写出三组对应边的比，相似比是 AD∶BA = 6∶8。注意 AE 和 DE 分别对应哪条边——其中 DE 竟然是个跟 x 无关的定值，AE 则是 x 的一次式。
</details>
<details><summary>提示 3</summary>

</details>
<details><summary>提示 4</summary>

</details>

#### (1) 求证：△ADE ∽ △BAD

因为 AD∥BC，AB = CD，且 AD < BC（即 AD 与 BC 不相等，ABCD 不是平行四边形），

所以 **四边形 ABCD 是等腰梯形**。

等腰梯形**同一底上的两个底角相等**，AD 是上底，所以

∠BAD = ∠ADC

又因为点 E 在边 CD 上，射线 DE 与射线 DC 是同一条射线，

**∠ADE = ∠ADC = ∠BAD** ……①

又已知 **∠EAD = ∠ABD** ……②

由 ① ②，两角对应相等，

**∴ △ADE ∽ △BAD**（对应关系 A↔B、D↔A、E↔D）。

**□ 证毕**

---

#### (2) 求 y 关于 x 的表达式及 x 的取值范围

**第一步：由 (1) 的相似写比例。**

△ADE ∽ △BAD，相似比

k = AD/BA = 6/8 = 3/4

对应边成比例：

**AD/BA = DE/AD = AE/BD**

- 由 DE/AD = 3/4 得 **DE = 6 × 3/4 = 9/2**（定值，与 x 无关——E 在 CD 上的位置是固定的，且 9/2 < 8 = CD，E 确实在边上）
- 由 AE/BD = 3/4 得 **AE = (3/4)x**

**第二步：求 AF（再找一对相似）。**

在 △DAF 与 △DBA 中（F 在 BD 上，所以 ∠ADF 与 ∠ADB 是同一个角）：

- ∠ADF = ∠BDA（公共角）
- ∠DAF = ∠DAE = ∠ABD = ∠DBA（已知条件）

所以 **△DAF ∽ △DBA**，对应关系 D↔D、A↔B、F↔A。

DA/DB = DF/DA = AF/BA

- 由 DA/DB = DF/DA 得 **DA² = DB·DF**，即 36 = x·DF，**DF = 36/x**
- 由 DA/DB = AF/BA 得 **AF = BA·DA/DB = 8×6/x = 48/x**

**第三步：写出 y。**

因为 F 是 AE 与 BD 的交点，F 在线段 AE 上，

**y = EF = AE − AF = (3/4)x − 48/x**

**第四步：求 x 的取值范围。**

设 BC = b，过 D 作 DH ⊥ BC 于 H。由等腰梯形的对称性：

CH = (b − 6)/2，　BH = BC − CH = (b + 6)/2

在 Rt△DHC 中：DH² = CD² − CH² = 64 − ((b−6)/2)²

在 Rt△DHB 中：

x² = BD² = BH² + DH² = ((b+6)/2)² + 64 − ((b−6)/2)²

((b+6)² − (b−6)²)/4 = 24b/4 = 6b

**∴ x² = 6b + 64**，即 **b = (x² − 64)/6**

梯形存在的条件：

- AD < BC ⟹ b > 6 ⟹ x² > 100 ⟹ x > 10
- 高 DH > 0 ⟹ ((b−6)/2)² < 64 ⟹ b < 22 ⟹ x² < 196 ⟹ x < 14

**∴ y = (3/4)x − 48/x（10 < x < 14）**

（顺带检验：x > 10 时 (3/4)x − 48/x > 7.5 − 4.8 > 0，y 恒为正，符合"长度"的身份。）

---

#### (3) 当 BF = 9 时，求 BC

由 (2) 的第二步，DF = 36/x，而 F 在线段 BD 上，

BF = BD − DF = x − 36/x = 9

两边同乘 x（x > 0）：

x² − 9x − 36 = 0

十字相乘：(x − 12)(x + 3) = 0

x = 12 或 x = −3（舍去，长度为正）

**x = BD = 12**，且 10 < 12 < 14 ✓ 在取值范围内。

代入 (2) 的关系式 b = (x² − 64)/6：

BC = (144 − 64)/6 = 80/6 = **40/3**

**验真除错（把这组数全部回代）：**
BC = 40/3 时，CH = (40/3 − 6)/2 = 11/3，DH = √(64 − 121/9) = √455/3；
BD² = ((40/3+6)/2)² + 455/9 = (29/3)² + 455/9 = (841 + 455)/9 = 1296/9 = 144，**BD = 12** ✓；
DF = 36/12 = 3，**BF = 12 − 3 = 9** ✓；
AE = (3/4)×12 = 9，AF = 48/12 = 4，**EF = 5**（也可由 y 的表达式：9 − 4 = 5）✓。
全部自洽。

**本题的两个关键动作：**
1. **(1) 里的"等腰梯形底角相等"是白送的第二对角**，很多人只盯着题给的 ∠EAD=∠ABD 那一对，找不到第二对就卡住了——AD∥BC 加 AB=CD 就是在提醒你用等腰梯形的性质。
2. **(2) 里 DA²=DB·DF 这个"共角共边"结构**（∠ADB 公共、DA 既是 △DAF 的边又是 △DBA 的边）是本章的高频模型，见到「一个角公共 + 一条边被两个三角形共用」，立刻往 **共用边² = 另两条边之积** 上想。
</details>
