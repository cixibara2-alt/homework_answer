这份是数学 **28.2(2) 相似三角形的判定(2)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

上一节（判定 1）只有一把钥匙 AA，这一节把另外两把补齐，从此判定相似有三条路：

> **① AA**：两角对应相等。
> **② SAS 相似**：**两边对应成比例且它们的夹角相等**。注意是**夹角**——角必须夹在这两条边中间，边角边的顺序错了就不成立。
> **③ SSS 相似**：三边对应成比例。

怎么选？看题目给了什么：

- 给的是**角**（平行、垂直、公共角、对顶角）→ 走 AA。
- 给的是**一个角 + 两条边（或一个乘积式/比例式）**→ 走 SAS，先把乘积式改写成比例式，再检查那个角是不是夹角（第 3、4、9、10、12 题）。
- 给的是**三组边**或能算出三条边 → 走 SSS（第 1、7、13(2) 题）。

本卷反复挖的三个坑：

1. **对应关系不唯一就要分类**。题目写成「与以点 X、Y、Z 为顶点的三角形相似」而不是写死 △XYZ，就是在明说有多解（第 9、10 题各有 2 个、3 个答案）。
2. **动点题必须写取值范围**，而范围来自「点还在边上」这个几何约束（第 8 题）。
3. **乘积式 ⇄ 比例式的改写方向**要对准你想用的那两个三角形（第 11、12 题）。

### 第 1 题
<details><summary>完整解析</summary>

**答案：C**

「假命题」= 说错了的那一句。逐条检验：

- **(A) 顶角相等的两个等腰三角形相似** —— 真。顶角相等，两个底角 = (180°−顶角)/2 也就跟着相等，AA 成立。
- **(B) 有一个底角相等的两个等腰三角形相似** —— 真。底角相等，则两个三角形的两个底角都相等（等腰三角形两底角相等），AA 成立。
- **(C) 有一个角相等的两个等腰三角形相似** —— **假**。这里的「一个角」没说是顶角还是底角，可以一个用顶角、另一个用底角。
  **反例：** 甲是顶角 60° 的等腰三角形（其实是等边三角形，三角均 60°），乙是底角 60°… 这还是等边。换一个更干脆的：甲的顶角为 100°、底角 40°；乙的顶角为 40°、底角 70°。两者都有一个 40° 的角，但甲的三个角是 100°、40°、40°，乙的是 40°、70°、70°，显然不相似。
- **(D) 腰长与底边长对应成比例的两个等腰三角形相似** —— 真。等腰三角形两腰相等，所以「腰∶腰 = 底∶底」就意味着三边对应成比例，**SSS 相似**成立。

选 **C**。

**一句话记住：** 等腰三角形里，**顶角和底角地位不同**。只说"有一个角相等"而不指明是顶角还是底角，就一定不能判相似——这是本节最经典的一个假命题。
</details>

**第一步：把六条边都补齐。**

△ABC 中 ∠A = 90°，所以 **BC 是斜边**：AB = 3，BC = 4，

AC = √(BC² − AB²) = √(16 − 9) = **√7**

△DEF 中 ∠F = 90°，所以 **DE 是斜边**：DE = 8，DF = 6，

EF = √(DE² − DF²) = √(64 − 36) = √28 = **2√7**

**第二步：验证三边对应成比例。**

把两个三角形的边按「直角边、直角边、斜边」摆好：

| △ABC | AB = 3 | AC = √7 | BC = 4（斜边）|
|---|---|---|---|
| △FDE | FD = 6 | FE = 2√7 | DE = 8（斜边）|

6/3 = 2，　2√7/√7 = 2，　8/4 = 2

三组比都等于 2，由 **SSS** 得 **△ABC ∽ △FDE**，对应关系 **A↔F、B↔D、C↔E**。

**第三步：找 ∠E 对应谁。**

C↔E，所以 **∠E = ∠C**。

在 Rt△ABC 中，∠A = 90°，两锐角互余：

∠C = 90° − ∠B ≈ 90° − 41° = **49°**

选 **C**。

**这题的坑在"字母顺序"。** 看到 △ABC 和 △DEF 就下意识配成 A↔D、B↔E、C↔F 的同学，会直接答 41°（选 A）。**直角三角形先认斜边**：∠A 与 ∠F 是那两个直角，它们必须对应，字母顺序在这里完全不作数。

已知 **∠BAC = ∠ADE**，这是 △ABC 的 ∠A 与 △ADE 的 ∠D。要用 **SAS 相似**补条件，必须让**夹这两个角的两组边**对应成比例：

- 在 △ABC 中，夹 ∠BAC 的两条边是 **AB、AC**；
- 在 △ADE 中，夹 ∠ADE 的两条边是 **DA、DE**。

所以要补的条件形如

AB/DA = AC/DE　或　AB/DE = AC/DA

**逐项检验：**

- **(A) AC/AD = AB/AE**：出现了 AE，而 AE 是 △ADE 中 ∠D 的**对边**，不是夹边。✗
- **(B) AC/AD = BC/DE**：出现了 BC，是 △ABC 中 ∠A 的**对边**。✗
- **(C) AC/AD = AB/DE**：把它交叉相乘得 AC·DE = AD·AB，也就是 **AB/DE = AC/AD** —— 正好是上面第二种，AB 配 DE、AC 配 DA，两条都是夹边。✓
  此时得到 **△ABC ∽ △DEA**（A↔D、B↔E、C↔A）。
- **(D) AC/AD = BC/AE**：BC 与 AE 都是对边，两个都不是夹边。✗

选 **C**。

**走过路过不要错过：** SAS 相似的「S-A-S」三个字母是有顺序的——**边、夹角、边**。判断一个比例式合不合格，只要问一句：这两条边是不是都从那个角的顶点出发？只要有一条不是，立刻淘汰。

### 第 4 题
<details><summary>提示 1</summary>
题目写死了 △ABC ∽ △DEF，对应关系已经定了：A↔D、B↔E、C↔F，**没有第二解**。
</details>
<details><summary>提示 2</summary>
∠B = ∠E 是那对相等的夹角，夹它的边在 △ABC 里是 BA 和 BC，在 △DEF 里是 ED 和 EF。按这个配对写一个比例式解 DE。答案是个整数。
</details>
<details><summary>完整解析</summary>

**答案：DE = 3**

题目已经把相似写成 **△ABC ∽ △DEF**，对应关系锁死：**A↔D、B↔E、C↔F**。

已知 ∠B = ∠E，这正是两个三角形中的一对对应角。夹这对角的边分别是：

- △ABC 中：**BA = 6** 与 **BC = 8**
- △DEF 中：**ED = ?** 与 **EF = 4**

由 SAS 相似的要求：

BA/ED = BC/EF

6/DE = 8/4 = 2

**DE = 3**

**验一下：** DE = 3、EF = 4，与 AB = 6、BC = 8 的比都是 1∶2，夹角 ∠E = ∠B，SAS 成立 ✓。

**易错点：** 有人会写成 AB/DE = BC/EF 之外的配法（比如 AB/EF = BC/DE），解出 DE = 16/3。那是把 B 的两条夹边交叉配了——**△ABC ∽ △DEF 这行字已经规定 A 只能对 D**，所以 AB 只能对 DE。题目没写「以 D、E、F 为顶点的三角形」，就没有分类的余地。
</details>

△ACD 与 △ABC 有**公共角 ∠A**（∠CAD 与 ∠BAC 是同一个角）。

要让它们相似，只能是 **△ACD ∽ △ABC**（A↔A、C↔B、D↔C）。夹 ∠A 的两组边分别是：

- △ACD：**AC** 与 **AD**
- △ABC：**AB** 与 **AC**

由 SAS 相似：

AC/AB = AD/AC

即

**AD/AC = AC/AB**，也就是 **AC² = AD·AB**

**为什么只有一个答案？** 另一种配法是 A↔A、C↔C、D↔B，那要求 AC/AC = AD/AB，即相似比为 1，两个三角形全等，D 与 B 重合——D 就不在 AB 的内部了，不合题意。所以本题只有一解，跟第 9、10 题的"多解"要区分开。

**这个模型叫「共角共边」**：两个三角形共用 ∠A，且 **AC 既是 △ACD 的边、又是 △ABC 的边**。结论永远是「**共用边的平方 = 另两条边之积**」。上一节第 14 题的 DA²=DB·DF 也是它，走过路过不要错过。
</details>

设每个小正方形的边长为 **1**，则 AB = BC = CD = 1，AE = 1，AD = EH = 3。

**第一步：∠ABE = 45°。**

在 △ABE 中，∠BAE = 90°（正方形的角），AB = AE = 1，是**等腰直角三角形**，

所以 **∠ABE = 45°**。

**第二步：把 ∠ACE 搬到 E 点。**

矩形 ADHE 中 **AD ∥ EH**，CE 是截线，由内错角相等：

**∠ACE = ∠CEH**

**第三步：把 ∠ADE 也搬到 E 点（本题的关键一步，用 SAS 相似）。**

在 △BEC 与 △BDE 中（注意 C 在线段 BD 上，所以 ∠EBC 与 ∠EBD 是**同一个角**）：

- ∠EBC = ∠EBD（公共角）
- BE² = AB² + AE² = 1 + 1 = 2，而 BC·BD = 1 × 2 = 2，所以 **BE² = BC·BD**，即

  **BE/BD = BC/BE**

由 **SAS 相似**得 **△BEC ∽ △BDE**（B↔B、E↔D、C↔E）。

所以 **∠BEC = ∠BDE**。而 A、B、C、D 共线，射线 DB 与射线 DA 是同一条射线，故 ∠BDE = ∠ADE，即

**∠ADE = ∠BEC**

**第四步：三个角在 E 点拼起来。**

由第二、三步：

∠ACE + ∠ADE = ∠CEH + ∠BEC

而射线 EC 在 ∠BEH 内部（EH 与 EF 是同一条射线方向），所以

∠CEH + ∠BEC = ∠BEH = ∠BEF

在等腰直角三角形 BFE 中（BF = FE = 1，∠BFE = 90°），**∠BEF = 45°**。

于是 ∠ACE + ∠ADE = 45°。

**最后合计：**

∠ABE + ∠ACE + ∠ADE = 45° + 45° = **90°**

**验真除错（数值核对）：** 以 E 为原点建系，A(0,1)、B(1,1)、C(2,1)、D(3,1)。
∠ABE = 45°；∠ACE 的正切 = AE/AC = 1/2，约 26.57°；∠ADE 的正切 = AE/AD = 1/3，约 18.43°。
45° + 26.57° + 18.43° = **90°** ✓ 与推理结果一致。

**这题为什么放在"判定 2"这一节？** 因为把 ∠ADE 搬家的那一步（BE² = BC·BD）正是本节的 **SAS 相似**——一个公共角加上"共用边的平方等于另两边之积"。纯靠 AA 是搬不动这个角的。

<details><summary>提示 1</summary>

<details><summary>提示 2</summary>
△DEF 已知的两条边 √3、√6 之间的比是多少？它只能对上 △ABC 三条边里的哪一对？对上之后，第三条边（也就是最长边）用同一个相似比一算就出来了。答案是个整数。

<details><summary>完整解析</summary>

**答案：3**

**第一步：把 △ABC 三边的比化简。**

√5 ∶ √10 ∶ √15 = √5 ∶ √5·√2 ∶ √5·√3 = **1 ∶ √2 ∶ √3**

**第二步：看 △DEF 已知两边的比。**

√6/√3 = √2

所以这两条边的比是 **1 ∶ √2**——在 △ABC 的比例串 1 ∶ √2 ∶ √3 里，只有**前两项**能对上（若对上 1∶√3 则比值应是 √3，若对上 √2∶√3 则比值应是 √(3/2)，都不是 √2）。

所以 **√3 对应 √5，√6 对应 √10**，相似比

k = √3/√5

**第三步：算最长边。**

最长边对应 √15：

最长边 = √15 × √3/√5 = √(15×3/5) = √9 = **3**

**检验：** △DEF 三边为 √3、√6、3，比值 √3 ∶ √6 ∶ 3 = 1 ∶ √2 ∶ √3 ✓ 与 △ABC 完全一致；且 3 > √6 ≈ 2.45 > √3 ≈ 1.73，3 确实是最长边 ✓。

**为什么可以断定 3 是最长边而不是 √6？** 因为若 √6 是最长边，那么第三条边要比 √6 小，此时已知的两条边 √3、√6 就分别是最短边和最长边，比值应为 √3——但实际是 √2，矛盾。**先定位，再计算**，别上来就假设第三条边最短。

### 第 8 题
<details><summary>提示 1</summary>
△APE ∽ △ACB 是写死的对应关系：A↔A、P↔C、E↔B。照这个写比例式，用 x 把 AP 表示出来（注意 x 是 BP 不是 AP），再解出 AE 关于 x 的式子。
</details>
<details><summary>提示 2</summary>
范围来自两个几何约束：**P 要在边 AB 上**（AP>0）、**E 要在边 AC 上**（0<AE≤6，E 可以恰好落在 C 点）。把 AE 的表达式代进 AE≤6 解不等式，就得到 x 的下界；上界来自 AP>0。
</details>

#### (2) 求证：△APQ ∽ △AQD

**第一步：先证 ∠AQP = 90°。**

由 (1)，△ADQ ∽ △QCP，所以

**∠AQD = ∠QPC**

而在 Rt△QCP 中，两锐角互余：

∠QPC + ∠PQC = 90°

代入得

**∠AQD + ∠PQC = 90°**

因为 D、Q、C 三点共线（Q 在边 DC 上），

∠AQP = 180° − ∠AQD − ∠PQC = 180° − 90° = **90°**

所以 **∠AQP = ∠ADQ = 90°** ……①

**第二步：再证夹这两个直角的边成比例。**

由 (1) 的相似比为 2∶1，对应边 AQ 与 QP 也满足

**AQ/QP = 2**

而

**AD/DQ = 4a/2a = 2**

所以

**AQ/AD = QP/DQ** ……②

**第三步：SAS 收工。**

在 △AQP 与 △ADQ 中，由 ① ②：

- ∠AQP = ∠ADQ = 90°
- AQ/AD = QP/DQ

所以 **△AQP ∽ △ADQ**，即 **△APQ ∽ △AQD**。

**□ 证毕**

---

**另一种证法（SSS，硬算三条边）：** 用勾股定理

- AQ = √(AD² + DQ²) = √(16a² + 4a²) = **2√5 a**
- PQ = √(QC² + CP²) = √(4a² + a²) = **√5 a**
- AP = √(AB² + BP²) = √(16a² + 9a²) = **5a**

于是

AP/AQ = 5a/(2√5 a) = **√5/2**，　PQ/QD = √5a/(2a) = **√5/2**，　AQ/AD = 2√5a/(4a) = **√5/2**

三组边的比都是 √5/2，由 **SSS** 得 △APQ ∽ △AQD ✓ 与上面的结果一致。

**两种证法的取舍：** SSS 那条路要开三次根号，属于死算协会的走法；借第 (1) 问的结论走 SAS，一个根号都不用开。**做多问题时，前一问的结论就是后一问的工具**，别做完 (1) 就把它扔了。
</details>

**准备（把 DE∥BC 榨干）。** 因为 DE ∥ BC，由平行线分线段成比例（或 △ADE ∽ △ABC）：

**AD/AB = AE/AC = DE/BC** ……(*)

由 (*) 的前一个等号得 **AE = AC·AD/AB**，代入已知的 AD² = AE·AC：

AD² = (AC·AD/AB)·AC

AD²·AB = AC²·AD

两边同除以 AD（AD > 0）：

**AC² = AD·AB** ……(**)

---

#### (1) 求证：△BCD ∽ △CDE

**第一对角：** 因为 DE ∥ BC，DC 是截线，由**内错角**相等：

**∠BCD = ∠CDE** ……①

**第一条比例链（用 (**)）：** 由 AC² = AD·AB 得

AC/AB = AD/AC

在 △ACD 与 △ABC 中，∠A 为公共角，且夹 ∠A 的两组边满足上式，由 **SAS 相似**：

**△ACD ∽ △ABC**（A↔A、C↔B、D↔C）

所以对应边成比例：

CD/BC = AC/AB，即 **BC/CD = AB/AC** ……②

**第二条比例链（用已知 AD²=AE·AC）：** 由 AD² = AE·AC 得

AD/AC = AE/AD

在 △ADE 与 △ACD 中，∠A 为公共角，且夹 ∠A 的两组边满足上式，由 **SAS 相似**：

**△ADE ∽ △ACD**（A↔A、D↔C、E↔D）

所以对应边成比例：

DE/CD = AD/AC，即 **CD/DE = AC/AD** ……③

**把两条链接起来。** 由 (**) 有 AC² = AD·AB，即

**AB/AC = AC/AD** ……④

由 ②、④、③ 依次相等：

BC/CD = AB/AC = AC/AD = CD/DE

即

**BC/CD = CD/DE** ……⑤

**收工。** 在 △BCD 与 △CDE 中，由 ① ⑤：

- ∠BCD = ∠CDE（夹角相等）
- CB/DC = CD/DE（夹这对角的两组边成比例：∠BCD 的夹边是 CB、CD，∠CDE 的夹边是 DC、DE）

所以 **△BCD ∽ △CDE**（两边对应成比例且夹角相等）。

**□ 证毕**

---

#### (2) 求证：CD²/BC² = AD/AB

由 (1) 的 ⑤ 式 BC/CD = CD/DE，交叉相乘得

**CD² = BC·DE**

两边同除以 BC²：

CD²/BC² = (BC·DE)/BC² = **DE/BC**

再由准备工作中的 (*)：DE/BC = AD/AB。

所以

**CD²/BC² = AD/AB**

**□ 证毕**

---

**验真除错（取一组具体数据全程回代）：**
取 AB = 8，AC = 4。由 (**) AC² = AD·AB 得 AD = 16/8 = **2**，于是 k = AD/AB = 1/4。
由 (*) 得 AE = AC·k = 1，检验已知条件：AD² = 4，AE·AC = 1×4 = 4 ✓。
再取 BC = 12，则 DE = BC·k = **3**；由 ② CD = BC·AC/AB = 12×4/8 = **6**。
检验 (1)：BC/CD = 12/6 = 2，CD/DE = 6/3 = 2 ✓ 相等。
检验 (2)：CD²/BC² = 36/144 = 1/4，AD/AB = 2/8 = 1/4 ✓ 相等。
（顺带核一下三角形是否存在：AB=8、AC=4、BC=12 时 8+4=12 恰好共线，是退化情形，说明 BC 不能取 12；改取 BC = 9，则 DE = 9/4、CD = 9×4/8 = 4.5，
BC/CD = 2、CD/DE = 4.5/2.25 = 2 ✓，CD²/BC² = 20.25/81 = 1/4 = AD/AB ✓，结论不受影响——
因为 ②③ 两条比例链都只依赖 (*) 与 (**)，与 BC 的具体取值无关。）

**这题的骨架就一句话：** DE∥BC 给「比」，AD²=AE·AC 给「共角共边」，两者合起来把 **AB、AC、AD** 三条线段串成一条等比链 AB∶AC = AC∶AD，再顺势把 **BC、CD、DE** 也串成同样比值的等比链 BC∶CD = CD∶DE。**看见 x²=yz 就想比例中项，看见比例中项就想共角共边**，这一节的题基本都是这一招的变形。
