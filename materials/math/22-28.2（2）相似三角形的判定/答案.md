这份是数学 **28.2(2) 相似三角形的判定(2)**，共 3 页：选择题 1~3、填空题 4~10、解答题 11~14。

上一节（判定 1）只有一把钥匙 AA，这一节把另外两把补齐，从此判定相似有三条路：

> **① AA**：两角对应相等。
> **② SAS 相似**：**两边对应成比例且它们的夹角相等**。注意是**夹角**——角必须夹在这两条边中间，边角边的顺序错了就不成立。
> **③ SSS 相似**：三边对应成比例。

怎么选？看题目给了什么：

- 给的是**角**（平行、垂直、公共角、对顶角）→ 走 AA。
- 给的是**一个角 + 两条边（或一个乘积式/比例式）**→ 走 SAS，先把乘积式改写成比例式，再检查那个角是不是夹角（第 3、4、9、10、12 题）。
- 给的是**三组边**或能算出三条边 → 走 SSS（第 1、7、13(2) 题）。

本卷反复挖的三个坑：

1. **对应关系不唯一就要分类**。题目写成「与以点 X、Y、Z 为顶点的三角形相似」而不是写死 △XYZ，就是在明说有多解（第 9、10 题各有 2 个、3 个答案）。
2. **动点题必须写取值范围**，而范围来自「点还在边上」这个几何约束（第 8 题）。
3. **乘积式 ⇄ 比例式的改写方向**要对准你想用的那两个三角形（第 11、12 题）。

设 **AP = t**（0 < t < 11），则 **BP = 11 − t**。

因为 CA ⊥ AB、DB ⊥ AB，所以 **∠CAP = ∠DBP = 90°**，两个三角形都是直角三角形，直角顶点 A 与 B 必须**互相对应**。剩下 C、P 与 D、P 的配法有两种：

---

**情况一：△ACP ∽ △BDP**（A↔B、C↔D、P↔P）

夹直角的两组边：AC 配 BD，AP 配 BP。

AC/BD = AP/BP

4/6 = t/(11 − t)

4(11 − t) = 6t

44 = 10t

**t = 22/5 = 4.4** ✓（0 < 4.4 < 11）

**情况二：△ACP ∽ △BPD**（A↔B、C↔P、P↔D）

夹直角的两组边：AC 配 BP，AP 配 BD。

AC/BP = AP/BD

4/(11 − t) = t/6

t(11 − t) = 24

t² − 11t + 24 = 0

(t − 3)(t − 8) = 0

**t = 3 或 t = 8** ✓（都在 0 与 11 之间）

---

**综上：AP = 22/5 或 3 或 8。**

**验真除错（逐个回代）：**
- t = 4.4：AC∶AP = 4∶4.4 = 10∶11，BD∶BP = 6∶6.6 = 10∶11 ✓
- t = 3：AC∶BP = 4∶8 = 1∶2，AP∶BD = 3∶6 = 1∶2 ✓
- t = 8：AC∶BP = 4∶3，AP∶BD = 8∶6 = 4∶3 ✓

三个答案全部成立。

**为什么会有 3 个答案？** 题目说的是「△ACP 与**以点 B、D、P 为顶点的三角形**相似」，顶点顺序自由，于是分成两类；而其中第二类是二次方程，本身又给出两个根。**分类之后还要看方程有几个根**，只写"两种情况"就收手，很可能漏掉一个——家徒一壁了。

<details><summary>提示 1</summary>
已知三组边成比例，这正是 SSS 相似的样子——先判出一对相似三角形，把它带来的**角相等**记下来。
</details>

要证的 AB·CE = AC·BD 改写成比例式是 AB/AC = BD/CE，说明真正要证的是 △ABD ∽ △ACE。这两个三角形的夹角 ∠BAD 与 ∠CAE 相等吗？把第一步得到的 ∠BAC = ∠DAE 两边同时减去（或加上）公共的 ∠DAC 试试。

**分析：** 要证 AB·CE = AC·BD，等价于

AB/AC = BD/CE

这两条比的四条线段分别落在 **△ABD** 与 **△ACE** 里，所以目标是证 **△ABD ∽ △ACE**。

**证明：**

**第一步（SSS，得角）。** 已知

AB/AD = AC/AE = BC/DE

三边对应成比例，所以

**△ABC ∽ △ADE**（SSS 相似）

从而

**∠BAC = ∠DAE**

**第二步（导角，得夹角相等）。** 两边同时减去公共角 ∠DAC：

∠BAC − ∠DAC = ∠DAE − ∠DAC

即

**∠BAD = ∠CAE** ……①

（若 D 落在 ∠BAC 外部，则改为两边同加 ∠DAC，结论 ∠BAD = ∠CAE 同样成立。）

**第三步（交换内项，得夹边成比例）。** 由 AB/AD = AC/AE，交换内项得

**AB/AC = AD/AE** ……②

**第四步（SAS，收工）。** 在 △ABD 与 △ACE 中，由 ① ②：

- ∠BAD = ∠CAE
- AB/AC = AD/AE

所以 **△ABD ∽ △ACE**（两边对应成比例且夹角相等）。

于是对应边成比例：

BD/CE = AB/AC

由比例的基本性质：

**AB·CE = AC·BD**

**□ 证毕**

**这是本章的招牌模型「手拉手（旋转型）相似」**：两个共顶点 A 的相似三角形 △ABC ∽ △ADE，把对应顶点交叉连起来（B–D、C–E），必然又得到一对相似三角形 △ABD ∽ △ACE。记住这个"买一送一"，见到共顶点的两个相似三角形，第二对相似直接就能用。

### 第 12 题
<details><summary>提示 1</summary>
先把 AE·CE = DE·BE 改写成比例式。注意有**两种**改法（AE/BE = DE/CE 或 AE/DE = BE/CE），它们分别指向以 E 为交点的两对不同的三角形。哪一种能配上对顶角？其实两种都能，但只有一种能推出你要的那个角。
</details>
<details><summary>提示 2</summary>
要证 △ABE ∽ △ACB，先注意 E 在 AC 上，所以 ∠BAE 与 ∠BAC 是**同一个角**——公共角白送。只差一对角：需要 ∠ABE = ∠ACB，也就是 ∠ABD = ∠ACB。
</details>
<details><summary>提示 3</summary>
∠ABD 有个好邻居：AB=AD 说明 △ABD 是等腰三角形，∠ABD = ∠ADB。所以只要证出 ∠ADB = ∠ACB 就够了——去看 △AED 与 △BEC（对顶角 ∠AED=∠BEC，夹边比由改写后的比例式给出）。

**分析：** 目标 △ABE ∽ △ACB。因为 E 在 AC 上，**∠BAE = ∠CAB 是同一个角**（公共角），所以按 AA 只需再证 **∠ABE = ∠ACB**。而 E 在 BD 上，∠ABE 就是 ∠ABD；又 AB = AD，∠ABD = ∠ADB。于是问题化为证 **∠ADB = ∠ACB**。

**证明：**

**第一步：把条件改写成比例式。**

由 AE·CE = DE·BE 得

**AE/BE = DE/CE** ……①

**第二步：证 △AED ∽ △BEC（SAS 相似）。**

在 △AED 与 △BEC 中：

- ∠AED = ∠BEC（**对顶角**）
- 夹这对角的两组边分别是 EA、ED 和 EB、EC，由 ① 有

  **EA/EB = ED/EC**

所以 **△AED ∽ △BEC**（两边对应成比例且夹角相等），对应关系 A↔B、E↔E、D↔C。

从而

**∠ADE = ∠BCE**

因为 E 在 BD 上，∠ADE = ∠ADB；因为 E 在 AC 上，∠BCE = ∠BCA。所以

**∠ADB = ∠ACB** ……②

**第三步：用等腰三角形转角。**

因为 **AB = AD**，△ABD 是等腰三角形，等边对等角：

**∠ABD = ∠ADB** ……③

由 ② ③ 得

**∠ABD = ∠ACB**，即 **∠ABE = ∠ACB** ……④

**第四步：AA 收工。**

在 △ABE 与 △ACB 中：

- ∠BAE = ∠CAB（公共角，因为 E 在线段 AC 上）
- ∠ABE = ∠ACB（由 ④）

所以 **△ABE ∽ △ACB**（两角对应相等）。

**□ 证毕**

**顺带白送一个结论：** 由 △ABE ∽ △ACB 立刻得 AB/AC = AE/AB，即 **AB² = AE·AC**——又是一个「共角共边」（∠A 公共，AB 是共用边）。第 5 题讲过的模型，这里以结论的身份又出现一次，走过路过不要错过。

**这题最容易卡住的地方**：把 AE·CE = DE·BE 改写成 AE/DE = BE/CE（配 △AEB 与 △DEC）。那样也能证出 △AEB ∽ △DEC，但得到的是 ∠ABE = ∠DCE，绕不到 ∠ACB 上去。**改写方向要盯着你想要的那个角选**，不能随手一改就往下推。
</details>

设 **PC = a**，则由 BC = 4PC 得正方形边长

**AB = BC = CD = DA = 4a**，　**BP = BC − PC = 3a**

Q 是 CD 的中点，所以

**DQ = QC = 2a**

---

#### (1) 求证：△ADQ ∽ △QCP

在 △ADQ 与 △QCP 中：

- **∠D = ∠C = 90°**（正方形的内角）
- 夹这两个直角的边分别是 DA、DQ 和 CQ、CP：

  AD/QC = 4a/2a = **2**，　　DQ/CP = 2a/a = **2**

  所以 **AD/QC = DQ/CP**

由**两边对应成比例且夹角相等**（SAS 相似）得

**△ADQ ∽ △QCP**（对应关系 A↔Q、D↔C、Q↔P，相似比 2∶1）

**□ 证毕**

---

#### (2) 求证：△APQ ∽ △AQD

**第一步：先证 ∠AQP = 90°。**

由 (1)，△ADQ ∽ △QCP，所以

**∠AQD = ∠QPC**

而在 Rt△QCP 中，两锐角互余：

∠QPC + ∠PQC = 90°

代入得

**∠AQD + ∠PQC = 90°**

因为 D、Q、C 三点共线（Q 在边 DC 上），

∠AQP = 180° − ∠AQD − ∠PQC = 180° − 90° = **90°**

所以 **∠AQP = ∠ADQ = 90°** ……①

**第二步：再证夹这两个直角的边成比例。**

由 (1) 的相似比为 2∶1，对应边 AQ 与 QP 也满足

**AQ/QP = 2**

而

**AD/DQ = 4a/2a = 2**

所以

**AQ/AD = QP/DQ** ……②

**第三步：SAS 收工。**

在 △AQP 与 △ADQ 中，由 ① ②：

- ∠AQP = ∠ADQ = 90°
- AQ/AD = QP/DQ

所以 **△AQP ∽ △ADQ**，即 **△APQ ∽ △AQD**。

**□ 证毕**

---

**另一种证法（SSS，硬算三条边）：** 用勾股定理

- AQ = √(AD² + DQ²) = √(16a² + 4a²) = **2√5 a**
- PQ = √(QC² + CP²) = √(4a² + a²) = **√5 a**
- AP = √(AB² + BP²) = √(16a² + 9a²) = **5a**

于是

AP/AQ = 5a/(2√5 a) = **√5/2**，　PQ/QD = √5a/(2a) = **√5/2**，　AQ/AD = 2√5a/(4a) = **√5/2**

三组边的比都是 √5/2，由 **SSS** 得 △APQ ∽ △AQD ✓ 与上面的结果一致。

**两种证法的取舍：** SSS 那条路要开三次根号，属于死算协会的走法；借第 (1) 问的结论走 SAS，一个根号都不用开。**做多问题时，前一问的结论就是后一问的工具**，别做完 (1) 就把它扔了。
</details>

**准备（把 DE∥BC 榨干）。** 因为 DE ∥ BC，由平行线分线段成比例（或 △ADE ∽ △ABC）：

**AD/AB = AE/AC = DE/BC** ……(*)

由 (*) 的前一个等号得 **AE = AC·AD/AB**，代入已知的 AD² = AE·AC：

AD² = (AC·AD/AB)·AC

AD²·AB = AC²·AD

两边同除以 AD（AD > 0）：

**AC² = AD·AB** ……(**)

---

#### (1) 求证：△BCD ∽ △CDE

**第一对角：** 因为 DE ∥ BC，DC 是截线，由**内错角**相等：

**∠BCD = ∠CDE** ……①

**第一条比例链（用 (**)）：** 由 AC² = AD·AB 得

AC/AB = AD/AC

在 △ACD 与 △ABC 中，∠A 为公共角，且夹 ∠A 的两组边满足上式，由 **SAS 相似**：

**△ACD ∽ △ABC**（A↔A、C↔B、D↔C）

所以对应边成比例：

CD/BC = AC/AB，即 **BC/CD = AB/AC** ……②

**第二条比例链（用已知 AD²=AE·AC）：** 由 AD² = AE·AC 得

AD/AC = AE/AD

在 △ADE 与 △ACD 中，∠A 为公共角，且夹 ∠A 的两组边满足上式，由 **SAS 相似**：

**△ADE ∽ △ACD**（A↔A、D↔C、E↔D）

所以对应边成比例：

DE/CD = AD/AC，即 **CD/DE = AC/AD** ……③

**把两条链接起来。** 由 (**) 有 AC² = AD·AB，即

**AB/AC = AC/AD** ……④

由 ②、④、③ 依次相等：

BC/CD = AB/AC = AC/AD = CD/DE

即

**BC/CD = CD/DE** ……⑤

**收工。** 在 △BCD 与 △CDE 中，由 ① ⑤：

- ∠BCD = ∠CDE（夹角相等）
- CB/DC = CD/DE（夹这对角的两组边成比例：∠BCD 的夹边是 CB、CD，∠CDE 的夹边是 DC、DE）

所以 **△BCD ∽ △CDE**（两边对应成比例且夹角相等）。

**□ 证毕**

---

#### (2) 求证：CD²/BC² = AD/AB

由 (1) 的 ⑤ 式 BC/CD = CD/DE，交叉相乘得

**CD² = BC·DE**

两边同除以 BC²：

CD²/BC² = (BC·DE)/BC² = **DE/BC**

再由准备工作中的 (*)：DE/BC = AD/AB。

所以

**CD²/BC² = AD/AB**

**□ 证毕**

---

**验真除错（取一组具体数据全程回代）：**
取 AB = 8，AC = 4。由 (**) AC² = AD·AB 得 AD = 16/8 = **2**，于是 k = AD/AB = 1/4。
由 (*) 得 AE = AC·k = 1，检验已知条件：AD² = 4，AE·AC = 1×4 = 4 ✓。
再取 BC = 12，则 DE = BC·k = **3**；由 ② CD = BC·AC/AB = 12×4/8 = **6**。
检验 (1)：BC/CD = 12/6 = 2，CD/DE = 6/3 = 2 ✓ 相等。
检验 (2)：CD²/BC² = 36/144 = 1/4，AD/AB = 2/8 = 1/4 ✓ 相等。
（顺带核一下三角形是否存在：AB=8、AC=4、BC=12 时 8+4=12 恰好共线，是退化情形，说明 BC 不能取 12；改取 BC = 9，则 DE = 9/4、CD = 9×4/8 = 4.5，
BC/CD = 2、CD/DE = 4.5/2.25 = 2 ✓，CD²/BC² = 20.25/81 = 1/4 = AD/AB ✓，结论不受影响——
因为 ②③ 两条比例链都只依赖 (*) 与 (**)，与 BC 的具体取值无关。）

**这题的骨架就一句话：** DE∥BC 给「比」，AD²=AE·AC 给「共角共边」，两者合起来把 **AB、AC、AD** 三条线段串成一条等比链 AB∶AC = AC∶AD，再顺势把 **BC、CD、DE** 也串成同样比值的等比链 BC∶CD = CD∶DE。**看见 x²=yz 就想比例中项，看见比例中项就想共角共边**，这一节的题基本都是这一招的变形。
