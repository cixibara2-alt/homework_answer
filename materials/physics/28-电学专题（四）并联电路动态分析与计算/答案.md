这份是物理电学专题（四）并联电路动态分析与计算，共 4 页。

这一讲反复用到的两条"底层规律"，先记住，后面每题都是它的变形：

1. **并联各支路两端的电压都等于电源电压**（电流表、开关、导线都当作没有电阻）。所以只要电源电压不变，**定值电阻那条支路的电流就是个死数**，别的支路怎么变都影响不到它。
2. 干路电流 I = I₁ + I₂。既然 I₁ 不变，那么**干路电流的变化量，就等于变阻器那条支路电流的变化量**（ΔI = ΔI₂）。这一条是本讲所有计算题的钥匙。

## 01

### 【例】滑片向右移动时

电路：电源、开关 S、电流表 A 在干路上；R₂（变阻器，左端固定接线柱 + 滑片 P 接入）串 A₂ 是一条支路，R₁ 串 A₁ 是另一条支路，两条支路并联；电压表 V 接在这两条支路共同的两端（也就是量电源电压）。
变阻器用的是"左端 + 滑片"，滑片向右移动，接入电路的那一段变长：

- **R₂ 阻值：变大**
- **电压表 V 的示数：不变**（V 量的是并联部分两端的电压，等于电源电压，恒定）
- **电流表 A₁ 的示数：不变**（I₁ = U/R₁，U 不变、R₁ 不变）
- **电流表 A₂ 的示数：变小**（I₂ = U/R₂，R₂ 变大）
- **电流表 A 的示数：变小**（I = I₁ + I₂，I₁ 不变、I₂ 变小）

（1）V 的示数与 A₁ 示数的比值 = U/I₁ = **R₁**，是个定值，所以**不变**。

（2）
- A₁ 与 A₂ 示数的比值 = I₁/I₂ = (U/R₁)/(U/R₂) = R₂/R₁，R₂ 变大 → **变大**；
- A₁ 与 A 示数的比值 = I₁/(I₁+I₂)，分子不变、分母因 I₂ 变小而变小 → **变大**；
- A₂ 与 A 示数的比值 = I₂/(I₁+I₂)，I₂ 变小时这个比值往 0 靠 → **变小**。

（3）**ΔI₂ ＝ ΔI**（填"="）。因为 I = I₁ + I₂ 而 I₁ 全程不变，干路电流的变化完全来自 I₂，两个变化量相等。

### 随堂练习 1

电路：R₁（变阻器，左端固定接线柱 + 滑片 P 接入）和 R₂（定值）两条支路并联，电源和开关 S 在干路上。

（1）先看"移动滑片时两个电流表示数都会变"这句话：R₂ 是定值电阻，它两端的电压永远等于电源电压，所以 **R₂ 支路的电流是不会变的**——那两个电流表都不可能接在 R₂ 支路上。剩下的位置只有 R₁ 支路和干路。再看"A₁ 示数大于 A₂ 示数"：并联电路里干路电流总是比任一支路电流大，所以大的那个是干路。
**A₁ 测量的是 C.干路 中的电流，A₂ 测量的是 A.R₁ 支路 中的电流。**

（2）A₁/A₂ = I干/I₁ = (I₁+I₂)/I₁ = 1 + I₂/I₁。I₂ 是定值，要让这个比值变大，就得让 I₁ 变小，也就是 R₁ 变大。变阻器用的是左端固定接线柱 + 滑片，滑片越往右接入的电阻丝越长、电阻越大。
**滑片 P 是向 B.右 端移动。**

### 随堂练习 2

**答案：A、C、D 都对，只有 B 错。**（如果老师那边只让填一个，最能体现本题考点的是 D。）

电路：电源直接接在左右两个节点上，V 经 S₁ 接在电源两端（量的就是电源电压）；R₂ 串 S₂ 是一条支路，A₁ 串 R₁ 是另一条支路，两条支路并联；电流表 A 在干路上。题目问的是"S₂ 也闭合、把 R₂ 这条支路接进来"前后的变化：

- A. 电压表 V 直接并在电源两端，读数永远等于电源电压，题目又说电源电压保持不变 → **示数不变，A 对**。
- B. R₁ 两端的电压始终等于电源电压（电流表、开关都不分压），所以 I₁ = U/R₁ **一直没变**，不是变大 → **B 错**。
- C. V 示数和 A₁ 示数两个都不变，比值当然也不变（这个比值就等于 R₁）→ **C 对**。
- D. 接入 R₂ 后多了一条支路，干路电流 I = I₁ + I₂ 变大，而 V 示数不变，乘积 U×I 变大 → **D 对**。

## 02

### 3

电路：R₁（6Ω，定值）与 R₂（变阻器，"50Ω 2A"，左端 + 滑片接入）并联，电流表 A 在干路上，电源电压 9V 不变。

R₁ 支路电流固定：I₁ = U/R₁ = 9V ÷ 6Ω = 1.5A。
R₂ 支路电流：I₂ = U/R₂ = 9V ÷ R₂，干路电流 I = 1.5A + I₂。

安全限制有两条，取更严的那条：
- 变阻器自身允许的最大电流 2A：I₂ ≤ 2A，对应 R₂ ≥ 9V ÷ 2A = 4.5Ω；
- **电流表本身的量程**：I₁ 一项就已经 1.5A，超过 0.6A 挡，所以电流表必须用 0～3A 挡，干路电流 I ≤ 3A → I₂ ≤ 3A − 1.5A = 1.5A，对应 R₂ ≥ 9V ÷ 1.5A = **6Ω**。

6Ω 比 4.5Ω 更严，所以真正的下限是 6Ω（此时 I₂ = 1.5A，没超过变阻器的 2A，安全）。上限就是变阻器的最大值 50Ω，此时 I₂ = 9V ÷ 50Ω = 0.18A，干路电流最小值 I小 = 1.5 + 0.18 = 1.68A。

- **电流表示数的最大变化量 ΔI = 3A − 1.68A = 1.32A**
- **R₂ 的取值范围：6Ω ≤ R₂ ≤ 50Ω**

（说明：这里用到了"电流表用 0～3A 量程、最大只能读到 3A"这个前提。题面没把电流表量程写出来，但 I₁ 已经是 1.5A，只能选 3A 挡，所以按 3A 算。）

（2）R₁ 两端电压等于电源电压，所以 I₁ = U/R₁ 是个定值，干路电流的变化量就等于 R₂ 支路电流的变化量：

电流表最大示数那次：I₁ = 2.6A − 2A = 0.6A。
**U = I₁ × R₁ = 0.6A × 10Ω = 6V。**

（3）R₂ 两端电压也是 6V：
R₂小 = 6V ÷ 2A = 3Ω，R₂大 = 6V ÷ 0.3A = 20Ω。
**R₂ 接入电路的阻值范围：3Ω ～ 20Ω。**

## 03

### 课后练习 1

**C（A₁ 示数不变，A 示数变小）。**

电路里 R₂ 串 A₂ 串 S 是一条支路，R₁ 串 A₁ 是另一条支路，两条并联；A 在干路上，V 直接并在电源两端。
S 由闭合变断开，R₂ 那条支路被切断：
- A₁ 测的是 R₁ 支路电流，R₁ 两端电压始终等于电源电压 → **示数不变**；
- A₂ 直接掉到 0 → 变小，不是变大，所以 A、D 都错；
- 干路电流 I = I₁ + I₂ 少了 I₂ → **变小**，所以 B 里"A 示数不变"错。

### 课后练习 2

电路：V、R₁串A₁、R₂（变阻器，左端 + 滑片）串A₂、"S+电源+A"这四条并联在同样的左右两点之间，所以 V 量的是电源电压，A 是干路电流。
滑片 P 向右移动 → R₂ 变大 → I₂（A₂）变小 → 干路电流 I（A）变小；I₁（A₁）和 V 都不变。

- ① V 的示数 = 电源电压 → 不变（既不变大也不变小）
- ② V 示数 ÷ A₂ 示数 = U/I₂ = R₂ → **变大**
- ③ V 示数 × A 示数 = U × I，U 不变、I 变小 → **变小**
- ④ A₁ ÷ A = I₁/(I₁+I₂)，分子不变、分母变小 → **变大**
- ⑤ A₂ ÷ A = I₂/(I₁+I₂)，I₂ 变小时这个比值往 0 靠 → **变小**

**变大的是 ②④；变小的是 ③⑤。**（①不变，两个空都不填它。）

### 课后练习 3

电路：R₀ 整根（两端都接进电路）接在电源两端，滑片 P 引出来接电压表 V 的一端，V 的另一端接在下面那条导线上——所以 V 量的是 R₀ 中"滑片以下那一段"的电压；压敏电阻 R 串联电流表 A，作为另一条支路也接在电源两端。人踩上去时，绝缘材料只是把压力传给 R，电路上没有连接。

（1）**电压表（V）用来反映身高，电流表（A）用来反映体重。**
（身高改变的是滑片位置，只影响 V 的读数；体重改变的是 R 的阻值，只影响 A 的读数，两者互不干扰——这正是把它们做成两条并联支路的目的。）

（2）身高越高 → 滑片 P 上滑 → 滑片以下接入的电阻丝变长、电压变大 → **身高仪表（电压表）的示数变大**；
通过 R₀ 的电流 = 电源电压 ÷ R₀ 的总电阻，而 R₀ 是整根接入的，滑片移动只改变分压比例、不改变接入的总电阻（电压表是理想的，不分走电流），所以**通过 R₀ 的电流不变**。

（3）体重越重 → 电流表示数越大 → 由 I = U/R（R 两端电压恒为电源电压）可知 R 变小，
所以说明 R 的阻值随压力的增大而 **减小（变小）**。

### 课后练习 4

（1）三次数据里 A₁ − A₂ 都等于 1.2A（1.4−0.2、1.6−0.4、2.1−0.9），说明有一条支路的电流始终是 1.2A 没变过——那就是定值电阻 R₁ 那条支路；而 A₁ 比 A₂ 大、且等于"A₂ + 定值"，说明 A₁ 读的是干路。
**A₁ 测量的是 C.干路 的电流，A₂ 测量的是 B.R₂ 支路 的电流。**

（2）I₁ = 1.2A，R₁ 两端电压等于电源电压 12V：
**R₁ = 12V ÷ 1.2A = 10Ω。**
滑片从最右端开始，第 1 次数据就是变阻器接入最大阻值时的情况，此时 I₂ = 0.2A：
**变阻器的最大电阻 = 12V ÷ 0.2A = 60Ω。**

### 5

电路（图 a）：R₁ 与变阻器 R₂（左端固定接线柱 + 滑片 P 接入）并联，电流表 A 在干路上，量的是总电流。电源电压 12V 不变，R₁ = 20Ω。

（1）R₁ 两端电压等于电源电压：
**I₁ = U/R₁ = 12V ÷ 20Ω = 0.6A。**（这个值跟滑片在哪儿无关，全程都是 0.6A。）

（2）图 b 的电流表：因为 I₁ 一项就有 0.6A，用 0～0.6A 挡会直接打满，所以接的是 0～3A 挡，每一小格 0.1A，指针指在 1.0A（对应小量程刻度上的 0.2）。
干路电流 I = 1.0A，所以 I₂ = I − I₁ = 1.0A − 0.6A = 0.4A。
滑片在最右端时接入的电阻丝最长，正好是变阻器的最大阻值：
**R₂大 = U/I₂ = 12V ÷ 0.4A = 30Ω。**

（3）I₁ 恒为 0.6A，所以电流表读数的变化量就等于 R₂ 支路电流的变化量。
指针最多变化 11 小格：ΔI = 11 × 0.1A = 1.1A，即 ΔI₂ = 1.1A。
**I₂大 = 0.4A + 1.1A = 1.5A。**
（此时干路电流 1.0 + 1.1 = 2.1A，没超过电流表 3A 的量程，合理。）

（1）**I₀ = U₁/R₁ = 9V ÷ 10Ω = 0.9A。**
（顺带得到：电流表、开关、导线都不分压，所以电源电压也就是 9V，后面两问要用。）
