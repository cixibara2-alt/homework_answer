这份是物理电学专题（五）并联电路故障分析，共 3 页。
（第 1 页题号是 1、2、3、4、6、7——卷子本身就跳过了 5，不是漏抄。）

判断并联电路故障，先记牢这几条，后面每题都是套用：

1. 并联电路里**某条支路断了，只有那条支路没电流**，其余支路照常工作，各支路两端的电压仍然等于电源电压。所以：**断路支路上的电流表示数变 0，干路电流表示数变小，电压表示数不变。**
2. **电压表在并联电路里几乎判断不出故障**：不管断的是哪条支路，把电压表接在任一支路两端、甚至接在断点两端，读数都是电源电压，两种故障看起来一模一样。
3. 某条支路**短路**＝把电源两端用导线直接连上（电源短路），所有用电器都不工作、电流表被烧、电压表示数变 0——这是要极力避免的，做题时一般用来排除选项。
4. 想区分"断的是哪一条"，靠的是**给某条支路加开关、或者移动变阻器滑片、或者换一个已知完好的电阻**，看干路电流表的反应。

## 01

### 1

**C（灯 L₂ 开路）。**

电路：电源和 S 在左边干路上，A₁ 接在干路上（量总电流），从 A₁ 右边的节点分出 L₁ 那条支路；再往右经过 A₂ 到第二个节点，分出 L₂ 和电压表 V。所以 **A₁ 量的是干路电流 I₁+I₂，A₂ 量的是 L₂ 支路的电流 I₂**。

- L₂ 开路：L₂ 灭 ✓；A₂ 变成 0（变小 ✓）；A₁ 只剩 I₁（变小 ✓）——两个电流表都变小，符合题意。
- L₁ 开路：A₁ 变小，但 A₂ 还是 I₂ 不变，不符合"两个都变小"。
- 任一盏灯短路都会把电源短路，两盏灯全灭、电流剧增，也不符合。

### 2

**B（灯 L₁ 开路）。**

三个电表：A₁ 干路、A₂ 量 L₂ 支路、V 量并联部分两端电压（＝电源电压）。
L₁ 开路后：A₁ 少了 I₁ → 变小；A₂ 还是 I₂ → 不变；V 仍是电源电压 → 不变。正好"一个电表变小、另外两个不变"。
（L₂ 开路会让 A₂ 和 A₁ 两个一起变小，不符合；短路会把电源短路，更不符合。）

### 3

**B（电阻 R₂ 存在开路故障）。**

电路：左右两个节点之间并排接了四条支路——"A₁＋R₁"、"A₂＋电源"（A₂ 在干路上量总电流）、"R₂＋S"、"V"。注意 **R₁ 那条支路上没有开关**，所以 S 断开时 R₁ 就已经在工作了。

正常情况下：S 断开时 A₁＝A₂＝U/R₁、V＝U；S 闭合后 R₂ 支路也通电，**A₂ 应该变大**（A₁、V 不变）。
现在三个电表示数都没变化，说明闭合 S 之后 R₂ 支路仍然没有电流 → **R₂ 断路**。
（R₁ 断路的话，闭合 S 前后 A₁、A₂ 会从 0 变成有示数，仍然会有变化；短路故障会把电源短路，V 直接掉到 0，变化更明显。）

### 4

电路：左右节点之间三条支路——"R₁＋A₁"、"S＋电源＋A"（A 在干路量总电流）、"R₂"。R₁＝R₂，两支路电压都等于电源电压，所以两支路电流相等。

第一空：A₁ 读的是 I₁＝I，那么 I₂ 也等于 I，**电流表 A 的示数为 2I**。

后面一空（两种可能都要写）：
- 若 **A₁ 示数为 0、A 示数为 I**（由 2I 变成 I）→ 故障是 **R₁ 开路**；
- 若 **A₁ 示数仍为 I（不变）、A 示数由 2I 变成 I** → 故障是 **R₂ 开路**。

### 6

（1）**选 A（把一个电流表接入到 Q 点）。**

理由：Q 在干路上（电源那条支路里），接电流表就是量总电流；而 R₂ 是**滑动变阻器**，这一点是解题的关键。
- B 不行：Q 和 M 都直接连在左边那根导线上，本来就是同一个点，电压表接上去读数永远是 0，什么也判断不了。
- C 不行：并联电路里 MN 之间（R₂ 两端）的电压永远等于电源电压——R₁ 断也好、R₂ 断也好，读数都一样，区分不开。

（2）操作与判断：**闭合开关 S 后，把滑动变阻器的滑片 P 从一端慢慢移到另一端，盯着电流表的示数看——**
- **若示数随滑片移动而改变**：说明电流是从 R₂ 这条支路流过去的，R₂ 完好 → **故障是 R₁ 开路**；
- **若示数不为零、但始终保持不变**：说明 R₂ 支路根本没有电流，电流只走 R₁ → **故障是 R₂ 开路**。

### 7

**① 选 C（在 b 点再接入一只开关 S₁）。**

电路：R₁、R₂ 并联在左右两节点之间，电流表 A 和电源、开关 S 在干路上；b 在 R₁ 支路上，a 在干路上。
- A 不行：a 点在干路上，跟原来的电流表 A 是同一条支路，再加一个电流表读到的数完全一样，等于白加。
- B 不行：a 相当于右节点、b 相当于左节点，电压表接在 a、b 之间量的就是电源电压，不论断的是 R₁ 还是 R₂ 都读电源电压，区分不开。
- C 可以：在 b 点（R₁ 支路上）加一个开关 S₁，就能单独把 R₁ 支路切断或接通，配合原来干路上的电流表 A 来判断。

## 02

### 7② （承接第 1 页第 7 题）

操作：**先把新加的 S₁ 断开（即把 R₁ 支路切断），再闭合原来的开关 S，观察干路电流表 A 的示数：**
- **A 有示数**：说明此时电流是从 R₂ 支路走的，R₂ 完好 → 故障是 **R₁ 开路**；
- **A 示数为 0**：说明 R₂ 支路不通 → 故障是 **R₂ 开路**。

（还可以再把 S₁ 闭合复核一次：若示数由 0 变为有示数，说明 R₁ 是好的，进一步印证故障在 R₂。）

## 课后作业（第 2 页）

### 1

**D（灯 L₂ 开路）。**

电路：上下两根导线之间并排挂着 V、L₁、L₂、"电源＋S"四条支路；电流表 A 接在下面那根导线上、位于 L₁ 与 L₂ 的下端之间——所以 **L₂ 的电流直接回电源、不经过 A，A 量的只是 L₁ 的电流**；V 量的是并联部分两端的电压（＝电源电压）。

L₂ 开路：L₂ 灭 ✓，A 仍读 L₁ 的电流（不变 ✓），V 仍读电源电压（不变 ✓）——正好符合"熄灭一盏灯而两表示数都不变"。
（L₁ 开路会让 A 掉到 0；任一盏灯短路都会把电源短路，V 掉到 0。）

### 2

**C（灯 L₂ 开路）。**

电路：L₁ 与电流表 A 串成一条支路接在电源两端，L₂ 单独接在电源两端，电压表 V 并在 L₁ 两端。所以 **A 量的是 L₁ 的电流，V 量的是 L₁ 两端的电压（＝电源电压）**，两者的比值就是 L₁ 的电阻。

L₂ 开路：L₂ 灭，L₁ 支路完全不受影响，V 和 A 的示数都不变，比值当然不变 ✓。
（L₁ 开路：A 变 0，比值没法保持；L₁ 或 L₂ 短路都会造成电源短路，两灯全灭。）

### 3

电路：R₂（滑动变阻器，左端固定接线柱＋滑片接入）与 R₁ 并联，电流表 A 在干路上，电源电压 U 不变，R₂ 的最大阻值＝2R₁。

**①** 滑片向右移动 → R₂ 接入的阻值变大 → I₂＝U/R₂ 变小 → 干路电流 I＝I₁+I₂ **变小**。

**②** 滑片在最右端时 R₂＝2R₁：
I₁＝U/R₁，I₂＝U/(2R₁)＝I₁/2，总电流 I总＝1.5·(U/R₁)＝3I，
所以 U/R₁＝2I，即 **I₁＝2I、I₂＝I**。
后来电流表突然只剩 I，正好等于 I₂，说明 R₁ 那条支路没电流了 → **故障是 R₁ 开路**。
（若是 R₂ 开路，剩下的应该是 I₁＝2I，对不上；短路故障会让电流剧增。）

### 4

电路：左右节点之间四条支路——"R₁＋A₁"、"电压表 V"、"R₂＋S"、"电源＋A₂"（A₂ 在干路量总电流）。V 的两端正好接在 R₂ 的两端，**所以 V 量的是 R₂ 两端的电压**；R₁ 那条支路上没有开关，S 只控制 R₂ 支路。

**（1）** S 断开时 R₂ 支路不通，R₂ 两端没有电压，V 读 0；S 闭合后 R₂ 接入，两端电压等于电源电压。
所以电压表 V 的示数将 **C.变大**（由 0 变成电源电压）；
R₁ 支路两端的电压一直是电源电压，跟 S 无关，所以电流表 A₁ 的示数将 **B.不变**。

**（2）** 三个电表里只有一个示数变化，对应的故障是 **R₂ 开路**，具体表现是：
**电压表 V 的示数由 0 变为电源电压（变大），电流表 A₁ 和 A₂ 的示数都不变。**

理由：R₂ 断了，闭合 S 后 R₂ 支路仍然没有电流，所以干路电流 A₂ 和支路电流 A₁ 都保持原样；但此时电压表和闭合的 S 串成了一条通路接在电源两端，电压表（内阻极大、几乎不通电流）就把电源电压全部量了出来，于是只有 V 一个表的示数发生变化。
（若是 R₁ 开路，闭合 S 前后 A₂、V 两个表都会变化，不止一个。）

### 5

**电流表应该串联在 b 处。**

b 在电源所在的那条干路上，量的是总电流；a、c 分别在 R₁、R₂ 支路上，只能知道自己那条支路的情况，管不到另一条（比如接在 a 处，S 断开时读数必然是 0，根本不能说明 R₂ 好不好）。

开关由断开到闭合时，电流表示数的情况及对应的情况：
- **断开时有示数，闭合后示数变大** → R₁、R₂ 都完好，电路没有故障；
- **断开时示数为 0，闭合后有示数** → 断开时只有 R₂ 支路能通电却没电流 → **R₂ 开路**；
- **断开时有示数，闭合后示数不变** → 闭合 S 后 R₁ 支路没有补上电流 → **R₁ 开路**。

## 03

### 6

电路：R₁ 与 R₂（滑动变阻器）并联，电源和 S 在干路上，只有一处开路故障，且在 R₁ 或 R₂ 上。

**（1）** 在干路串联一个电流表，闭合开关后移动滑片 P，
**若电流表有示数、但示数不随滑片的移动而改变（始终不变）**，说明电流全是从 R₁ 走的、R₂ 那条支路没有电流，就说明电阻 R₂ 断路。
（反过来，若示数随滑片移动而改变，说明电流走的是 R₂ 支路，断的是 R₁。）

**（2）不能用电压表判断。**
因为并联电路各支路两端的电压都等于电源电压：不论断的是 R₁ 还是 R₂，把电压表并到 R₁ 两端、并到 R₂ 两端、甚至并在断点两端，读数统统是电源电压，两种故障给出的读数完全一样，无法区分。（电压表内阻很大、几乎不通电流，也不能靠"移动滑片看它变不变"来判断。）

### 7

**选 A 或 B 都能判断，选 C 不行。**（如果只允许填一个，填 B「R₃＝R₁」最保险、现象最好描述。）

先分析：电路是 R₁∥R₂，电流表在干路。示数变小说明有一条支路断了，故障要么是 R₁ 开路（此时干路电流＝U/R₂），要么是 R₂ 开路（此时干路电流＝U/R₁）。现在把 R₁ 换成完好的 R₃，看示数怎么变：
- 若原来是 **R₁ 开路**：换上好电阻后这条支路恢复，电流变成 U/R₂＋U/R₃ → **一定变大**；
- 若原来是 **R₂ 开路**：电流由 U/R₁ 变成 U/R₃，是变大还是变小取决于 R₃ 与 R₁ 的大小。

所以：
- **B（R₃＝R₁）**：两种故障分别对应"变大"和"不变"，能区分 ✓
- **A（R₃>R₁）**：两种故障分别对应"变大"和"变小"，也能区分 ✓
- **C（R₃<R₁）**：两种故障都表现为"变大"，看不出到底断的是哪一个 ✗

（这道题按题目给的三个选项，A 和 B 在逻辑上都成立，答案不唯一；我按上面的道理都写出来了，请以老师的标准答案为准。）

### 8

电路：R₁∥R₂（阻值都是 R₀），电流表在干路上，电源电压 U₀ 不变。

**（1）ABD。**
干路电流不为零，说明至少有一条支路是通的：
- A（R₁ 开路）：R₂ 还通，电流＝U₀/R₀≠0 ✓ 可能；
- B（R₂ 开路）：同理 ✓ 可能；
- C（两个都开路）：一条支路都不通，电流必为 0 ✗ 不可能；
- D（电路正常）：电流＝2U₀/R₀≠0 ✓ 可能。

**（2）** 用完好的 R₃（阻值也是 R₀）替换 R₁ 后闭合开关：
- **若电流表示数为 2U₀/R₀**：说明现在两条支路都通了，原来断的正是被换掉的那个 → **故障是 R₁ 开路**；
- **若电流表示数为 U₀/R₀**：说明只有 R₃ 这一条支路有电流，另一条仍然不通 → **故障是 R₂ 开路**。

### 9

图(a)：R₁ 与 R₂ **串联**，A₁ 和电源、S₁ 在同一个回路里。
图(b)：R₃ 与 R₁ **并联**，A₂ 在干路上，电源和 S₂ 在干路里。
三个电阻中只有一个有故障，闭合 S₁、S₂ 后 A₁、A₂ 都有示数。

**（1）故障可能是：R₂ 短路，或者 R₃ 开路。**

推理：
- 图(a)是串联电路，A₁ 有示数说明回路是通的 → R₁、R₂ 都不可能开路，只可能短路；
- R₂ 只出现在(a)里，**R₂ 短路**时(a)的电流＝U/R₁≠0 ✓，(b)不含 R₂ 不受影响 ✓，成立；
- R₃ 只出现在(b)里，**R₃ 开路**时(b)里 R₁ 仍通电、A₂＝U/R₁≠0 ✓，(a)不含 R₃ 不受影响 ✓，成立；
- R₁ 短路要排除：R₁ 在(b)里是并联支路，短路就等于把电源两端直接用导线连起来（电源短路），会烧坏电源和电流表，不是正常能观察到的情况；R₃ 短路同理也要排除。

**（2）采用方案①（在图(a)中把 R₂ 换成 R₃）。**

理由：换上 R₃ 后(a)变成"R₁ 与 R₃ 串联"，
- 若电流表 **示数变小但仍不为零**（由 U/R₁ 变成 U/(R₁+R₃)）→ 说明拿掉的 R₂ 正是短路的那个，**故障是 R₂ 短路**；
- 若电流表 **示数变为 0** → 说明串进来的 R₃ 是断的，**故障是 R₃ 开路**。
两种故障的现象完全不同，能明确区分，而且电路始终是串联，没有危险。

不能采用方案②的原因：方案②是把 R₂ 接进图(b)的并联电路里。**万一故障恰好就是 R₂ 短路，一条阻值为零的支路直接并在电源两端，就造成了电源短路**，电流会大到烧坏电源和电流表——不但判断不出故障，还会把器材损坏，所以不能这么做。
