## 01

### 1
C —— 电路两端有电压，电路不一定是通路（比如开关断开时，断口两端也有电压，但电路是开路，没有电流）。A、B、D 说法都对。

### 2
C —— 铭牌"输出：5.0V＝1.0A"，输出电压就是 5.0V。

### 3
C —— 用 15V 挡时，实际电压 = 3V 挡读数 × 5（因为 15V 挡量程是 3V 挡的 5 倍）：1.8V×5=9.0V。

### 4
B —— 番茄电池本质是化学电池，能把化学能转化为电能，这是电池的基本作用，B 正确。
A 不对：锌比铜活泼，锌失去电子被氧化，是番茄电池的负极，铜才是正极。
C 不对：电路图里通常箭头标的是电流方向，不是电子移动方向（电流方向和电子移动方向相反）。
D 不对：电压表内阻很大，直接接在电源两端是电压表的正常使用方式，不会损坏电压表（会烧坏的是电流表）。

### 5
C —— 分析每个选项（电池左边短粗线是"－"、右边长细线是"＋"，电流从"＋"经外电路流回"－"）：
- A：电压表并联在 L2 两端，但电压表标的是"＋V－"从左到右，电流沿外电路是从右往左经过 L2 这一段（先到电池"＋"经开关再到右边），所以电压表右边（电流先到的一端，电位更高）应该接"＋"，图上却是左边"＋"、右边"－"，接线柱接反了，不对。
- B：电流表串联在电路里，电流是从上方经开关、往下流入电流表（从电流表上方"－"接线柱流入），接线柱也接反了，不对。
- C：L1、L2 和"电池+开关"串联支路三者并联，开关闭合后 L1、L2 都能正常发光，接法本身没有问题，正确。
- D：开关 S 直接并联在 L1、L2 串联支路的两端，开关闭合后会把 L1、L2 那条支路直接短路，两个灯反而不亮（跟正常"闭合开关灯亮"相反），接法不对。

### 6
A —— A 图中电压表跟 L1 各自独立接在同一组左右两个节点之间（也就是电压表和 L1 是并联的，中间"开关+电池+L2"是给这两个节点供电的支路），所以电压表测的正是 L1 两端的电压，正确。
B 图中"电池+开关"是一条支路，"L1、L2 串联"是另一条支路，电压表并联在这两个节点上，测的是 L1、L2 两个灯泡串联在一起的总电压，不是单独 L1 的电压，不对。
C 图里电压表被直接串联在主电路里（电压表内阻很大，串联进去会让电路几乎断路，L1、L2 都不能正常工作），接法本身就错了，不对。
D 图里电压表并联在 L2 两端，测的是 L2 的电压，不是 L1 的，不对。

### 7
C —— 电路里 L1 和 L2 串联，中间节点记为 B。C 图中电压表跨接在 L2 自己的两个接线柱上（B 到 L2 右端），并联的正好只是 L2，测的是 L2 两端电压，正确。
A、D 两图电压表都是并联在"L1、L2 串联整体"的两端（跟第 6 题 B 选项一个道理），测的是 L1、L2 的总电压，不是单独 L2 的，不对。
B 图电压表并联在 L1 两端，测的是 L1 的电压，不是 L2 的，不对。

## 02

### 8
教室电风扇正常工作电压约为 **220**V（家庭电路电压）；一节新干电池的电压为 **1.5**V。电压使导体中的自由电荷发生**定向移动**，形成电流。
图中甲导体里电子的箭头指向杂乱、没有统一方向，乙导体里电子箭头方向整齐一致（都朝同一个方向运动），只有电荷做规则的定向移动才形成电流，所以有电流的是**乙**导体。

### 9
电路中产生持续电流的条件：**电路中要有电源（提供持续的电压），并且电路是通路（闭合回路，没有断开的地方）**。

### 10
图甲电池的 A 端是**正**极（干电池凸起的小圆点一端是正极）。
要把图甲的电池正确装进电池盒，电池的正极要接电池盒里"平直金属片"的那一端接线柱、负极接"弹簧"那一端——图乙里 B 是弹簧触点（负极接线柱），C 是平直金属片触点（正极接线柱），所以甲电池的 A 端（正极）应接到乙电池盒的 **C** 接线柱。
用图丙的电压表测一节干电池（约 1.5V）的电压，应该选 **0～3V** 的量程（比 0～15V 精确得多，1.5V 又落在 0～3V 范围内）。

### 11
电表读数要"两看清"：先看清接的是哪个量程，再看清这个量程对应的分度值，最后读数。
(1) 图甲（电流表，接线柱用的是"－"和"0.6"）：量程 **0～0.6A**；分度值 **0.02A**；读数 **0.4A**。
(2) 图乙（电压表，接线柱用的是"－"和"15"）：量程 **0～15V**；分度值 **1V**；读数 **5V**。

### 12
在"用电压表测电压"实验中，连接电路时，开关应处于 **B.断开** 状态，电压表应与被测物体 **B.并** 联连接，且电压表的 **"＋"** 接线柱靠近电源正极一侧。能与电源两端直接相连的是 **A.电压表**（电压表内阻很大，直接接电源两端是正常用法；电流表内阻很小，直接接电源两端相当于短路，会烧坏电流表）。

### 13
(a)：与电池、开关串联在主回路里的那个圆圈应该填**电流表（A）**——它在电路主干上，测的是通过整个电路的电流；跟 L2 并联的那个圆圈应该填**电压表（V）**——并联接法内阻大，正好用来测 L2 两端的电压，不会影响 L1、L2 正常发光。
(b)：跟 L1 串联的圆圈、跟 L2（及电池、开关）串联的圆圈，都应该填**电流表（A）**，分别测 L1 支路、L2 支路的电流；单独直接横跨在电路两端（不跟任何灯泡串联）的那个圆圈应该填**电压表（V）**——如果这里接电流表，内阻几乎为零，会把整个电路直接短路，只有电压表内阻大，能安全地接在这两点之间，测的是这部分电路两端的电压。

### 14
把 L2 接在电池、开关所在的那条竖直导线的空缺处（跟电池、开关串联，属于电压表不跨接的那一段）；把 L1 接在电压表正对着的那一段空缺处（跟电压表并联，让电压表两个接线柱正好卡在 L1 的两个接线柱上）。
这样接完，电路是"电池—开关—L2—L1—回到电池"的一个串联回路，电压表只跨在 L1 两端，不会把 L2 也包括进去，正好满足"电压表只测 L1 两端电压"的要求。
（这一题原图里 L1、L2 具体的两个空缺位置在扫描件上偏小、不是特别清晰，以上是根据"电压表只能测 L1"这个要求反推出的接法，逻辑上是唯一合理的接法，建议对照原图确认一下两个空缺具体在哪根导线上。）

## 03

### 15
(1) 水轮机在"水路"中的作用相当于电路中的 **C. 电灯**（水轮机是靠水流冲击才转动做功的装置，跟电灯靠电流才发光工作是一个道理，都是"用电/水的装置"）。
(2) 我们可以将电路中的**电压**类比为"水路"中的水压，**电流**类比为水流，抽水机类比为**电源**（抽水机提供水路的"水压差"，让水流动起来，就像电源提供电压、让电荷定向移动形成电流）。

### 16
先测 L1 电压时，电压表接的是 A、B 两点（正好是 L1 的两个接线柱，A—L1—B）。
小金测 L2 电压时，只把接 A 的那一端改接到 C，电压表的另一端仍然接在 B——这样电压表就变成接在 B、C 两点之间，正好是 L2 的两个接线柱（B—L2—C），这种接法 **A. 正确**，理由是：电压表两个接线柱正好对应 L2 的两个接线柱，中间没有把 L1 包含进来，测的就是 L2 单独两端的电压。
小丽却是把接 B 的那一端改接到 C，电压表另一端仍在 A——这样电压表就变成接在 A、C 两点之间，从 A 到 C 中间经过了 L1 和 L2 两个灯泡，测得的其实是 **L1 和 L2 两个灯泡串联在一起的总（两端）** 电压，不是 L2 单独的电压。这样操作可能带来的错误是：会把"L1、L2 两个灯泡加起来的总电压"误当成"L2 一个灯泡的电压"来记录和分析，导致数据偏大，得出错误的结论（比如错误估计 L2 实际承受的电压，或者在总结串联电路电压规律时用错了数据）。
